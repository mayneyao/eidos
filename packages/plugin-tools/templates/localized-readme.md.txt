# Localized Page

This page follows the host language without resetting the search field.

Requires Plugin API 3.7.0. Use matching checkout SDK, tools and host builds until
releases with this API are available. Checkout-generated projects include the
matching SDK/tools in `.eidos-toolchain/`; commit this directory with the project.
Run `npm install`, `npm run check -- --target lite` and `npm run pack:plugin`.
Messages and this documentation
are bundled for offline use.
