# Example Skills

This directory contains example skills to demonstrate the skills system.

## Skills Included

### eidos-automation

Automates common Eidos tasks like creating tables, organizing data, and managing spaces.

**Location:** `examples/skills/eidos-automation/SKILL.md`

**To use globally:**
```bash
ln -s $(pwd)/examples/skills/eidos-automation ~/.eidos/skills/eidos-automation
```

**To use in a specific space:**
```bash
ln -s $(pwd)/examples/skills/eidos-automation /path/to/your/space/.eidos/skills/eidos-automation
```
