# 真实 BLE 设备电量插件

这个插件通过 Lite 的设备选择弹窗授权真实 BLE 外设，在独立 background 中连接、读取电量，
并在设备支持时订阅电量变化。插件没有启用模拟后端，也不需要填写设备 ID。

## 设备与宿主要求

- 使用本仓库开发版 Lite，支持插件 API 3.4 或更新版本，并已构建 plugin-sandbox。
- 设备应支持 BLE GATT Battery Service（`0x180F`）和可读 Battery Level（`0x2A19`）。
  设备出现在扫描列表中不代表它一定支持这些服务；应查阅设备的 GATT 文档。
- 打开电脑蓝牙，允许 Lite/Electron 的系统蓝牙权限，让外设进入可发现/广播状态。
- 此示例不提供蓝牙音箱音频播放；音频输出属于另一种系统接口。

## 安装与使用

在 Cmd+K 搜索“蓝牙电量”，可执行“打开面板”“选择并连接设备”“查看连接与电量”“断开并停止后台”。
“打开面板”只打开页面，不启动后台、不扫描或连接设备。已连接时，在面板点击“恢复后台状态”查看当前连接。

在 Lite 插件管理中安装 `dist/bluetooth-battery-1.0.0.eidos-plugin`，并在当前 Space 启用。
开发时也可选择“加载开发源码”，打开此目录的 `plugin.json`。

1. 打开导航中的 **Bluetooth Battery**，点击 **选择设备**。
2. Lite 弹窗打开后自动扫描，点击设备行选中，再点击“连接”授权该设备。可重新扫描或随时取消；操作系统可能另行询问蓝牙权限。
3. 选择器关闭后，页面持续显示设备名称和进度：连接设备 → 检查电量服务 → 读取电量。只有读取成功才显示“已连接”和电量百分比。
4. 点击 **刷新电量** 主动读取；支持通知的设备还会推送变化。
5. 关闭页面后连接继续保留。在 Cmd+K 执行 **蓝牙电量：查看连接与电量** 查看后台状态，
   或重新打开页面并点击 **恢复后台状态** 恢复消息订阅。
6. 点击 **断开连接**，或执行 Cmd+K 的 **蓝牙电量：断开并停止后台**，
   释放连接和设备授权。

也可直接通过 Cmd+K 的 **蓝牙电量：选择并连接设备** 发起选择与连接。
打开页面不会自动连接。选择新设备会重启 background；其他页面需重新订阅。
设备掉线不会静默重连，停用插件、关闭 Space/窗口或退出 Lite 也会结束后台。

## 连接状态与恢复

- 选择器只负责授权；关闭选择器不代表已经连接。
- 连接中可以点击“取消连接”，停止后台并撤销本次设备授权。迟到的连接回复不会覆盖取消结果。
- 连接失败后保留设备与错误详情，提供“重试连接”和“换个设备”。缺少电量服务时显示针对性的说明。
- 设备断线后显示“连接已断开”，隐藏旧电量，等待用户主动重连。
- 已连接时取消换设备会保留原来的连接状态。
- 打开页面不会自动启动后台；重新打开时用“恢复后台状态”查询并恢复订阅。

## 代码入口

- `plugin.json`：使用 `bluetooth: true` 授权用户选中设备的 GATT 访问，不声明网络权限。示例代码只读取电量并订阅通知。
- `page.ts`：设备选择、连接、读取和停止按钮。
- `extension.ts`：Cmd+K 命令。
- `background.ts`：`getDevices()` → `gatt.connect()` → `getPrimaryService()` →
  `getCharacteristic()` → `readValue()` / `startNotifications()`。

## 常见结果

可选白名单：`bluetooth: { services: [{ uuid: "battery_service" }] }` 仅允许电量服务。
省略操作字段时允许设备支持的所有操作；指定任意 `read`、`write` 或 `notify` 字段后，
未声明的操作被禁止。例如 `read: true, notify: true` 不允许写入。

- 扫描不到：检查广播状态、系统权限，以及外设是否已被其他客户端占用。
- 选择成功但连接/读取失败：检查设备是否支持上述服务和特征，及是否要求配对。
- `connected: false`：后台尚未连接或设备已经掉线。
- 电量一直不变：有些设备只支持读取，或只在电量变化时通知，可主动点击读取。

编译与 Lite 目标检查不等同于真机验收。自动化测试使用显式模拟 BLE 后端；
真实设备连接需在你选定的硬件上完成。
