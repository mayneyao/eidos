# Markdown 编辑器 API 导读

本文面向 `0.1.0` 预发布版本，介绍接入时最常用的契约，不是逐项类型声明的完整译本。所有公开属性和插件贡献类型请对照[英文完整 API](/docs/api)。

## 受控文档

| 属性               | 作用                                   |
| ------------------ | -------------------------------------- |
| `documentKey`      | 文档身份；切换到另一篇文档时使用新的值 |
| `markdown`         | 当前文档的 Markdown 字符串             |
| `onMarkdownChange` | 接收编辑结果；宿主应保存并回传该值     |
| `onSaveRequest`    | 请求宿主保存，不代替文档变更回调       |
| `readOnly`         | 禁止修改，但仍可选择并复制内容         |

组件自行创建 Lexical composer。普通 React 接入方不需要操作 Lexical 节点，也不应把内部编辑器状态作为存储格式。目前没有命令式 editor ref；更新文档请使用受控值。

## 草稿与外部更新

用户正在编辑局部源码、行内公式或插入浮层时，外部文档更新不会直接覆盖未提交的草稿。组件保留草稿并通过 `onError` 报告冲突。

- 提交：保留本地草稿，并通过 `onMarkdownChange` 发出结果。
- 取消或按 Escape：丢弃草稿，加载待处理的宿主文档值。
- 持久化版本之间的冲突策略仍由宿主决定。

## 布局与主题

| 属性          | 说明                                                                        |
| ------------- | --------------------------------------------------------------------------- |
| `layout`      | `document` 提供文档留白；`embedded` 在全宽选择区域内保留居中的 760px 正文列 |
| `theme`       | `light` 或 `dark`，默认浅色                                                 |
| `className`   | 添加到编辑器根元素的类名                                                    |
| `ariaLabel`   | 可编辑区域的无障碍名称                                                      |
| `placeholder` | 空白文档提示，不写入 Markdown                                               |
| `labels`      | 覆盖组件公开的菜单、格式工具、浮层和提示文案                                |
| `autoFocus`   | 挂载时聚焦编辑器，默认关闭                                                  |
| `showToolbar` | 是否显示浮动工具栏和插入界面；原生 Markdown 快捷输入仍有效                  |

中文站通过 `labels` 提供中文菜单。此属性不是宿主应用的全局语言设置，也不会自动翻译第三方插件或文档正文。

## 图片粘贴与资源解析

`onPasteImage` 接收剪贴板图片，由宿主负责存储。保存成功后，组件在粘贴时保留的选区位置插入图片。异步操作需要尊重取消信号，不能把已经切换文档或变为只读的编辑器当作原目标继续修改。

`resolveImageUrl` 将 Markdown 中的规范图片地址解析为浏览器可展示的地址。可以同步或异步返回，适合把 `opfs:` 等存储地址转换为临时展示 URL。

Playground 使用 OPFS 存储粘贴图片。存储权限、配额、清理策略和备份不属于编辑器核心的责任。

完整请求与返回类型见[剪贴板图片接入](/docs/api#clipboard-image-integration)。

## 链接与文档内导航

- `baseUri` 用于解析相对资源；它不是任意文件系统访问权限。
- `onOpenExternalUrl` 接收通过策略检查后的外部地址。可编辑内容使用 Mod+点击，只读内容使用普通点击。
- 同文档片段在编辑器内部定位，不更改宿主 URL 或浏览器历史。
- Obsidian 配置中的 `onOpenInternalLink` 把已解析的笔记链接交给宿主查找和打开。
- `navigationTarget` 可在目标文档挂载后定位标题或块 ID。

## 插件与语法配置

`plugins` 和 `profile` 互斥。前者组合 Eidos codec 下的语法和行为；后者选择一个版本化 codec 及其插件集。内置 `profile` 值是 `gfm`、`eidos` 和实验性的 `obsidian`，也可以传入自定义 `MarkdownProfile`。参见[预设](./presets.md)。

插件配置是会话级不可变配置。改变编译后的插件签名或配置身份会建立新会话，因此应在渲染之外定义稳定的插件集合。不要用这种方式更新普通文档内容。

## 快捷键与代码高亮

`shortcuts` 按稳定的命令 ID 替换或禁用默认快捷键。作用域区分列表项、菜单、块选区、源码编辑器等上下文；不要在宿主添加全局按键监听来模拟同一条命令。

`codeHighlightTokenizer` 可替换围栏代码高亮器；设为 `false` 时关闭高亮，不改变代码内容。

## 错误与兼容性诊断

| 回调                    | 说明                                                 |
| ----------------------- | ---------------------------------------------------- |
| `onError`               | 编辑器、资源解析、保存、导航和分词等错误             |
| `onEfmDiagnostics`      | 延迟分析后的完整 EFM 诊断列表，包括空列表            |
| `onUnsupportedMarkdown` | 需要保留源码回退的非空兼容性摘要；不以空列表通知清除 |

这些回调是展示和诊断边界，不应被当作文档保存事件。
