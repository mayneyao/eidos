# 交互指南

编辑器采用安静的书写画布和按需出现的工具。文本编辑、块选择、菜单与源码草稿有各自的状态，不能互相抢占输入。

## 文本选区与块选区

正文内部拖动保留浏览器的文本选择，可以跨多个内容块。块级框选从正文外的画布留白开始；嵌入模式下，两侧选择区域不应通过增加正文 padding 来实现。

块选区与原生文本选区互斥。长文档框选及拖动需要跟随滚动，屏幕外已选内容仍属于选区。

当光标位于正文中时，按 Escape 可选择所在顶层块。进入块选择后，Shift+上/下箭头扩展选区，Mod+A 选择所有顶层块，再按 Escape 返回原光标。

## 插入与拖动

内容块顶部左侧依次显示 `+` 和拖动把手。`+` 在当前块下方插入新块，而不是转换当前块的类型。拖动把手操作它所对应的块，不跟随其他位置的文本光标。

插入菜单按列表排列，支持输入过滤和方向键导航。正文空行输入 `/` 打开块菜单；适当的行内命令边界可打开行内菜单，例如插入行内公式。普通词语中的 `/` 保持文本含义。

图片与块级公式可先以占位块出现。编辑浮层应悬浮定位，不挤压后面的内容。

## 列表与任务项

- Alt+上/下箭头在同级列表项之间排序，子列表随所属项移动。
- Mod+Enter 切换当前任务列表项的勾选状态。
- 无序列表、有序列表和任务列表的正文使用一致的缩进基准。
- 鼠标勾选不应产生包围整行的多余边框；键盘操作仍需可见的焦点提示。

## 局部源码编辑

选择连续顶层块后，按未修饰的 `E`，可将该范围原地切换成 Markdown 源码编辑器。列表和表格以整个顶层块参与，而不是单个嵌套列表项或单元格。

提交后重新解析为可视内容，并作为一次撤销操作；取消则保留原文档。无效输入保留在编辑状态并显示错误，不能悄悄丢失源码。

源码编辑区域支持行移动、复制、缩进、删除等快捷键。正在输入、处理 IME 组合输入或编辑浮层时，不应误触块级命令。

## 脚注与内部跳转

脚注定义显示在文档底部，不能作为普通块拖动排序或向下新建。正文引用与底部返回链接在当前编辑器内跳转，不应触发宿主路由。

源码中脚注定义的位置与可视化位置可以不同；显示在底部不意味着打开文档时必须重写源码。

## 只读与宿主集成

只读模式禁止修改、插入和排序，同时保留选择、复制和浏览链接的能力。图片存储、跨文档导航和保存由宿主接管。

本站的语言切换保留当前示例或 Playground 的未保存文档。切换语言不翻译用户已经输入的内容；首页的“重置示例”会载入当前语言的初始示例，并支持撤销重置。

## 快捷键说明

Mac 上 Mod 代表 Command，其他平台通常代表 Control。Playground 右上角的“快捷键”弹窗列出组件默认注册表中的全部命令；插件或宿主可按公开 ID 覆盖绑定。

详细行为与边界以[英文交互指南](/docs/guide)和[行为规范](/docs/specification)为准。
