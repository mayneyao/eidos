# 交付路线

状态：进行中。本文是当前交付方向的中文导读，不是完整验收清单；最新证据与未完成项目见[英文交付记录](/docs/roadmap)。

## 产品方向

`@eidos.space/markdown` 是通用、React 优先的 Markdown 编辑器。Notion 是交互参考：安静的画布、上下文工具、可预期的选区、键盘操作和锚定编辑。

Pierre 的 Diffs 与 Trees 是工程和文档参考：清晰的公开入口、可运行的示例、独立包产物、测试和性能证据；不要求复制其内部渲染架构。

Eidos 是消费者，组件不依赖其 Runtime、路由、存储、Electron 或全局样式。

## 交付内容

- 组件、插件 API 和既有宿主迁移。
- 明确区分规范、架构、使用指南与实现状态的文档。
- 有控制项、源码和重置功能的交互示例。
- 独立打包消费测试，以及浏览器、兼容性和性能验收。
- 文档与示例站点，最终部署到 md.eidos.space。

## 已有基础

已有独立 tarball 消费验证，站点生产构建不使用源码别名。CommonMark 和 GFM 的标准行为已迁入各自功能。站点已有首页示例、文档搜索、主题和完整 Playground。

这些成果不代表全部插件职责、宿主迁移、性能和可访问性验收已经完成。

## 剩余重点

继续拆分共享语法与节点；稳定公开 API 并迁移宿主；验证多实例和嵌入布局；建立长文档性能与源码保留证据；完成发布说明、部署和线上验证。

首轮交付不包括其他框架绑定、协作编辑、插件市场或 Obsidian 应用配置兼容。
