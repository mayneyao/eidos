# Eidos Android 0.9.0

## Brazilian Portuguese, Japanese, and Korean

The Android interface, table editor, and Markdown editor now support
**Português (Brasil)**, **日本語**, and **한국어**. In the file browser, open
**Folder actions → Language** to choose a language or keep **Follow system**.
Your choice is saved on the device. Dates and numbers use the selected
language's display format.

## Install and testing scope

Download `eidos-android-0.9.0.apk` and verify it against `SHA256SUMS`. Install
over 0.8.1 to retain local data. The APK supports ARM64 and x86-64 and requires
Android 9 or later.

Android emulator testing covers changing languages, reopening the app, and
opening tables and Markdown documents in the new languages.
