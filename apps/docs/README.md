# Eidos documentation

This Astro/Starlight site documents the current Eidos File and Eidos Lite
product line and is published at [docs.eidos.space](https://docs.eidos.space).

## Content rules

- Document shipped Eidos File, CLI, Web, and Lite behavior.
- Link normative behavior to the specification suite in `docs/specs`.
- Keep English and Simplified Chinese foundation pages aligned.
- Do not add retired application APIs or exploratory extension contracts.

## Commands

Run from the repository root:

```bash
pnpm dev:docs
pnpm build:docs
pnpm deploy:docs
```
