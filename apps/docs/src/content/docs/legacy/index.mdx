The previous documentation described the retired all-in-one Eidos Desktop,
including Nodes, Extensions, Relay, legacy application APIs, and Services.
Those pages do not describe the current Eidos File and Eidos Lite codebase.

Current work should start with:

- [Eidos Lite](/user-guide/) for local Spaces and desktop workflows;
- [Eidos CLI](/cli/) for terminal and Agent workflows;
- [Build with Eidos File](/developers/) for Runtime and UI packages;
- [Eidos File Specs](/specifications/) for interoperability contracts.

The old implementation and its historical documentation remain available on
the [`legacy/0.32` branch](https://github.com/mayneyao/eidos/tree/legacy/0.32).
Old documentation URLs redirect here when there is no truthful one-to-one
replacement.
