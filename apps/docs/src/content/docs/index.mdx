## Start with the file

**Eidos File** is an open, SQLite-backed format for structured data, with a
portable Runtime and shared editor UI. A `.eidos` file stores tables, typed
fields, records, relations, and saved views. Use the browser editor, the
agent-first CLI, or `eidos serve` to work directly with the file.

**Eidos Lite** is the desktop app for a local folder of `.eidos` files,
Markdown notes, and other ordinary files. That folder is your **Space**.
Lite adds local Graft history and optional Sync. Your local files remain
usable offline and without signing in.
