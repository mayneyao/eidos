## Start with the file

**Eidos File** is an open, SQLite-backed format for structured data.
A `.eidos` file stores tables, typed fields, records, and saved views.
You can open this file in the Web Editor, edit it with the CLI, or embed it in your applications.

**Eidos Lite** is a desktop application for local folders.
That folder is your **Space**.
Lite keeps `.eidos` files alongside Markdown notes and attachments.
Lite includes local history and optional Sync.
All local files remain usable offline without an account.
