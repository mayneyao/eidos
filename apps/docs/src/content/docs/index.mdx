The Web Editor, CLI, and Eidos Lite 0.1.2 are available now. macOS Lite
installers are signed and notarized; Windows and Linux installers are unsigned.
Lite 0.1.2 uses Graft 0.3.8 for reliable incremental Pull and cancellation
recovery. Sync remains an invite-only private preview.

## Eidos File

An Eidos File is a portable SQLite file for typed tables, relations, formulas,
and saved views. Web Editor, Eidos Lite, and `eidos serve` use the same editor
and Runtime.
