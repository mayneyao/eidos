The `eidos` CLI works directly with local `.eidos` files. It does not require Eidos Lite or a
background service.

<Aside type="note" title="Eidos CLI 2.0">
Eidos CLI 2.0 reorganizes commands into clear, atomic namespaces:
- **`file`**: File-level operations (`new`, `inspect`, `validate`, `repair`)
- **`schema`**: Relational structure (`dump`, `apply`, `table`, `field`, `view`)
- **`data`**: Rows and records (`query`, `mutate`, `compact`, `asset`)
- **`serve`**: Local/LAN web editor
- **`cloud`**: Account and remote services (`login`, `whoami`, `logout`, `publish`, `collect`)
- **`self`**: CLI maintenance and skills (`skill`, `upgrade`)
- **`plugin`**: Local plugin package management (`list`, `install`, `remove`, `inspect`)

Legacy 1.x flat commands (`eidos create`, `eidos context`, `eidos rows`, etc.) remain available as hidden aliases for backward compatibility.
</Aside>

## Basics

Use command-first namespaced syntax:

```bash
eidos file inspect tracker.eidos
eidos data query tracker.eidos Tasks --fields Title,Status --limit 50
eidos file validate tracker.eidos --level full
```

Commands print readable output by default. Add `--json` when a script or Agent needs the stable
machine-readable result:

```bash
eidos --json data query tracker.eidos Tasks --fields Title,Status --limit 50
```

Use `eidos --help` to list commands, and `eidos <command> --help` for the options of one command.

## File editor plugins

Use `eidos plugin` to inspect and manage locally installed plugins:

```bash
eidos plugin list
eidos plugin install ./my-plugin.eidos-plugin
eidos plugin remove com.example.plugin
```

To create and package new plugins, use `@eidos.space/plugin-tools`:

```bash
npx @eidos.space/plugin-tools create my-plugin
npx @eidos.space/plugin-tools check
npx @eidos.space/plugin-tools pack
```

Follow the [plugin development guide](/plugins/guide/) for a complete CSV editor walkthrough.

## Initialize the Agent Skill

The CLI bundles the Eidos Skill, so an Agent setup does not need Node.js,
`npm`, or `npx`:

```bash
# Install in the current Space/project.
eidos self skill init

# Install for the current user and all projects.
eidos self skill init --global
```

Use `eidos self skill init --space <DIR>` for another Space. The command writes the
standard `.agents/skills/eidos` layout, is safe to repeat, and refuses to
replace locally edited files unless `--force` is explicit. Start a new Agent
task after initialization.

folder navigation, Space history, or Sync.
