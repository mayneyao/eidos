Declarations request capabilities; the host validates and grants access. apiVersion is the package protocol; requires.pluginApi is the minimum host API. Access defaults to read. Background requires Lite API 3.4; templates 3.2; hooks 3.3; file metadata and explorer 3.1.

Usage guide: [views](/plugins/views/). [API index](/plugins/api/).

Signatures, parameters and return types are generated from the SDK. Optional members are not available in every host and context.

### PluginManifest.background

A separate Worker-style entry. network: true permits public HTTPS/WSS after approval; up to eight exact networkOrigins optionally restrict it. bluetooth: true grants the selected device, optionally narrowed by a service whitelist. Device IDs are chosen by the host. API 3.6 adds autoStart: true for approved startup on Space opening, and fileHistory: true for file-open metadata in the owner window and Space; fileHistory does not grant file contents.


```ts
background?: {
    entry: string;
    network?: true;
    networkOrigins?: string[];
    bluetooth?: true | {
        services: BluetoothServicePermission[];
    };
    fileHistory?: true;
    autoStart?: true;
};
```
