Lite API 3.8. Declare a local program name and fixed arguments in manifest.sidecar. Only standalone page and file Views receive this optional capability. Native startup requires host approval; the program retains OS permissions outside the JavaScript capability sandbox. CLI Serve and mobile do not expose native sidecars.

Usage guide: [native-processes](/plugins/native-processes/). [API index](/plugins/api/).

Signatures, parameters and return types are generated from the SDK. Optional members are not available in every host and context.

### PluginSidecar.status

Supported hosts: <Badge text="Lite" variant="note" />

Discovery only: available means an executable was found; running means an owned native process exists. Neither implies protocol readiness or a compatible program version. Does not execute, install or prompt.


```ts
status(): Promise<SidecarStatus>;
```


Returns: `Promise<SidecarStatus>`.

### PluginSidecar.start

Supported hosts: <Badge text="Lite" variant="note" />

Checks a remembered approval for the Space, exact plugin revision, executable path/target/content, fixed argv and canonical Space cwd. Installation or enablement review can grant this; otherwise first use requests native approval showing these details and OS access. Unchanged consent survives host restart. Disabling/uninstalling revokes it; Stop does not. Reuses the same owner/Space/plugin/revision run. Pending startup expires after five minutes and is cancelled with its initiating View; after startup, closing a View only detaches it. Changed or missing identity requires renewed approval. Success means OS spawn, not protocol readiness.


```ts
start(): Promise<void>;
```


Returns: `Promise<void>`.

### PluginSidecar.stop

Supported hosts: <Badge text="Lite" variant="note" />

Stops the shared owned process tree, affecting every attached View. Disabling/updating the plugin, leaving the Space, closing its owner window or quitting Lite also stops it. Native side effects are not undone.


```ts
stop(): Promise<void>;
```


Returns: `Promise<void>`.

### PluginSidecar.send

Supported hosts: <Badge text="Lite" variant="note" />

Writes one JSON value followed by LF. Each frame including LF is limited to 1 MiB; queued stdin including the incoming frame is limited to 4 MiB. Completion means stream write completion, not a native protocol response.


```ts
send(data: BackgroundMessage): Promise<void>;
```

| Parameter | Type | Required |
| --- | --- | --- |
| `data` | `BackgroundMessage` | Yes |

Returns: `Promise<void>`.

### PluginSidecar.onEvent

Supported hosts: <Badge text="Lite" variant="note" />

Subscribes without starting a process. Returns a disposable observer; closing the View unsubscribes. stdout is LF-delimited JSON (CRLF accepted), with a 1 MiB frame and 16 MiB/s rate limit; stderr over 1 MiB/s is dropped. Malformed output stops the process. Unicode line separators are ordinary string content. Reconcile native state after reattaching because events are not replayed.


```ts
onEvent(listener: (event: SidecarEvent) => void): Promise<Disposable>;
```

| Parameter | Type | Required |
| --- | --- | --- |
| `listener` | `(event: SidecarEvent) => void` | Yes |

Returns: `Promise<Disposable>`.
