A plugin adds an interface or operation to Eidos.
For example, build a reader for text files, a project overview page, or a
command that processes selected records.

## Choose where the View opens

| View kind | Opens from | Example |
| --- | --- | --- |
| `page` | Sidebar navigation | A project overview |
| `file` | A file, or a table inside an Eidos File | A text reader or table visualization |

A page opens independently. A file View receives the file it is bound to.
These are the two View kinds.
A plugin can also provide commands, shortcuts, and document formatting.
Theme packages provide light and dark palettes for Lite.

## Build a working example

Follow [Create your first plugin](/plugins/guide/).
You will declare a text reader, load its source in Lite, and check that it
updates when the file changes.

Then read [plugin concepts](/plugins/concepts/) to understand data access and
lifetime. Use the [API reference](/plugins/api/) for exact methods and types.

## Install a package

1. Install an `.eidos-plugin` package through Lite's Plugin Manager.
2. Review its requested access.
3. Enable it for the current Space.
4. Open the entry point it declares.

File Views appear in **Open with**. Page Views appear in navigation.
Commands use their declared entry points, such as the command palette.

Each Space keeps its own plugin enablement and settings.
Themes apply throughout Eidos Lite.
Follow [development and distribution](/plugins/workflow/) to package your work.
