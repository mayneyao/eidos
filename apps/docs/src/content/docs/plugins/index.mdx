Plugins let you build file editors, dashboards and tools inside Eidos. You can give CSV files a spreadsheet interface, add a project overview page, or run a command that processes selected records.

## Choose how your view opens

A **page view** is an independent tool opened from the sidebar. Use it for a project home, journal index or workspace dashboard.

A **file view** opens with a file and displays or edits its contents. Use it for a text editor, media player, or a visualization of a table inside an Eidos file.

One plugin can provide several views alongside commands, keyboard shortcuts and document formatting. You can also create a theme package with light and dark palettes for Eidos Lite.

## Start building

[Create your first plugin](/plugins/guide/) walks through a text reader: declare the view, build its interface, open it in Eidos Lite and observe content changes. You can load this example directly from source.

Then read [core concepts](/plugins/concepts/) to understand how views connect to files and data, use the [API reference](/plugins/api/) to look up methods, and follow [development and distribution](/plugins/workflow/) to package your plugin for others.

## Install and use

Plugins are distributed as `.eidos-plugin` files. Install one through Eidos Lite's Plugin Manager, then enable it for a Space. File views appear in **Open with**, pages appear in sidebar navigation, and commands run from entry points such as the command palette.

You can use a plugin in several Spaces. Each Space keeps its own enablement and plugin settings. Themes apply throughout Eidos Lite.
