Look up declarations, contexts, capabilities and data types by API name. Signatures are generated from the SDK; use `import type` to import types. Task-oriented walkthroughs live in the development guides.

import { Badge } from "@astrojs/starlight/components"

API entries use host badges: <Badge text="Lite" variant="note" /> for Eidos Lite,
<Badge text="Serve" variant="note" /> for CLI Serve, and
<Badge text="Mobile" variant="note" /> for the Android/iOS plugin host.
Only supported hosts are shown. Badges apply to the individual member; declarations,
permissions, minimum API versions, and context restrictions still apply. An entry
without badges makes no host-support claim, including shared data types.
