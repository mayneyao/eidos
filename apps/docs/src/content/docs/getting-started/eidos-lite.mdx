## 1. Install the app

Download Eidos Lite from the [Eidos download page](https://eidos.space/download), then complete
the installation for your operating system.

Eidos Lite can be used locally without signing in. An account is only required for optional
services such as Sync and Publish.

## 2. Create or open a Space

Start Eidos Lite, then choose one of these options:

- **New Space** creates a new local folder.
- **Open Space** uses a folder that already exists on your computer.

The selected folder remains an ordinary folder. Eidos Lite does not convert it into a proprietary
container.

## 3. Create your first file

Select **New Eidos File** in the Explorer and give the file a name. Eidos Lite creates a `.eidos`
file and opens it in the editor.

Create a table, add a few fields, and enter the first record. Changes are written to the local file.

Continue with [Start with an Eidos File](/user-guide/eidos-file-basics/).

## Open an existing file

If a Space already contains `.eidos` files, select one in the Explorer to open it. You can also
copy files into the Space with your normal file manager, then refresh the Explorer.

To inspect one file without creating a Space, use the [Web Editor](/getting-started/browser/).
