Eidos Lite is the desktop app for working with local files.
You can open a Space and edit its files without an account or internet connection.

## Install Eidos Lite

Get the package for your system from the [download page](https://eidos.space/download).
Install it, then open Eidos Lite.

## Open a folder

Choose **New Space** to start in a new folder, or **Open Space** to use an
existing folder. For this example, use a folder named `Research`.

**Check:** the sidebar shows the contents of that folder.

<FileMap />

The diagram shows a possible folder after you add a book list, a note, and an
image. Opening a Space does not create those example files.

## Create an Eidos File

1. Open **New File** in the sidebar.
2. Choose **Eidos** and name the file `books.eidos`.
3. Open the file in the editor.

**Check:** the sidebar contains `books.eidos`, and the editor displays the file.

## Find your way around

| Area | Use it to |
| --- | --- |
| Sidebar | Open, create, rename, or move files in the Space |
| Tabs | Return to an open file |
| Editor | Read notes or work with table records |
| Versions | Review changes and saved history |
| Sync | Check optional cross-device synchronization |

Continue with [Create a book list](/user-guide/eidos-file-basics/).
To use the Space on your phone, pair it in **Settings → Devices**, then enable
**Sync → 局域网同步** for the Space. Follow the [LAN sync guide](/user-guide/sync/);
no cloud account is required.
Before moving a Space to another drive, read [data storage and backups](/user-guide/data-safety/).
