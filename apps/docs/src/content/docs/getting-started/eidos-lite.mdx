Eidos Lite is a focused desktop application that brings structured data, visual tables, and versatile note-taking to your local folders. It runs completely offline without requiring an account.

---

## 1. Download & Installation

Visit the [official download page](https://eidos.space/download) to get the installer for your system:

- **macOS**: Native packages for both Apple Silicon (M series) and Intel Macs. Simply drag Eidos Lite into your Applications folder.
- **Windows**: Download the installer and follow the standard setup wizard.
- **Linux**: Available as `.deb` packages and standalone archives.

---

## 2. Open Your First Space

When you launch Eidos Lite, choose one of two options on the welcome screen:

- **New Space**: Pick or create an empty local folder to start a fresh workspace.
- **Open Space**: Select an existing folder on your machine (such as an existing projects or documents folder).

:::tip[A Space is Just an Ordinary Folder]
The folder you select remains completely standard in your operating system. Eidos never converts it into a locked database. You can open and edit files directly in macOS Finder or Windows File Explorer at any time.
:::

---

## 3. Interface Overview

Eidos Lite is organized into four core functional zones:

1. **Left Workspace Sidebar**:
   - Navigate your folder tree with collapsible hierarchies.
   - Quick action buttons at the top: **New Eidos File**, **New Markdown Note**, and **New Folder**.
   - Right-click any file or folder to rename, reveal in your operating system, publish, or delete.
   - Access **Plugin Manager** and **App Settings** from the bottom.
2. **Tabs Bar**:
   - Seamlessly switch between multiple open `.eidos` tables, Markdown notes, and sub-views just like in a modern code editor or web browser.
3. **Main Editor Canvas**:
   - When viewing an `.eidos` file, easily switch between Grid, Gallery, Kanban, and Calendar views with intuitive column customization panels.
   - When viewing a `.md` file, enjoy an instant, distraction-free Markdown writing environment.
4. **Action Bar (Top Right)**:
   - **Version History (Clock Icon)**: Snapshot and restore states in your local workspace time machine.
   - **Cloud Sync (Cloud Icon)**: Multi-device sync indicator and controls.
   - **Publish (Rocket Icon)**: Share documents or form views as live web pages with one click.

---

## 4. Quick 3-Step Start

1. Click the **New File** button in the sidebar and choose **Eidos**.
2. Name your file (e.g. `Tasks.eidos` or `Projects.eidos`) and press Enter.
3. In the opened table, double-click the first row to start typing, or click the **+** button on the far right of the header to add new custom columns.
