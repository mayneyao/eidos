Eidos Lite is the desktop app for local folders.
It opens folders that contain `.eidos` files, Markdown notes, and attachments.
Lite provides local version history and optional Sync.
You can open a Space and edit files offline without an account.

## Install Eidos Lite

Download the installer for your system from the [download page](https://eidos.space/download).
Install the application and start Eidos Lite.

## Open a folder

Select **New Space** to start in a new folder.
Select **Open Space** to use an existing folder.
For this guide, use a folder named `Research`.

**Check:** The sidebar shows the contents of that folder.

<FileMap />

The diagram shows a possible Space structure with a book list, a note, and an image.
Opening an empty Space does not create these example files.

Lite automatically reopens your last Space on startup. The Space selector appears
on first use, when there is no remembered Space, or when the last folder cannot be
opened. Closing a Space window keeps the selector closed. Switch Spaces at any
time from the Space name at the top of the sidebar.

## Create an Eidos File

1. Select **New File** in the sidebar.
2. Select **Eidos** and name the file `books.eidos`.
3. Open the file in the editor.

**Check:** The sidebar contains `books.eidos`, and the editor shows the file.

## Find your way around

| Area     | Purpose                                          |
| -------- | ------------------------------------------------ |
| Sidebar  | Open, create, rename, or move files in the Space |
| Tabs     | Switch between open files                        |
| Editor   | Read notes and edit table records                |
| Versions | Review changes and restore saved history         |
| Sync     | Manage cross-device synchronization              |

Continue with [Create a book list](/user-guide/eidos-file-basics/).
To use the Space on a mobile device, pair devices in **Settings → Devices**.
Then enable **Sync → LAN Sync** for the Space.
Follow the [LAN sync guide](/user-guide/sync/).
LAN sync does not require a cloud account.
Before you move a Space to another drive, read [data storage and backups](/user-guide/data-safety/).
