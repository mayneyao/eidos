Eidos Lite is the primary desktop product for using an ordinary folder as a
Space. A Space can contain several `.eidos` files and ordinary files without
turning the folder into a proprietary container.

<Aside type="note" title="Eidos Lite 0.1.3 is available">
  Download Eidos Lite from the [Eidos download
  page](https://eidos.space/download#eidos-lite). Version 0.1.3 renders HTTPS
  URL fields as cached Grid thumbnails and Gallery covers, supports remote File
  attachments, and keeps expanded Explorer folders stable during refreshes. Sync
  is an invite-only private preview and remains unavailable until waitlist
  access is approved.
</Aside>

## What Lite adds

- one Explorer for Eidos Files, folders, and ordinary files;
- shared Grid, Gallery, Kanban, and Calendar editing through `eidos-file-ui`;
- local Space history and row-aware changes through Graft;
- files deleted from the Explorer move to the system Trash;
- invite-only authenticated Sync while local work remains account-free.

## The file model

The folder you choose remains a normal folder. `.eidos` files remain SQLite
application files. Local history metadata is separate from the data model, and
signing out or going offline does not make local files unreadable.

## Global preferences

Open **Settings → Preferences** to choose the theme, language, and whether
Calendar weeks start on Monday. The calendar preference applies immediately to
every open Eidos File, but remains an app preference rather than file metadata.

Developers who need to run the current source can use the
[Eidos Lite workspace guide](https://github.com/mayneyao/eidos/tree/dev/apps/eidos-lite-desktop).
For everyday data guarantees, read [History, recovery, and Sync](/user-guide/history-and-sync/).
