## About Eidos Files

An **Eidos File** is a SQLite application file with a versioned format for
tables, fields, records, relations, and saved views. Web Editor, Eidos Lite,
and CLI Serve use the same Runtime to read and edit it.

Read [Core concepts](/concepts/) for Runtime, Space, and Graft, or go directly
to the [user guide](/user-guide/).
