Choose the tool that fits your task. All three work with the Eidos File format.

| I want to… | Start here | Where work is saved |
| --- | --- | --- |
| Manage a folder of files and notes | [Eidos Lite](/getting-started/eidos-lite/) | Local files in a Space |
| Try one file without installing an app | [Web Editor](/getting-started/browser/) | Save to disk or download the working copy |
| Use commands or an agent | [CLI](/getting-started/cli/) | The file path supplied to the command |

## Make something small

1. Open or create an Eidos File.
2. Add a **Books** table with a **Title** field.
3. Add a book, then create a **Status** Select field.
4. Create a view that shows only books you are reading.
5. Check that your changes are saved.

Follow [the book-list walkthrough](/user-guide/eidos-file-basics/).
If the names are unfamiliar, first read [how the pieces fit](/concepts/).
