An **Eidos File** is a standard SQLite database with a defined schema for
tables, fields, records, and saved views. The format remains useful outside any
single Eidos application.

## Choose a host

| Host                | Best for                                                                    |
| ------------------- | --------------------------------------------------------------------------- |
| Eidos Lite          | Working with a folder of local files, version history, and optional Sync    |
| Eidos File Web      | Opening one `.eidos` file in a compatible browser                           |
| Eidos CLI           | Creating, inspecting, querying, mutating, and serving files from a terminal |
| Eidos File packages | Embedding the Runtime or shared React UI in another application             |

## Try the CLI

Install the current stable binary, create a file, and open its local editor:

```bash
curl --proto '=https' --tlsv1.2 -LsSf \
  https://download.eidos.space/cli/install.sh | sh

eidos create tracker.eidos --title "Project Tracker"
eidos serve tracker.eidos --open
```

Windows PowerShell users can install with:

```powershell
irm https://download.eidos.space/cli/install.ps1 | iex
```
