The Web Editor creates and edits individual `.eidos` files in your browser.
It uses the same Runtime and editor UI as Lite and CLI Serve.
It does not require software installation or an account.
To work with a folder of notes and other files, use [Eidos Lite](/getting-started/eidos-lite/).

<Steps>

1. Open [editor.eidos.space](https://editor.eidos.space/).

2. Select **New** for a blank file. Select **Open** for an existing `.eidos` file. You can also open the bundled sample.

3. Add records, fields, tables, or views. Double-click a Grid cell or press <kbd>Enter</kbd> to edit it.

4. Select **Save** to update the local file directly. If your browser does not support writable file handles, select **Save As** or **Download a copy**.

</Steps>

<Aside type="note" title="Know which copy you are editing">
  Chromium browsers can write changes directly back to your local file after you grant permission.
  Other browsers import a temporary working copy and require you to download changes.
  The titlebar shows the current save state.
</Aside>

## What stays local

Your file data, SQLite queries, and edits remain on your local device.
The editor keeps a private recovery copy in the browser for unsaved work where supported.
This recovery copy does not replace saving or backing up your `.eidos` file.

Continue with [Eidos File basics](/user-guide/eidos-file-basics/) or
[Data location and safety](/user-guide/data-safety/).
