The specification suite defines how compatible implementations store, interpret, edit, and render
an Eidos File. English pages are normative. Chinese pages are informative translations.

## Start reading

Read the specifications in layer order when implementing the complete stack:

```text
File Format → Runtime → Adapter → UI
```

Start with File Format and Runtime. Read Adapter when connecting Runtime to a platform, and UI when
building an editor or viewer.
