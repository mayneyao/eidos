The Rust `eidos` CLI works directly on `.eidos` files and does not require a
running desktop or web application. It is the supported automation boundary
for logical Eidos File data.

Use `context` to discover a bounded working set, then use `apply` or
`schema-apply` with the current revision. Every mutation is atomic; follow a
write workflow with full validation.

```bash
eidos tracker.eidos context Tasks --fields Title,Status --limit 50
eidos tracker.eidos apply request.json
eidos tracker.eidos validate --level full
```

Raw SQLite writes bypass Runtime invariants and are not a supported automation
interface. See the [CLI README](https://github.com/mayneyao/eidos/tree/dev/apps/cli)
for installation and the complete command contract.
