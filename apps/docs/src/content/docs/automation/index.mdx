Automation is a separate platform module from extensions. Use it when a
workflow runs outside an Eidos UI surface or must be driven by another process.

| Surface            | Use it for                                                                            | Status         |
| ------------------ | ------------------------------------------------------------------------------------- | -------------- |
| Eidos File CLI     | Typed `.eidos` queries and revision-checked mutations from scripts or external agents | Alpha          |
| Agent Skill        | Safe inspect, plan, apply, validate, and Graft-review workflow around the CLI         | Alpha          |
| Desktop API        | Controlled integration with a running Desktop app                                     | Evolving       |
| Native Agent tools | Permission-aware operations initiated inside Eidos                                    | Paused         |
| Extension SDK      | Commands and UI that run inside Eidos                                                 | Design preview |

The Rust `eidos` CLI works directly on open Eidos Files and does not require
Desktop to run. It is the supported automation boundary for `.eidos` data;
raw SQLite writes are not supported. For the previous database-backed Space
APIs, use the [Legacy Docs](https://legacy.docs.eidos.space).
