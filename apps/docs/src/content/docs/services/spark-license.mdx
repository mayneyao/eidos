Eidos is an independently developed, open-source product. While local features are free forever, some advanced scenarios (cross-network data receiving, sync, etc.) require cloud computing resources—we call these **Add-on Services**.

Spark License unlocks premium cloud features through two core benefits:

## 1. Early Access to New Features

Be the first to try new capabilities:

| Feature | Status |
|---------|--------|
| **Custom Sync Provider** | ✅ Available (AWS S3, R2, MinIO, etc.) |
| **Relay** | ✅ Available |
| **Official Sync** | ⏳ Coming soon |
| **Publish** | ⏳ Coming soon |

## 2. Free Quotas for Add-on Services

Spark users receive free cloud resource quotas:

### Relay

| Parameter | Spark | Free¹ |
|-----------|-------|-------|
| **Channels** | 100 | 5 |
| **Storage** | 100 MB (~50k messages) | 10 MB (~5k messages) |
| **Retention** | 14 days | 3 days |
| **Max Message Size** | 128 KB | 128 KB |
| **API Rate Limit** | 1000 reqs/hr | 1000 reqs/hr |

¹ Free Relay is currently in a promotional trial period and will transition to a subscription model in the future.

:::note
These quotas are **dynamic** and operate on a **shared pool model**. We do **not** guarantee permanent allocation at fixed levels—they may adjust based on infrastructure capacity and service growth.

**Example**: Current storage is 100 MB. As more Spark users join, the base quota may decrease to 50 MB for sustainability. However, early supporters permanently retain **2x the base quota** (or higher, depending on tier), so they still enjoy 100 MB while new users start at 50 MB.
:::
