Eidos Publish shares one selected file from a Space. After publishing, it has a stable web address, and Eidos Lite and your computer do not need to remain online.

Eidos Publish is a subscription service provided by Eidos. Your account must have Publish enabled before you can publish or update online content. Local use of Eidos Lite does not require a subscription.

You can publish:

- An `.eidos` file as a read-only interactive file or as one of its Form Views.
- A `.md` or `.markdown` file as a web page.

Publish and Sync are enabled separately. Enabling one does not automatically enable the other.

## Publish a file

1. Right-click the file in the Space Explorer.
2. Choose **Publish…**.
3. Set the web path under **Resource slug**.
4. Choose an option under **Access**.
5. Select **Publish**.

When publishing finishes, copy the link or open the page from the progress panel.

For an `.eidos` file, **Interactive Eidos File** under **Publish as** lets visitors browse its data and Views without changing your local file.

## Choose who can open it

- **Public** — anyone with the link.
- **Password** — anyone with the password you set.
- **Private** — only you, while signed in as the publisher.

Password and Private access depend on the current Publish plan.

## Update published content

Editing the local file does not automatically update the published copy. To update it:

1. Right-click the original file.
2. Choose **Manage Publish…**.
3. Find the existing resource and select its Republish action.

The original web address stays the same.

## Publish a Form

If an `.eidos` file contains a Form View, you can publish that Form:

1. Right-click the `.eidos` file and choose **Publish…**.
2. Under **Publish as**, choose the Form.
3. Choose who can respond and whether one account may submit more than once.
4. Set the web path and access, then select **Publish**.

Responses first stay in the Publish service; they are not written to the local file automatically. To import them, open **Manage Publish…** and select **Collect now** beside the Form.

Republish after changing the Form's questions or Fields so the online Form receives the update.

## How attachments are published

Attachments remain separate files in the Space; they are not stored inside the `.eidos` file. During publishing, Eidos finds attachments referenced by the source and uploads the files that are needed.

Keep attachments in the source file's folder or one of its subfolders, and preserve their relative paths. Publishing includes only the selected source and its referenced attachments—not the whole Space.
