Publish creates a hosted page from selected content in your Space.
Your computer can go offline after publication.
Local edits reach the hosted page only when you republish.

## Publish a file

1. Right-click a Markdown or Eidos File in the sidebar.
2. Choose **Publish…**.
3. Set the URL path and access mode.
4. Review the content and choose **Publish**.
5. Open the returned link and check the result.

| Access mode | Who can open the page |
| --- | --- |
| Public | Anyone with access to the URL |
| Password | Visitors who provide the password |
| Private | The signed-in publisher |

Available modes depend on the content and service plan.
A published Eidos File is read-only for visitors; browsing it does not edit
your local file.

## Collect form responses

1. Create a Form view in the table.
2. Open **Publish…** for the Eidos File.
3. Under **Publish as**, select the form.
4. Configure submission access and publish.
5. Submit a test response through the hosted form.
6. Open **Manage Publish…** in Lite and choose **Collect now**.

**Check:** the submitted response appears in the local table.
Publishing a form and collecting its responses are separate operations.

## Ordinary files and plugin Views (staging preview)

The staging build can publish an ordinary file as a download.
If an enabled plugin provides a compatible read-only file View, select it
under **Publish as** to render the file as a page.

This Pro preview snapshots the source file and plugin together.
Each must fit the 16 MiB limit. The View can read only the published file.
Visitors do not need to install the plugin.
See the [CLI compatibility requirements](/cli/publish/#ordinary-files-and-plugin-views-staging-preview).

## Update or remove the page

Open **Manage Publish…** to republish after local changes.
Republishing updates the hosted content at the existing URL.
Use the management controls to unpublish a page when it should no longer
be available.

**Check:** open the URL after each operation to verify the intended state.

## Check service access

Publishing requires an eligible account and plan.
Check the [account dashboard](https://eidos.space/account) for available
features and current limits.

For sharing an editable local file instead, read [data storage and attachments](/user-guide/data-safety/).
