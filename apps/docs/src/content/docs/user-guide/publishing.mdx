Publish creates a hosted page from selected content in your Space.
Your computer can go offline after publication.
Local edits reach the hosted page only when you republish.

## Publish a file

1. Right-click a file in the sidebar.
2. Select **Publish…**.
3. Set the URL path and access mode.
4. Review the content and select **Publish**.
5. Open the returned link and check the result.

| Access mode | Who can open the page           |
| ----------- | ------------------------------- |
| Public      | Anyone with access to the URL   |
| Password    | Visitors who enter the password |
| Private     | The signed-in publisher         |

Available modes depend on the content type and your service plan.
A published Eidos File is read-only for visitors.
Browsing the hosted page does not change your local file.

## Collect form responses

1. Create a Form view in your table.
2. Open **Publish…** for the Eidos File.
3. Under **Publish as**, select the form.
4. Configure submission access and publish.
5. Submit a test response through the hosted form.
6. Open **Manage Publish…** in Lite and select **Collect now**.

**Check:** The submitted response appears in your local table.
Publishing a form and collecting responses are separate operations.

## Ordinary files and plugin Views

Publish an ordinary file as a direct download by selecting **Download file** under **Publish as**.
If an enabled plugin provides a compatible read-only file View, select it to render the file as a web page.

This Pro feature packages the source file and plugin together.
Each item must fit within the 16 MiB size limit.
The View can read only the published file.
Visitors do not need to install the plugin.
Files without a plugin View remain available as file downloads.
Downloads support files up to 1 GiB, subject to account limits.
See [CLI compatibility requirements](/cli/publish/#ordinary-files-and-plugin-views).

## Update or remove the page

Open **Manage Publish…** to republish after you edit local content.
Republishing updates the hosted content at the existing URL.
Use the management panel to unpublish a page when you want to take it down.

**Check:** Open the URL after each action to check the updated state.

## Check service access

Publishing requires an eligible account and plan.
Check your [account dashboard](https://eidos.space/account) for features and storage limits.

To share an editable local file instead, read [data storage and attachments](/user-guide/data-safety/).
