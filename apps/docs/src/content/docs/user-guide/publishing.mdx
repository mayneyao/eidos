Eidos Publish gives one file in your Space a stable web address. After publishing, you can close
Eidos Lite and your computer does not need to remain online.

Publish works independently from Sync. Before you begin, sign in and activate Publish under
**Settings → Account & Services**.

## Publish a file

1. Find the `.eidos`, `.md`, or `.markdown` file in the Space Explorer.
2. Right-click the file and choose **Publish…**.
3. Set its web address, then choose **Public**, **Password**, or **Private** access.
4. Select **Publish**.

When publishing finishes, copy the link or open it in your browser. Visitors can read the
published content but cannot change your local file.

If the file refers to images or attachments in the same Space, Eidos includes them when
publishing. They remain separate files and are not stored inside the `.eidos` file.

## Update published content

1. Right-click the original file in the Space Explorer.
2. Choose **Manage Publish…**.
3. Review the address and access setting, then publish again.

The web address stays the same. Visitors see the latest published content when they open it again.

## Publish a form

1. Create a Form View in an Eidos File.
2. Right-click that `.eidos` file in the Space Explorer and choose **Publish…**.
3. Under **Publish as**, choose the form and decide who can respond.
4. Publish it, then share the link with respondents.

Responses are not written to the local file automatically. To collect them, right-click the
original file and choose **Manage Publish… → Collect now**. Eidos imports the waiting responses
into the original table.

If you change the form's questions or fields, publish it again to update the live form.

## Choose who can open it

- **Public** — anyone with the link.
- **Password** — anyone with the correct password.
- **Private** — only the publisher while signed in.

## Troubleshooting

**Sign in or activate Publish**

Open **Settings → Account & Services**, sign in, and check your Publish status.

**An attachment is missing**

Make sure the attachment is still inside the Space and the source file refers to it with a
relative path.

**Publishing failed or reached a limit**

Open the task details for the reason. The account and pricing pages show the current file and
storage limits.

For terminal workflows, see [Publish from the command line](/cli/publish/).
