Eidos Lite provides seamless interoperability with standard CSV formats, making it easy to migrate data from Excel, Numbers, Google Sheets, or other tools, and export reports for external use.

---

## 1. Import a CSV as a New Table

If you have existing spreadsheet data (exported from Excel, Google Sheets, or other databases as a `.csv` file), you can import it in seconds:

1. In your `.eidos` file, click the **+** button in the table tab bar and select **Import CSV**.
2. Select your `.csv` file.
3. **Review & Configure**:
   - **Table Name**: Defaults to the CSV filename; adjust if desired.
   - **Record Label Field**: Pick which column represents the primary title of each record (e.g. "Product Name" or "Contact Name").
   - **Field Types**: Eidos automatically infers column data types (numbers, dates, text, checkboxes). Adjust any dropdown if needed.
4. Click **Start Import** to convert your spreadsheet rows into structured Eidos records.

Once imported, you can customize option colors for single-select columns, create Kanban views, or establish cross-table relationships.

---

## 2. Export Current View to CSV

When you only need to export the subset of data filtered in a specific view (e.g. "Completed Tasks for August"):

1. Open your target view.
2. Open the view menu in the top right and choose **Export Current View to CSV**.
3. Eidos exports exactly what you see: honoring column order, visible fields, and active filters—ideal for sharing reports or feeding analytics tools.

---

## 3. Export Full Table to CSV

If you want all raw records from a table without view filters or hidden columns:

1. Open the table menu.
2. Select **Export Entire Table to CSV** and save the file to your computer.

---

## 4. Comparing CSV to .eidos Files

- **CSV is for Data Interchange**: CSV is a universal flat text format designed to move raw table rows between different software applications.
- **.eidos is for Complete Workspaces**: A flat CSV cannot store your Kanban layouts, gallery covers, saved filter presets, formulas, cross-table relationships, or binary attachments. To back up or share your full workspace, **always copy the `.eidos` file itself**.
