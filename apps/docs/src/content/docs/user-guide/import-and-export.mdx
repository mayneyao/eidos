Use CSV to exchange rows with other tools. Use an Eidos File, together with
its referenced assets, to preserve the file's structure and saved views.

## Import a new table

1. Export your source spreadsheet as CSV.
2. In the Eidos File, open the add-table menu and choose **Import CSV**.
3. Select the CSV file.
4. Review the table name, Record Label Field, and inferred field types.
5. Start the import.

**Check:** compare the imported row count and a few values with the source.
Pay particular attention to dates, empty values, and codes with leading zeros.
Use Text for a code such as `00127` if its zeros must be preserved.

CSV import does not infer a Select field's create-time default.
Review imported empty values before continuing.

## Choose an export scope

| What you need | Operation | Result |
| --- | --- | --- |
| A report from the current view | Export Current View to CSV | The view's selected records and displayed fields |
| All records and fields in a table | Export Entire Table to CSV | Table data without the view's filter |

Open the relevant view or table menu to export. Open the resulting CSV and
check the headers and row count before sending it to someone else.

## Know what CSV leaves out

CSV stores flat values. It does not preserve the complete Eidos schema,
saved layouts, formulas as working field definitions, relations, or attachment
files. Exporting a CSV is not a complete backup.

To preserve your work, follow [data storage and backups](/user-guide/data-safety/).
To refine a report first, see [views and filters](/user-guide/views-and-querying/).
