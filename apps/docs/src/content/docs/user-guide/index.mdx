Eidos Lite opens a local folder as a **Space**. Keep your `.eidos` files,
Markdown notes, and attachments together, and work offline without signing in.
Eidos File stores structured data in portable SQLite-backed files; Lite
provides folder navigation, local Graft history, and optional Sync.

## Learn by making a book list

[Install and open a Space](/getting-started/eidos-lite/), then
[create your first table](/user-guide/eidos-file-basics/).
The walkthrough introduces fields, records, and views with one example.
