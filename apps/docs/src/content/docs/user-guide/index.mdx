Eidos stores structured data in `.eidos` files. The Web Editor opens one file
in the browser, CLI Serve opens one local file, and Eidos Lite manages files in
an ordinary folder.

## Files and applications

Your data is stored in the `.eidos` file. An application may keep a temporary
working or recovery copy while you edit, so check its save state before closing
the file.
