**Eidos Lite** is a focused desktop application that brings structured data management, versatile views, and notes to the folders on your computer.

A Space is an ordinary local folder where you can freely mix `.eidos` tables, Markdown notes, images, and everyday documents. Everyday use requires no account and works seamlessly offline.
