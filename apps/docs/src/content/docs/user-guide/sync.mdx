Eidos Sync keeps a Space available across your own devices. Each device still has an ordinary
local folder, so you can open and edit it without a network connection.

:::note
Sync is in a limited preview. Joining the waitlist does not grant access immediately; check the
account page for your current access.
:::

## Sync a Space for the first time

1. Open the Space you want to sync.
2. Go to **Settings → Account & Services** and sign in to your Eidos account.
3. Enable local versioning, then save a version in **Changes**.
4. Select **Sync** in the title bar.
5. Review what will be synced, then confirm the connection.

When the first upload finishes, the Space appears in your account's list of synced Spaces.

Sync includes the whole Space, not only the `.eidos` file currently open. Move anything you do
not want to upload out of the Space before confirming.

## Continue on another device

1. Install Eidos Lite and sign in with the same account.
2. Open **Sync** and choose the existing Space.
3. Choose an empty folder for the local copy.
4. Wait for the download to finish, then open the Space.

The downloaded Space works like any other local folder. You can edit it offline and sync saved
versions when you are online again.

## Sync new changes

When a set of changes is ready, save a version in **Changes**. Only saved versions sync; unsaved
changes remain on the current device.

Open **Sync** to check the current state. If it shows **Waiting to sync** or **Try again later**, you
can keep using the local files while Eidos waits for the connection to recover.

## If the same content changed on two devices

Eidos pauses before replacing either side and lists the conflicts in **Changes**.

Resolve each item, save the merged version, then sync again. If you are not ready to decide, leave
the conflict unresolved; the original local files will not be replaced.

## Troubleshooting

**Sync access is required**

Open **Settings → Account & Services** to check your access. Joining the waitlist is not the same
as having access.

**Save a version first**

Open **Changes**, save the current work, then sync again.

**The first sync cannot continue**

Follow the check results, move unsupported or unwanted files out of the Space, and retry.

Sync helps you continue across devices; it is not a replacement for regular backups. For local
versions and recovery options, see [History and recovery](/user-guide/history-and-sync/).
