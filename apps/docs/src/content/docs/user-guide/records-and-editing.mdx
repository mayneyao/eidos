A record is one item in a table. The same record can appear as a Grid row,
a Gallery card, or an item in another view.

## Change a value

1. Select a cell in Grid.
2. Press **Enter** or double-click to edit.
3. Enter the new value and commit the edit.
4. Check the displayed value.

Use **Escape** to cancel the current cell edit. Use **Tab** and **Shift + Tab**
to move between cells. A calculated field, such as Formula or Lookup, cannot
be edited directly; change its inputs instead.

## Add a record

Use **Add record**, or **Cmd + Enter** on macOS and **Ctrl + Enter** on
Windows/Linux in Grid. Enter a recognizable title in the Record Label Field.

If a new record is missing from the current view, check the view's filters.
The record may not match them.

## Paste a block of cells

Copy rows and columns from a spreadsheet. Select the destination cell and
paste. Check that the columns align and that dates and numbers have the
intended values. For a whole dataset, use [CSV import](/user-guide/import-and-export/).

## Read a long record

Use the row's expand control to open its details.
This gives long text, relations, and attachments more room than a Grid cell.

## Link to another record

1. Open a Relation cell.
2. Search for a record in the target table.
3. Select the record to link it.

The relation stores the record's ID. The displayed label comes from the
target table's Record Label Field. Renaming that label does not break the link.

## Add attachments

Use a File field to add an attachment. Available import and preview controls
depend on the app that opened the Eidos File.
When moving the data, include referenced local attachments.
See [data storage](/user-guide/data-safety/).

## Undo an edit

Use **Cmd + Z** on macOS or **Ctrl + Z** on Windows/Linux for edits supported
by the active editor's undo history. Check the result after undoing.
For older saved states, use [Versions](/user-guide/history-and-recovery/);
undo is not a substitute for a backup.
