A saved table view stores how to select and display records.
Use separate views for recurring tasks, such as **Reading now** or **Finished books**.

## Try the difference between hiding and editing

1. Turn on **Show unfinished only**. One record disappears.
2. Switch to **Gallery**. The same two records appear as cards.
3. Mark a visible book as **Finished**. It no longer matches the filter.
4. Clear the filter. All three records are still there.

This example illustrates the relationship between data and a view.
It is not connected to an Eidos File.

## Choose a layout for the task

| Layout | Use it to | Configure |
| --- | --- | --- |
| Grid | Compare fields and edit rows | Field order, widths, visibility |
| Gallery | Browse records as cards | Card content and cover field |
| Kanban | Group records by a state | A single-select grouping field |
| Calendar | See records by date | A Date or Date & time field |
| Form | Enter a new record | Questions and submission settings |
| Feed | Read records in a stream | Fields to display |

For layout contracts, see [Standard Views](/specifications/standard-views-1-0/).
For plugin development, **page** and **file** are the two View kinds;
they describe where a plugin opens. See [plugin concepts](/plugins/concepts/).

## Search for a quick lookup

Use **Search** to find a title or keyword. Clear the search to return to the
saved view's results. Save a filter when you need the same selection repeatedly.

## Combine filters

Open **Filter**. Choose how to combine conditions:

| Rule | Example | Result |
| --- | --- | --- |
| ALL (AND) | Status is Reading AND Rating is 5 | Only books satisfying both |
| ANY (OR) | Status is Reading OR Rating is 5 | Books satisfying either |

A record that fails the filter remains in the table.
When a date filter is relative, its results can change as the date changes.

## Sort results

Open **Sort** and add rules in priority order.
For example, sort by Status first, then by Title.
The second rule orders records with the same value for the first.

## Show the fields you need

Open **Fields** to change visibility and field order.
Hiding a field does not delete its values. For card layouts, configure card
content and the cover separately. A hidden field is not shown on the card.
