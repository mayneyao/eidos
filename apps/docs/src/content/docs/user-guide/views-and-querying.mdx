A **View** is a saved, tailored perspective on the exact same underlying table. Instead of duplicating records, you can create distinct views for specific daily workflows—such as "My Open Tasks", "High Priority", or "Weekly Archive".

Editing a record in one view updates all other views immediately.

---

## 1. Four Core View Types

Click the **+** button in the view bar to add a new view and switch between formats effortlessly:

| View Type | Best Used For | Key Features & Interaction |
| :--- | :--- | :--- |
| **Grid** | High-density data comparison, mass entry, bulk edits | Browse all columns just like a classic spreadsheet; freely resize and reorder columns. |
| **Kanban** | Workflow pipelines, stage tracking, project tasks | Cards are grouped into columns by single-select fields (e.g. "Status"); drag cards across columns to advance progress. |
| **Gallery** | Visual asset catalogs, portfolios, movie posters | Set cover images to an attachment field for a rich card wall. |
| **Calendar** | Milestones, publishing schedules, event deadlines | Plot records onto a clean monthly or weekly calendar by any date field. Click any day cell to add a new event on that date. |

:::tip[Temporary Search vs Saved Views]
- **Top Search Bar**: Perfect for quick, ephemeral lookups (e.g. finding a specific name or keyword). Clearing the search box restores the full saved view instantly.
- **Saved Views**: When you configure recurring filters (e.g. "Status = In Progress AND Priority = High"), sorting rules, or hidden columns, these settings are **permanently saved** to the current view.
:::

---

## 2. Powerful Compound Filters

Click the **Filter** button in the toolbar to craft precise queries:

- **Filter Conditions**:
  - **Match ALL conditions (AND)**: Records must satisfy every rule simultaneously.
  - **Match ANY condition (OR)**: Records matching at least one rule are displayed.
- **Dynamic Relative Dates**:
  - Date fields support dynamic relative filtering: **is Today**, **is This Week**, **in the Past 7 Days**, or **in the Next Month**.
  - Once saved, the view shifts automatically with the real-world calendar—giving you an up-to-date queue every morning without manual date adjustments.

---

## 3. Multi-Level Sorting

Click the **Sort** button in the toolbar to organize records:

- Add multiple sorting criteria in priority order. For example: first sort by **Due Date (Ascending)**, and for tasks due on the exact same day, secondary sort by **Priority (Descending)**.
- Easily toggle between ascending and descending orders, or drag sorting rules to adjust their priority.

---

## 4. Column Visibility & Card Customization

To keep views focused and clutter-free, open the **Fields** menu:

- **Toggle Visibility**: Hide auxiliary columns that are not relevant to the current task. Hiding a column only affects display in that view and never deletes data.
- **Card Badges & Cover Aspect Ratio**: In Kanban and Gallery views, choose exactly which property badges show up on the front of cards (e.g. Assignee avatar, tags, and due date), and choose the ideal card cover aspect ratio.
