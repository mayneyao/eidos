By the end of this guide, `books.eidos` will contain a book list and a saved
view of books you are reading.

Start with an open Eidos File in [Lite](/getting-started/eidos-lite/),
the [Web Editor](/getting-started/browser/), or [CLI Serve](/getting-started/cli/).

## 1. Create the table

Create a table named **Books**. Use a Text field named **Title** as its
Record Label Field. Eidos uses this field as the displayed name of each book.

Add a Select field named **Status**, with the options **To read**, **Reading**,
and **Finished**.

| Field | Type | Purpose |
| --- | --- | --- |
| Title | Text | Name of the book; Record Label Field |
| Status | Select | One reading state |

## 2. Add records

Add three records. Enter the title and choose the status for each.

| Title | Status |
| --- | --- |
| The Little Prince | Reading |
| A Room of One's Own | Finished |
| Walden | To read |

**Check:** Books contains three records. Each record describes one book.

## 3. Save a reading view

Add a Grid view named **Reading now**. Open **Filter** and add
`Status = Reading`.

**Check:** the view shows **The Little Prince**. The other two records are
still in Books. Clear the filter to see them.

## 4. Try a different layout

Create a Gallery view to see books as cards. Changing a book's Status there
changes the same record you see in Grid.

This small example uses a Finished checkbox to show the relationship.
Its changes stay on this page and reset when you reload.

## 5. Check saving

In Lite and CLI Serve, committed edits write to the local file.
In the Web Editor, check the save state and use **Save**, **Save As**, or
**Download a copy**, as available.

When moving `books.eidos`, include any local files its attachment fields
reference. [Learn what to back up](/user-guide/data-safety/).
