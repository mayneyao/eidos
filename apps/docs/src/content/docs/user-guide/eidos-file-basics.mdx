Follow this walkthrough to create a book list in `books.eidos` with a saved view.

Open an Eidos File in [Lite](/getting-started/eidos-lite/),
the [Web Editor](/getting-started/browser/), or [CLI Serve](/getting-started/cli/).

## 1. Create the table

Create a table named **Books**.
Use a Text field named **Title** as its Record Label Field.
Eidos uses this field as the primary label for each book record.

Add a Select field named **Status**.
Add three options: **To read**, **Reading**, and **Finished**.

| Field  | Type   | Purpose                               |
| ------ | ------ | ------------------------------------- |
| Title  | Text   | Name of the book (Record Label Field) |
| Status | Select | Current reading state                 |

## 2. Add records

Add three records. Enter the title and select the status for each book.

| Title               | Status   |
| ------------------- | -------- |
| The Little Prince   | Reading  |
| A Room of One's Own | Finished |
| Walden              | To read  |

**Check:** The table contains three records. Each record describes one book.

## 3. Save a reading view

Add a Grid view named **Reading now**.
Open **Filter** and add `Status = Reading`.

**Check:** The view shows **The Little Prince**.
The other two records remain in the Books table.
Clear the filter to show them again.

## 4. Change the view layout

Create a Gallery view to show books as cards.
Changing a book's Status in Gallery updates the same record in the Grid view.

## 5. Check your file

In Lite and CLI Serve, committed edits write directly to the local file.
In the Web Editor, check the save status.
Use **Save**, **Save As**, or **Download a copy** to preserve your work.

When you copy or move `books.eidos`, include any local attachment files.
Read [what to back up](/user-guide/data-safety/).
