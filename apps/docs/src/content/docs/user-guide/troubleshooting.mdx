## 1. Frequently Encountered Questions

### "File is in use or locked"
- **Cause**: Another window, an external SQLite utility, or a backup tool holds an exclusive lock on that `.eidos` file.
- **Solution**: Close any external programs or duplicate windows accessing the file, wait two seconds, and re-open it in Eidos Lite.

### Space folder or file cannot be opened
- **Check Paths & Permissions**: Verify that the folder has not been moved, renamed, or trashed in your operating system's file manager.
- **Valid File Format**: `.eidos` files contain specialized database schemas. Renaming an arbitrary blank text file to `.eidos` will not make it readable.

### "Please save current changes first" when restoring or syncing
- **Solution**: Click the clock icon in the top right to open Versions. Under **Changes**, click **Save version** (or discard temporary edits). Once saved, proceed with your restore or sync operation.

### Accidental deletion: how to recover lost files?
1. **Operating System Trash**: Files deleted from the Eidos Lite sidebar are sent to your operating system's Trash or Recycle Bin first. You can restore them from there.
2. **Restore from Versions**: If you have versioning enabled, click the clock icon, locate an earlier snapshot containing the file in **History**, and click restore.

## 2. Keyboard Shortcuts Cheat Sheet

| Shortcut (macOS) | Shortcut (Windows/Linux) | Action |
| :--- | :--- | :--- |
| <kbd>⌘</kbd> + <kbd>N</kbd> | <kbd>Ctrl</kbd> + <kbd>N</kbd> | Open New File dialog |
| <kbd>⌘</kbd> + <kbd>Enter</kbd> | <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Add new row below and begin editing |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Navigate to next / previous cell |
| <kbd>Space</kbd> | <kbd>Space</kbd> | Toggle checkbox in selected cell |
| <kbd>Esc</kbd> | <kbd>Esc</kbd> | Cancel cell editing and restore previous value |
| <kbd>⌘</kbd> + <kbd>Z</kbd> | <kbd>Ctrl</kbd> + <kbd>Z</kbd> | Undo last action |
| <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> | <kbd>Ctrl</kbd> + <kbd>Y</kbd> | Redo |

## 3. Diagnostics & Contacting Support

If you encounter an issue that cannot be resolved:

1. Open **Settings → About**.
2. Click **Copy diagnostics**.
3. If requested by the team, click **Show logs folder** to find detailed application logs.
4. Visit [GitHub Issues](https://github.com/mayneyao/eidos/issues) and submit your feedback along with the diagnostic snippet.
