title: Resolve a file problem

Start with the message shown by Eidos Lite. Use the matching case below.

## File is in use or locked

Close other windows or tools that write to the same file, then retry.
If the message remains, check whether another process still owns the file.
Do not delete lock or database sidecar files to bypass the message.

## A file or Space will not open

1. Check that the path still exists.
2. Check that your account can read and write the folder.
3. For an Eidos File, check that you created it as an Eidos File.

Renaming an arbitrary file to `.eidos` does not create the required schema.
If corruption damages the file, save a copy before you attempt repairs.

## A record disappeared

Clear temporary search and check the view filters.
An edit can cause a record to stop matching the current view.
Check another unfiltered view before you assume the record is gone.

## Restore or Sync asks you to save changes

Review current work in **Versions → Changes**.
Save a version when prompted, then retry the operation.
Do not discard changes unless you intend to lose them.

## Recover a deleted file

Check your operating system Trash or Recycle Bin.
If the file is not there, check for a version or independent backup that contains it.
Read the restore scope before you proceed. Restoring a Space affects more than
the selected file. See [version recovery](/user-guide/history-and-recovery/).

## Collect diagnostics

For LAN sync problems, first use the checks below. For other problems or a
sync failure that persists, collect diagnostics from the computer:

1. Open **Settings → About**.
2. Select **Copy diagnostics**.
3. Record the steps that caused the problem and the message shown.
4. Submit an issue on [GitHub](https://github.com/mayneyao/eidos/issues).

If you need log files, select **Show logs folder**. Check diagnostics and logs for
private paths or content before sharing them.

For editing keys, see [everyday editing](/user-guide/records-and-editing/).

## LAN sync cannot connect or find a Space

1. Check that the phone and computer use the same reachable local network,
   Eidos Lite is running, and the phone app is in the foreground. Check the
   operating system local-network permission and firewall access for Eidos Lite.
   Guest Wi-Fi or client isolation can prevent devices from reaching one another.
2. On the computer, check **Settings → Devices → 局域网服务**. Then check that
   you enable the intended Space in **Sync → 局域网同步**. Pairing alone does
   not make a Space available. Restart requires you to enable sharing again.
3. On the phone, select the intended computer and select **刷新设备状态**
   (Refresh device status) in the menu. An online computer can still keep
   sharing turned off for that Space.
4. If pairing waits for approval, check the computer dialog or
   **Settings → Devices**. If a code expires, generate a new one. If camera
   access is unavailable, use the copied pairing code.

## A LAN download times out or fails validation

Keep the source Space on the computer and any existing phone copy. Check the
connection and retry from the phone Sync page. A partial first download is
not a complete local Space. Do not bypass validation or delete database,
history, or lock files to force the Space open.

If the operation fails again, record the exact message, the file and stage shown, the
direction of transfer, both app versions, and whether this was the first
download or a later sync. Include the elapsed time and transferred bytes for
a stall, along with the computer diagnostics described above. An online
indicator or a byte counter is not proof of a completed sync.

If the phone asks you to resolve a conflict on the computer, open the computer
**Sync** panel, check the conflict, and sync from the phone again after you resolve
it. See the [sync guide](/user-guide/sync/).
