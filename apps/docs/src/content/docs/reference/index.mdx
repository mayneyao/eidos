Reference pages describe contracts rather than tutorials. Each stable API page
will include availability, permissions, inputs, outputs, errors, and a complete
example.

## Available now

- [Extension manifest schema](/schemas/extension-manifest.schema.json) — a
  machine-readable **design preview** of the file-based package manifest.
- [Extension surface protocol](/reference/extension-surface-protocol/) — the
  executable P3a text-document and transport contract for custom UI.
- [Build with Eidos File UI](/reference/eidos-file-ui-package/) — the proposed public
  package API: Grid by default, opt-in Gallery/Kanban, and custom view plugins.
- [Eidos File format and custom views](/reference/eidos-file-custom-views/) — the `.eidos`
  metadata, runtime adapter, built-in renderers, and trusted custom view API.
- [`llms.txt`](/llms.txt) — the canonical documentation map for agents.
- [`llms-full.txt`](/llms-full.txt) — a compact extension development contract.
