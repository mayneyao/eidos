## Specifications

- [Eidos File 1.0 suite](https://github.com/mayneyao/eidos/tree/dev/docs/specs)
  defines the canonical File Format, Runtime, Adapter, and UI contracts.
- [Eidos File format and custom views](/reference/eidos-file-custom-views/)
  describes `.eidos` metadata, Runtime adapters, built-in views, and trusted UI
  view plugins.
- [Build with Eidos File UI](/reference/eidos-file-ui-package/) documents the
  published React package shared by first-party hosts.

English specification files are normative. Chinese files are informative
translations and do not override the English contract.
