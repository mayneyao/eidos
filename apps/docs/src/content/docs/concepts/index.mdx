Before diving into Eidos Lite, understanding these core concepts will help you effortlessly build personal databases, notes, and workflows.

---

## 1. Space (Your Workspace)

**A Space is simply an ordinary local folder on your computer.**

- **Never proprietary**: Eidos Lite does not trap your files inside a locked database. You can open and inspect this folder in your operating system (Finder or File Explorer) at any time.
- **Mix and match**: In the same Space, you can store `.eidos` database files, Markdown notes, PDFs, images, and other everyday files side by side.
- **Portable**: You can move or copy your Space folder to an external SSD, USB drive, or cloud backup, and everything remains completely intact.

---

## 2. Eidos File (`.eidos` Documents)

**An `.eidos` file is a lightweight, self-contained structured document.**

- **Single-file portability**: Each `.eidos` file packages your tables, field definitions, records, and view layouts into a single standalone file.
- **Offline first, instant response**: Open and edit thousands of records locally in milliseconds, with zero network lag and no mandatory sign-in.
- **Easy sharing**: Just like sharing a regular spreadsheet or text document, you can email or transfer an `.eidos` file to a colleague, who can open it immediately with all views and layouts preserved.

---

## 3. Multiple Views

**Inspect the exact same data from different perspectives.**

In traditional tools, creating a board or gallery often requires duplicating data. In Eidos:

- **Table Grid**: Designed for high-density editing, rapid data entry, and multi-column comparisons.
- **Kanban Board**: Group records into visual columns by single-select fields (e.g. "To Do", "In Progress", "Done") with drag-and-drop status updates.
- **Card Gallery**: Feature cover images or attachment thumbnails to build a visual card showcase.
- **Calendar**: Plot dates and milestones directly onto a clean monthly or weekly calendar.

All views point to the exact same underlying records. Edits made in one view update across all other views in real time, with **zero duplicated copies**.

---

## 4. Local-First & Data Ownership

**Your data stays strictly under your control.**

- **Always usable offline**: You don't need to create an account or connect to a cloud service for everyday use.
- **Built-in version history**: Snapshots let you travel back in time to any previous state without needing an account.
- **Optional cloud superpowers**: When you need to work across multiple laptops, enable Sync. When you want to share a note or form with others, publish it as a live web page with one click.
