## Eidos File

An Eidos File is a physical SQLite file with canonical metadata and data
objects. The Runtime maps those objects to typed tables, fields, records, and
views. Hosts must not reinterpret those semantics.

## Space

In Eidos Lite, a Space is an ordinary folder the user opens. It may contain
multiple `.eidos` files and other normal files. Eidos does not replace it with
a proprietary container.

## Runtime and hosts

The portable Runtime owns query, Formula, Lookup, Relation, conversion,
revision, and validation meaning. Browser, desktop, and CLI adapters supply
SQLite connections and platform capabilities without changing those results.

## Shared UI

`@eidos.space/eidos-file-ui` provides the editor used by Eidos File Web, Eidos
Lite, and `eidos serve`. Grid, Gallery, Kanban, record editing, query controls,
and semantic theme tokens are shared implementations rather than host forks.

## Version history and Sync

Eidos Lite uses Graft for local Space history and an optional authenticated
remote. Versioning and Sync do not define whether local files are readable:
files remain available while offline or signed out.
