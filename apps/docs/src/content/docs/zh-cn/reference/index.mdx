参考页面描述的是契约，而不是教程。每一个稳定 API 页面都会包含可用状态、权限、输入、输出、
错误以及完整示例。

## 当前提供

- [Extension Manifest Schema](/schemas/extension-manifest.schema.json)：file-based package manifest
  的机器可读 **Design preview**。
- [Extension surface protocol](/zh-cn/reference/extension-surface-protocol/)：custom UI 的可执行 P3a
  text-document 与 transport contract。
- [`llms.txt`](/llms.txt)：面向 Agent 的规范文档导航。
- [`llms-full.txt`](/llms-full.txt)：紧凑的扩展开发契约。

## 随运行时补齐

- Stable Extension SDK availability 和 capability error
- Contribution point reference
- Space path 与文件操作语义
- Base view contract
- 兼容性和 runtime ABI policy
