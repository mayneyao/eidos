`@eidos.space/extension-sdk` 是第三方 file-based extension 唯一支持的 TypeScript contract。它不会暴露
旧版 `DataSpace`、Electron、Node.js、SQLite 或 raw filesystem API。

SDK 当前处于 experimental developer preview。Version 1 包含 command worker context，以及独立的 text
file editor UI context。Storage、secret、network access、Base view 和 agent tool 仍不在可执行边界内。

Extension source 中的 SDK import 是 type-only。固定 compiler 会移除它，并拒绝任意 bare-module import；
runtime context 始终由宿主构造。

## Worker context

```ts
import type { ExtensionContext } from "@eidos.space/extension-sdk"

export function activate(context: ExtensionContext) {
  context.subscriptions.add(
    context.commands.register("example.package.command", async (resource) => {
      const text = await context.space.files.readText(resource.path)
      context.window.showNotice(`${text.length} characters`)
    })
  )
}
```

| Namespace               | 当前操作                                   | Enforcement                                              |
| ----------------------- | ------------------------------------------ | -------------------------------------------------------- |
| `context.commands`      | 注册同一 package Manifest 中声明的 command | 未声明 ID 会让 activation 失败                           |
| `context.space.files`   | `readText(path)`                           | 需要当前有效且匹配的 `files.read` grant                  |
| `context.window`        | `showNotice`、`confirm`、`select`          | 宿主校验并渲染 semantic UI                               |
| `context.subscriptions` | 管理 disposable                            | stop、update、disable 或 stale generation 时统一 dispose |

Worker `activate()` 是 lazy 的。安装或发现 package 不会启动 worker。Worker 绑定 inspected content digest
与 effective grant；任何一项改变都会终止旧 generation。

## File editor context

包含 `entrypoints.ui` 与匹配 `fileEditors` contribution 的 package 导出：

```ts
import type { ExtensionFileEditorContext } from "@eidos.space/extension-sdk"

export function activate(context: ExtensionFileEditorContext) {
  context.root.textContent = context.document.snapshot.text
}
```

| Member                              | 含义                                                                  |
| ----------------------------------- | --------------------------------------------------------------------- |
| `extensionId`、`editorId`、`viewId` | 稳定 activation identity 与当前 surface instance                      |
| `root`                              | Package 唯一获得的 DOM mount point                                    |
| `document.snapshot`                 | 最新 immutable text、resource metadata、revision、dirty 与 undo state |
| `document.applyEdits()`             | 针对当前 revision 提交排序且不重叠的 UTF-16 edit                      |
| `document.save()`                   | 请求宿主持久化当前 revision                                           |
| `document.undo()` / `redo()`        | 操作共享的 host-owned document history                                |
| `document.resync()`                 | Local view stale 后请求一份新的完整 snapshot                          |
| `document.onDidChange()`            | 接收每个 view 产生的 minimal edit 或 replacement snapshot             |
| `document.onDidChangeState()`       | 接收 dirty、saved baseline、conflict 与 undo-state 变化               |
| `document.onDidChangeSaveState()`   | 接收 saving、saved 与 error transition                                |
| `appearance.current`                | 已解析 locale、color scheme 与稳定 theme token                        |
| `capabilities`                      | 经过本地 grant 后生效的 editable/save/undo 与 autosave policy         |
| `subscriptions`                     | 随 surface generation 一起 dispose 的 listener                        |

Document API 返回宿主接受的 revision number，永远不返回 file handle。Surface 必须应用每一条 host
broadcast，包括 attribution 指向当前 view 的 edit，因为宿主才是权威状态。

精确 serializable message 定义在
[surface protocol](/zh-cn/reference/extension-surface-protocol/)。

## Appearance token

Runtime 会把 `appearance.current.theme` 映射为 CSS custom property：

```css
var(--eidos-color-background)
var(--eidos-color-foreground)
var(--eidos-color-muted-background)
var(--eidos-color-muted-foreground)
var(--eidos-color-border)
var(--eidos-color-accent)
var(--eidos-color-accent-foreground)
var(--eidos-color-destructive)
var(--eidos-color-destructive-foreground)
var(--eidos-color-focus-ring)
var(--eidos-font-family)
var(--eidos-font-family-mono)
```

这些是解析后的宿主 token，不是 class name。Appearance 改变时宿主会更新变量，surface 不需要访问 Eidos
内部实现。

## Error contract

Worker failure 使用 `CAPABILITY_DENIED`、`RUNTIME_STALE`、`RUNTIME_TIMEOUT`、
`RUNTIME_COMMAND_FAILED` 等 code。

File-editor document request 可能以 `INVALID_EDIT`、`STALE_REVISION`、`READ_ONLY`、`CONFLICT`、
`RUNTIME_STALE`、`SAVE_FAILED` 或 `NOT_AVAILABLE` 拒绝。它们是 runtime state，不能作为绕过 SDK 的理由。
收到 `STALE_REVISION` 后，应先应用 pending broadcast 或调用 `resync()`，再重试。
