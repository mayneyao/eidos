`eidos` CLI 读写本地 `.eidos` 文件，不依赖 Eidos Lite 或后台服务。
还没有安装时，先按[安装指南](/zh-cn/getting-started/cli/)操作。

## 检查、查询、验证

对于已有的 `tracker.eidos` 文件及其 Tasks 表：

```bash
eidos file inspect tracker.eidos
eidos data query tracker.eidos Tasks --fields Title,Status --limit 50
eidos file validate tracker.eidos --level full
```

第一个命令描述文件，第二个返回最多 50 条记录，
第三个按 full 级别验证文件。使用时换成自己的文件路径和表名。

## 按任务选择命令组

| 任务 | 命令组 |
| --- | --- |
| 创建、检查、验证或修复文件 | `eidos file` |
| 管理表、字段和视图 | `eidos schema` |
| 查询或修改记录与附件 | `eidos data` |
| 打开本地网页编辑器 | `eidos serve` |
| 登录、发布或收集提交 | `eidos cloud` |
| 管理本地插件包 | `eidos plugin` |
| 更新 CLI 或安装智能体技能 | `eidos self` |

运行 `eidos --help` 查看命令列表。
在命令组后添加 `--help` 查看选项。

## 给脚本返回数据

使用 `--json` 获取机器可读结果：

```bash
eidos --json data query tracker.eidos Tasks --fields Title,Status --limit 50
```

使用结果前先检查退出状态。
写入时，[读取上下文、检查 revision 后应用改动，再验证](/zh-cn/cli/automation-workflow/)。
不要让脚本解析面向人的文本输出。

## 配置智能体

将内置 Eidos Skill 安装到当前项目：

```bash
eidos self skill init
```

使用 `--global` 安装到当前用户，或用 `--space <DIR>` 指定其他项目。
除非明确使用 `--force`，初始化命令不会替换已被修改的技能文件。
安装后开启新的智能体任务。

## 添加本地插件

```bash
eidos plugin list
eidos plugin install ./my-plugin.eidos-plugin
```

使用 `eidos plugin remove <PLUGIN_ID>` 移除已安装的插件包。
开发插件请按[文本阅读器教程](/zh-cn/plugins/guide/)操作。
