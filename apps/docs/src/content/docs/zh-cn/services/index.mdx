Eidos 是一款**本地优先 (Local-First)** 的应用——你的数据完全存储在自己的设备上，无需依赖任何云服务即可使用。这带来了极佳的隐私保护和数据所有权，但本地优先的设计也有其天然的局限：

- **你的电脑必须开着**，外部服务才能向 Eidos 推送数据
- **你的数据只在一台设备上**，无法在多台电脑之间同步
- **你的内容是私有的**，无法直接分享给他人

**Eidos 服务**是一组可选的云端增强功能，专门用来弥补这些局限。它们完全遵循 Eidos 的设计哲学：即使不使用任何服务，Eidos 依然完整好用；而当你需要时，这些服务可以无缝扩展你的能力。
