使用自己的域名访问已发布的页面。例如，`your-name.eidos.ink/notes`
也可以通过 `notes.example.com/notes` 打开。
Publish Pro **每个账户包含 1 个自定义主机名**，并自动配置 HTTPS。
域名注册费用另计。

## 开始前准备

- 保持 Publish Pro 方案有效。
- 确认你可以编辑域名的 DNS 记录。
- 选择一个主机名，例如 `notes.example.com` 或 `example.com`。
- 先发布一个页面，保留现有的 `eidos.ink` 链接以便对照。

一个主机名承载该 Publish 账户下的所有发布内容，并沿用各自的路径。
接入域名不会在 `/` 自动创建主页或目录。
例如，原来发布在 `/notes` 的页面，接入后仍使用 `/notes`。
根域名与 `www` 是两个不同的主机名，不会自动添加 `www`。

如果该主机名已有其他网站，修改流量记录会替换原网站入口。
请先保存原有 DNS 配置。
DNS 变更可能需要几分钟或更久才能对访客生效，切换期间可能短暂无法访问。

## 添加域名

1. 打开[账户 → Publish](https://eidos.space/zh/account?tab=publish)。
2. 选择**概览**，找到**自有域名**。
3. 输入主机名，不要包含 `https://`、路径或端口。
4. 选择**添加域名**。

账户页会显示本次绑定所需的 DNS 记录。
请从该页面复制实际值，验证值因域名而异。

## 配置 DNS

以 `notes.example.com` 为例，记录格式如下：

| 类型  | 名称                                | 值                    | 用途                   |
| ----- | ----------------------------------- | --------------------- | ---------------------- |
| TXT   | `_eidos-publish.notes.example.com`  | 账户页显示的值        | 验证域名管理权限       |
| CNAME | `_acme-challenge.notes.example.com` | 账户页显示的委托目标  | 签发与续期 HTTPS 证书  |
| CNAME | `notes.example.com`                 | `customers.eidos.ink` | 将访客流量指向 Publish |

如果账户页还显示其他证书或主机名验证记录，也需要添加，
例如按提示添加 `_cf-custom-hostname` TXT 记录。
部分 DNS 服务商会自动补全域名后缀，请检查最终的完整记录名，避免域名重复。

激活后也要保留所有权 TXT 和证书验证记录。
Publish 会定期复验所有权，HTTPS 证书续期也需要这些验证记录。
请保留无关的邮箱及其他 DNS 记录。

### 使用 Cloudflare DNS

将流量 CNAME 设置为**仅 DNS**（灰云）。
证书验证 CNAME 也使用**仅 DNS**。
此接入方式不包含客户域名侧的 Cloudflare 代理。

接入根域名时，流量记录名称填 `@`，目标填 `customers.eidos.ink`。
已验证的根域名接入方式是 Cloudflare 的根 CNAME flattening。
其他 DNS 服务商需要兼容的 flattening 或 ALIAS 支持，普通根域名 CNAME 无法接入。
不要将解析得到的 Eidos IP 地址填入 A 或 AAAA 记录来代替。

## 检测并激活

1. 回到**自有域名**。
2. 选择**检测 DNS 和证书**。
3. 如果仍在等待 DNS 或证书，核对显示的记录，等待解析生效后再次检测。
4. 状态变为**可以激活**时，选择**激活**。
5. 等待显示**已启用**，再用自有域名打开一个已知的发布路径。

**检查结果：** 分别打开 `https://notes.example.com/notes` 和原来的
`https://your-name.eidos.ink/notes`，两者应显示同一份发布内容。
如果使用密码保护或表单，也请检查对应页面。
首次访问新域名时，可能需要重新输入页面密码或登录。

激活后，账户页和新的发布结果会优先使用自定义域名。
原有 `eidos.ink` 链接继续可用，无需仅为接入域名而重新发布内容。
文件、附件、表单和访问权限沿用原有路径与行为。

## 保留或移除域名

请保持 Pro 有效，并保留所有必需的 DNS 记录。
如果所有权验证、DNS、HTTPS 或 Pro 权限失效，自定义域名可能停止提供访问。
恢复相应条件后，可通过**检测 DNS 和证书**检查状态。

如需断开连接，选择**移除**并确认。此操作停止自定义域名访问，但不会删除发布内容。
Pro 到期后仍可移除域名。添加其他主机名前，需要先移除旧绑定。
如需将域名用于其他网站，请在 DNS 服务商处修改流量记录。

## 故障排查

**等待 DNS 配置：** 对照账户页逐条核对记录，检查是否重复添加了域名后缀、
流量记录是否冲突，以及 CNAME 是否启用了代理。

**等待证书：** 保留证书委托 CNAME 和页面显示的其他验证记录。
已有的 CAA 限制或 DNSSEC 问题可能阻止证书签发，请向 DNS 服务商检查。

**根路径没有页面：** 打开具体发布路径，例如 `/notes`。
接入主机名不会在 `/` 自动创建主页。

**页面内的旧链接仍指向其他域名：** 域名接入不会改写你在内容中写入的网址。
如需修改，请编辑内容后重新发布。

发布与更新内容的操作请参阅[分享发布副本](/zh-cn/user-guide/publishing/)
或[使用 CLI 发布](/zh-cn/cli/publish/)。
