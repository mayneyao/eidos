插件为 Eidos 添加界面或操作。
例如，开发文本文件阅读器、项目概览页面，或处理选中记录的命令。

## 选择 View 从哪里打开

| View 种类 | 入口 | 示例 |
| --- | --- | --- |
| `page` | 侧边栏导航 | 项目概览 |
| `file` | 文件，或 Eidos File 内的表 | 文本阅读器、表数据可视化 |

page 独立打开，file View 接收它绑定的文件。
这是两种 View 种类。
插件也可以提供命令、快捷键和文档格式化。
主题包为 Lite 提供浅色与深色配色。

## 做一个能运行的例子

按[创建第一个插件](/zh-cn/plugins/guide/)操作。
你将声明一个文本阅读器，在 Lite 中加载源码，
并检查文件变化后阅读器是否更新。

接着阅读[插件概念](/zh-cn/plugins/concepts/)，理解数据访问和生命周期。
方法和类型的具体定义见 [API 参考](/zh-cn/plugins/api/)。

## 安装插件包

1. 通过 Lite 的 Plugin Manager 安装 `.eidos-plugin` 包。
2. 检查它请求的权限。
3. 为当前 Space 启用插件。
4. 从它声明的入口打开。

file View 出现在 **Open with** 中，page View 出现在导航中。
命令使用声明的入口，例如命令面板。

每个 Space 分别保存插件启用状态和设置。
主题作用于整个 Eidos Lite。
准备分享时，按[开发与分发](/zh-cn/plugins/workflow/)打包。
