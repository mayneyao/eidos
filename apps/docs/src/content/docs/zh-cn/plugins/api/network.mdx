network.read 向 browser.networkOrigins 执行有界的匿名 HTTPS 读取，与 background 的 fetch/WebSocket 分开。需要凭据的请求应声明 connections，由用户在宿主配置凭据。View 和普通命令可以使用 connections，命令调用结束时会取消其请求。

使用指南: [services](/zh-cn/plugins/services/). [API 索引](/zh-cn/plugins/api/).

签名、参数及返回类型从 SDK 自动生成；可选成员不保证在每个宿主和上下文中存在。

### PluginNetwork.read

读取已授权的 HTTPS 地址，可请求指定字节范围。


```ts
read(request: {
    url: string;
    range?: {
        offset: number;
        length: number;
    };
}): Promise<{
    data: Uint8Array;
    status: number;
    etag?: string;
}>;
```

| 参数 | 类型 | 必填 |
| --- | --- | --- |
| `request` | `{     url: string;     range?: {         offset: number;         length: number;     }; }` | 是 |

返回值: `Promise<{     data: Uint8Array;     status: number;     etag?: string; }>`.
