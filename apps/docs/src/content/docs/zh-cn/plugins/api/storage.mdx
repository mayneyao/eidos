声明 storage.maxBytes。二进制对象是插件私有的本机数据，跨 View 和应用重启保留。不存在的键读取为 null，写入受声明配额和宿主限制。Lite API 3.11 可声明 storage.atomic: true，使用 readVersioned 和 compareAndWrite 跨窗口原子比较并替换字节；冲突不写入，应重读并重放本次编辑，不得覆盖旧的完整快照。

### PluginStorage.compareAndWrite

支持宿主: <Badge text="Lite" variant="note" />

Lite API 3.11，需声明 storage.atomic: true。在一次宿主操作中比较 expectedVersion 与当前令牌并替换字节。冲突返回 applied: false 和当前令牌，不写入；重试前应重读并重放本次编辑。仍受 4 MiB 单对象上限和插件声明配额限制。


```ts
compareAndWrite?(key: string, expectedVersion: string | null, data: Uint8Array): Promise<StorageWriteResult>;
```

| 参数 | 类型 | 必填 |
| --- | --- | --- |
| `key` | `string` | 是 |
| `expectedVersion` | `string &#124; null` | 是 |
| `data` | `Uint8Array` | 是 |

返回值: `Promise<StorageWriteResult>`.
