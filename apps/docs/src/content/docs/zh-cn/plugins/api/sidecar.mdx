### PluginSidecar.status

支持宿主: <Badge text="Lite" variant="note" />

仅查询：available 表示找到了程序，running 表示存在所属原生进程；均不保证协议就绪或程序版本兼容。不会执行、安装或弹出授权。


```ts
status(): Promise<SidecarStatus>;
```


返回值: `Promise<SidecarStatus>`.

### PluginSidecar.start

支持宿主: <Badge text="Lite" variant="note" />

核对按 Space、包修订及含参数的精确程序身份保存的授权，缺失或变化时请求审阅。安装或启用可审阅具体默认启动；覆盖须声明 configurable: true。不同的已有进程须先停止。待启动确认最多五分钟，随发起 View 取消；已启动后关闭 View 仅断开连接。成功仅表示系统启动程序，不代表协议就绪。


```ts
start(launch?: SidecarLaunch): Promise<void>;
```

| 参数 | 类型 | 必填 |
| --- | --- | --- |
| `launch` | `SidecarLaunch` | 否 |

返回值: `Promise<void>`.

### PluginSidecar.stop

支持宿主: <Badge text="Lite" variant="note" />

停止共享的所属进程树并等待退出，影响所有已连接 View。Stop 保留授权，禁用或卸载撤销授权。更新插件、离开 Space、关闭所属窗口或退出 Lite 也会停止进程；不会撤销已产生的原生修改。


```ts
stop(): Promise<void>;
```


返回值: `Promise<void>`.

### PluginSidecar.send

支持宿主: <Badge text="Lite" variant="note" />

写入一个 JSON 值并追加 LF。包含 LF 的单帧最多 1 MiB；含本次新帧的待写 stdin 最多 4 MiB。完成表示流写入完成，不表示收到原生协议回复。


```ts
send(data: BackgroundMessage): Promise<void>;
```

| 参数 | 类型 | 必填 |
| --- | --- | --- |
| `data` | `BackgroundMessage` | 是 |

返回值: `Promise<void>`.

### PluginSidecar.onEvent

支持宿主: <Badge text="Lite" variant="note" />

订阅不会启动进程，返回可释放监听器，关闭 View 时取消订阅。stdout 以 LF 分隔 JSON（接受 CRLF），单帧最多 1 MiB、每秒最多 16 MiB；stderr 每秒超出 1 MiB 的部分丢弃。非法输出会终止进程。Unicode 行分隔符仍是字符串内容。事件不重放，重新连接后应查询原生状态。


```ts
onEvent(listener: (event: SidecarEvent) => void): Promise<Disposable>;
```

| 参数 | 类型 | 必填 |
| --- | --- | --- |
| `listener` | `(event: SidecarEvent) => void` | 是 |

返回值: `Promise<Disposable>`.
