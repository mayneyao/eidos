声明用于申请能力，宿主负责校验和授权。apiVersion 是包协议版本，requires.pluginApi 是宿主 API 最低版本。access 默认为 read。Background 要求 Lite API 3.4，模板要求 3.2，hooks 要求 3.3，文件属性和目录树要求 3.1。

使用指南: [views](/zh-cn/plugins/views/). [API 索引](/zh-cn/plugins/api/).

签名、参数及返回类型从 SDK 自动生成；可选成员不保证在每个宿主和上下文中存在。

### PluginManifest.background

独立的 Worker 风格入口。network: true 经授权允许公网 HTTPS/WSS，可用最多八个精确 networkOrigins 收窄。bluetooth: true 授权选中设备，可用服务白名单限制。设备 ID 由宿主选择。API 3.6 支持 autoStart: true，经授权随 Space 打开自动启动；fileHistory: true 监听所属窗口和 Space 的文件打开元数据，不授予文件内容。


```ts
background?: {
    entry: string;
    network?: true;
    networkOrigins?: string[];
    bluetooth?: true | {
        services: BluetoothServicePermission[];
    };
    fileHistory?: true;
    autoStart?: true;
};
```
