Lite API 3.1。声明 workspace.filemeta.namespaces；patch 还需 filemeta.write 和贡献点的 write 权限。路径相对 Space。缺失命名空间返回空对象。patch 保留其他键；null 是值，remove 才删除键。数据上限 1 MiB，文件系统可能有更低限制。属性权限不包含文件内容写入。
