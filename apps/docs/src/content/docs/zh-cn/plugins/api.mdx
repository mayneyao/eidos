import { Badge } from "@astrojs/starlight/components"

API 使用 badge 标记支持宿主：<Badge text="Lite" variant="note" /> 表示 Eidos Lite，
<Badge text="Serve" variant="note" /> 表示 CLI Serve，
<Badge text="Mobile" variant="note" /> 表示 Android/iOS 插件宿主。
只显示支持的宿主，标记以具体成员为准；仍需满足声明、权限、最低 API 版本和调用上下文要求。
未标记的条目（如共享数据类型）不表示支持所有宿主。
