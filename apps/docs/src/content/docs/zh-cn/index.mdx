## 先看文件里有什么

**Eidos File** 是基于 SQLite 的开放结构化数据格式，提供可跨平台使用的
Runtime 和共享编辑器 UI。一个 `.eidos` 文件保存表、类型化字段、记录、关系和视图。
通过网页编辑器、面向智能体的 CLI 或 `eidos serve`，可以直接操作这个文件。

**Eidos Lite** 是桌面应用，用来打开包含 `.eidos` 文件、Markdown 笔记和
其他普通文件的本地文件夹。这个文件夹叫作 **Space**。
Lite 提供本地 Graft 历史和可选的 Sync。本地文件在离线或未登录时仍然可用。
