## 先看文件里有什么

**Eidos File** 是基于 SQLite 的文件格式，保存表、记录和视图。
**Eidos Lite** 是桌面应用，用来打开包含这些文件、笔记和其他文档的文件夹。
这个文件夹叫作 **Space**。
