## 先看文件里有什么

**Eidos File** 是基于 SQLite 的开放结构化数据格式。
一个 `.eidos` 文件保存表格、类型化字段、记录与已保存视图。
你可以在网页编辑器中打开该文件，使用 CLI 处理数据，或将其集成至应用程序中。

**Eidos Lite** 是管理本地文件夹的桌面应用。
该文件夹即为你的 **Space**。
Lite 将 `.eidos` 文件与 Markdown 笔记及附件一同保存。
Lite 提供本地版本历史与可选的同步功能。
所有本地文件均可在未登录与离线状态下正常使用。
