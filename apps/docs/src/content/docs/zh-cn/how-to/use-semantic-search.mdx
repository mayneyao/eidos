语义化搜索让你能够基于*含义*而非精确的关键词匹配来查找内容。通过将文本转换为向量嵌入，你可以使用自然语言查询（如"机器学习教程"）进行搜索，即使内容不包含这些确切词汇也能找到相关项目。

本指南介绍如何在文本字段上启用语义化搜索并使用它来搜索数据。我们将以 Hacker News 文章为例进行实践演示。

## 前提条件

1.  **Eidos 桌面版**：生成嵌入需要桌面应用。
2.  **AI 提供商**：在 **设置 → AI** 中配置嵌入模型。

## 设置

### 1. 在 Text 字段上启用嵌入

语义化搜索适用于任何 **Text** 字段。启用方法如下：

1. 打开你的表格
2. 点击 **Text** 字段标题 → **编辑属性**
3. 展开 **AI 增强** 部分
4. 开启 **启用嵌入**
5. （可选）开启 **颜色提示** 以查看向量化状态

<Aside type="note">
  如果你按照 [Hacker News
  导入指南](/zh-cn/how-to/interact-with-desktop-app-via-api/)
  操作过，你的表格已经有了一个可以启用嵌入的 `Content` 字段。
</Aside>

<Aside type="note">
  只有 **Text** 字段支持嵌入。Title、URL 和其他字段类型不能被嵌入。
</Aside>

### 2. 处理嵌入

添加数据后，Eidos 会自动为已启用的字段生成嵌入。在字段属性中查看进度：

- **绿色单元格** = 最新的向量
- **黄色单元格** = 已过时（文本被编辑）

如果需要，点击 **处理** 手动触发嵌入生成。

## 使用语义化搜索

### 在表格视图中

1. 打开你的表格
2. 点击搜索/筛选图标
3. 选择 **语义化搜索**
4. 用自然语言输入查询

例如，如果你正在搜索 Hacker News 文章：

| 查询                      | 查找关于...的文章        |
| ------------------------- | ------------------------ |
| "AI and machine learning" | 神经网络、LLM、深度学习  |
| "web development tools"   | 框架、构建工具、CSS 库   |
| "database optimization"   | 查询性能、索引、缓存     |
| "career advice"           | 招聘、面试、工作文化     |
| "debugging techniques"    | 故障排查、日志、可观测性 |

## 故障排除

### "未配置嵌入模型"

前往 **设置 → AI** 并添加嵌入提供商。你可以使用基于云的提供商（OpenAI 等）或本地离线模型。

### 搜索性能缓慢

- 检查是否所有向量都已生成（绿色单元格）
- 减少 `limit` 参数（例如 10 而不是 100）
- 确保你的设备有足够的内存运行嵌入模型

### 模型不匹配

如果你切换嵌入模型，现有向量将失效：

1. 打开字段属性
2. 点击 **重置向量** 清除旧的嵌入
3. 点击 **处理** 使用新模型重新生成

<Aside type="danger">
  重置向量需要重新处理所有数据。对于大型表格，这可能需要几分钟。
</Aside>
