Rust `eidos` CLI 直接操作 `.eidos` 文件，不要求桌面或 Web 应用正在运行。它是逻辑
Eidos File 数据受支持的自动化边界。

先用 `context` 获取有界工作集，再带当前 revision 调用 `apply` 或 `schema-apply`。
每次 mutation 都是原子的；写入流程完成后应执行 full validation。

```bash
eidos tracker.eidos context Tasks --fields Title,Status --limit 50
eidos tracker.eidos apply request.json
eidos tracker.eidos validate --level full
```

Raw SQLite 写入会绕过 Runtime invariant，不属于受支持的自动化接口。安装方式和完整命令契约见
[CLI README](https://github.com/mayneyao/eidos/tree/dev/apps/cli)。
