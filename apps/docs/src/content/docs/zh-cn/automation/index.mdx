自动化与扩展是两个不同的平台模块。工作流运行在 Eidos UI 之外，或者需要由其他进程驱动时，
应使用自动化接口。

| 接口 | 适用场景 | 状态 |
| --- | --- | --- |
| CLI | Space 检查、可重复维护和本地脚本 | 持续演进 |
| Desktop API | 与运行中的 Desktop 应用进行受控集成 | 持续演进 |
| Agent tools | AI Agent 发起且经过权限检查的操作 | Design preview |
| Extension SDK | 运行在 Eidos 内部的命令和 UI | Design preview |

file-based API 稳定后会逐步补齐新的自动化参考。数据库驱动的旧 API 请查阅
[旧版文档](https://legacy.docs.eidos.space/zh-cn/)。
