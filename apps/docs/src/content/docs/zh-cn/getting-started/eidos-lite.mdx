Eidos Lite 是处理本地文件夹的桌面应用，支持 `.eidos` 文件、Markdown 笔记和
其他普通文件，提供本地 Graft 历史和可选的 Sync。
打开 Space 和编辑本地文件不需要账户或网络。

## 安装 Eidos Lite

从[下载页面](https://eidos.space/download)选择适合系统的安装包。
安装后打开 Eidos Lite。

## 打开文件夹

选择 **New Space** 在新文件夹中开始，或选择 **Open Space** 打开已有文件夹。
本例使用名为 `Research` 的文件夹。

**检查结果：**侧边栏显示该文件夹的内容。

上图展示添加书单、笔记和图片之后的一种文件结构。
打开 Space 不会自动创建这些示例文件。

## 创建 Eidos File

1. 在侧边栏打开 **New File**。
2. 选择 **Eidos**，将文件命名为 `books.eidos`。
3. 在编辑器中打开文件。

**检查结果：**侧边栏包含 `books.eidos`，编辑区显示该文件。

## 找到常用操作

| 区域     | 用途                                    |
| -------- | --------------------------------------- |
| 侧边栏   | 打开、创建、重命名或移动 Space 中的文件 |
| 标签栏   | 回到已打开的文件                        |
| 编辑区   | 阅读笔记或编辑表记录                    |
| Versions | 查看改动和已保存的历史                  |
| Sync     | 检查可选的跨设备同步                    |

继续阅读[创建书单](/zh-cn/user-guide/eidos-file-basics/)。
要在手机使用 Space，先在 **设置 → 设备** 配对，再为该 Space 开启
**Sync → 局域网同步**。具体步骤见[局域网同步指南](/zh-cn/user-guide/sync/)，无需云端账号。
把 Space 移到另一块磁盘之前，先了解[数据存储与备份](/zh-cn/user-guide/data-safety/)。
