Eidos Lite 是为你电脑上的文件夹提供结构化管理与强大编辑能力的桌面应用。日常在本地使用完全无需登录，断网也能流畅运行。

---

## 1. 下载与安装

前往 [Eidos 官方下载页](https://eidos.space/zh/download) 下载适用于你操作系统的安装包：

- **macOS**：提供 Apple Silicon (M 系列芯片) 与 Intel 芯片的原生安装包，拖入 Applications 目录即可。
- **Windows**：下载安装程序运行，按照向导完成安装。
- **Linux**：提供 `.deb` 包及免安装压缩包。

---

## 2. 开启你的第一个 Space

启动 Eidos Lite 后，在欢迎屏幕中选择：

- **新建 Space**：选择或新建一个本地文件夹作为你的工作区。
- **打开已有 Space**：直接选择电脑上已有的文件夹（例如你平时存放文档或项目的目录）。

:::tip[Space 就是普通的文件夹]
你选择的文件夹始终保持操作系统原生结构，Eidos 不会对其进行任何私有化或格式转换。你可以随时在系统的 Finder 或资源管理器中像往常一样直接读写里面的文件。
:::

---

## 3. 认识主界面布局

Eidos Lite 的界面分为四个核心区域：

1. **左侧工作区边栏（Sidebar）**：
   - 浏览 Space 的目录树，支持层级折叠与展开。
   - 顶部提供快捷按钮：**新建 Eidos 文件**、**新建 Markdown 笔记** 与 **新建文件夹**。
   - 右键文件或目录可进行重命名、在系统文件管理器中显示、发布或删除。
   - 底部可打开 **插件中心** 与 **软件设置**。
2. **多标签页栏（Tabs Bar）**：
   - 像现代代码编辑器或浏览器一样，可以同时在多个 `.eidos` 表格、文档之间自由切换，互不干扰。
3. **中央主编辑区（Editor Canvas）**：
   - 当打开 `.eidos` 文件时，提供表格（Grid）、画廊（Gallery）、看板（Kanban）和日历（Calendar）等多重视图与字段配置面板。
   - 当打开 `.md` 文件时，提供极速响应的 Markdown 笔记编辑体验。
4. **右上角功能区（Action Bar）**：
   - **版本时光机（时钟图标）**：本地快照历史，随时回滚或查看改动。
   - **云同步（云朵图标）**：多设备无缝同步状态与开关。
   - **发布（火箭图标）**：将当前文件一键发布为在线网页或收集表单。

---

## 4. 三步开启第一条工作流

1. 在左侧边栏顶部点击 **新建文件**，选择 **Eidos**。
2. 输入文件名称（例如 `待办事项.eidos` 或 `项目管理.eidos`），回车创建。
3. 进入表格后，双击第一行输入内容，或点击列头右侧的 **+** 添加新的属性列。
