Eidos Lite 是管理本地文件夹的桌面应用。
它支持 `.eidos` 文件、Markdown 笔记和附件。
Lite 提供本地历史记录和可选的同步服务。
你可以在未登录账户且离线的状态下打开 Space 并编辑文件。

## 安装 Eidos Lite

从[下载页面](https://eidos.space/download)选择适合当前操作系统的安装包。
完成安装后启动 Eidos Lite。

## 打开文件夹

选择 **New Space** 在新文件夹中开始工作。
选择 **Open Space** 打开已有的本地文件夹。
本教程使用名为 `Research` 的文件夹。

**检查结果：** 侧边栏显示该文件夹包含的文件与目录。

Lite 启动时会自动重新打开上次的 Space。首次使用、没有历史记录或上次的文件夹
无法打开时，才会显示 Space 选择器。关闭 Space 窗口后不会再弹出选择器。
你可以随时点击侧边栏顶部的 Space 名称来切换 Space。

## 创建 Eidos File

1. 在侧边栏选择 **New File**。
2. 选择 **Eidos** 并将文件命名为 `books.eidos`。
3. 在编辑器中打开该文件。

**检查结果：** 侧边栏列出 `books.eidos`，编辑器显示该文件。

## 编写和保存 Markdown 笔记

在 Markdown 正文中输入 `/`，选择**附加文件**，即可从电脑选择 PDF 等普通文件。
Lite 将文件复制到笔记旁的 `assets/` 文件夹，并插入相对 Markdown 链接。
已有附件不会被覆盖，同名文件会添加编号。取消选择不会修改正文。
附件大小须在 1 字节至 64 MiB 之间。要嵌入图片，请使用 **Image（图片）**。

点击编辑器下方的**保存**，或按 macOS 的 **Cmd+S** / Windows、Linux 的 **Ctrl+S**。
状态会显示未保存、正在保存或已保存到磁盘。
焦点移到 Explorer 后，快捷键仍会保存最近操作过的文本文件，包括文件侧栏中的笔记。
搜索框和对话框保留自己的键盘焦点。主区和侧栏同时打开笔记时，点击目标笔记或它的保存按钮，明确选择保存对象。

保存会将笔记写入本地文件，本地版本历史和远端 Sync 是独立操作。
若保存失败，草稿会保留；解决提示的问题后再次点击**保存**，也可以**另存副本**。
切换笔记会保留未保存草稿，关闭 Space 或窗口时会询问如何处理。

## 工作台区域

| 区域     | 用途                                    |
| -------- | --------------------------------------- |
| 侧边栏   | 打开、创建、重命名或移动 Space 中的文件 |
| 标签页   | 在已打开的文件之间快速切换              |
| 编辑器   | 阅读笔记和编辑表格记录                  |
| Versions | 检查修改历史并按需恢复版本              |
| Sync     | 管理跨设备同步状态                      |

接下来请阅读[创建书单教程](/zh-cn/user-guide/eidos-file-basics/)。
若要在移动设备上使用该 Space，请先在 **设置 → 设备** 中配对。
然后在 Space 设置中开启 **Sync → 局域网同步**。
具体步骤请参考[局域网同步指南](/zh-cn/recipes/sync-lan/)。局域网同步无需云端账户。
将 Space 移动到其他磁盘前，请先阅读[数据存储与备份](/zh-cn/user-guide/data-safety/)。
