## 1. 安装应用

从 [Eidos 下载页](https://eidos.space/zh/download)下载 Eidos Lite，然后按照系统提示完成安装。

本地使用不需要登录。只有同步和发布等可选服务需要 Eidos 账户。

## 2. 创建或打开 Space

启动 Eidos Lite，然后选择一种方式：

- **新建 Space**：创建一个新的本地文件夹。
- **打开 Space**：使用电脑上已有的文件夹。

你选择的文件夹始终是普通文件夹，不会被转换成专有容器。

## 3. 创建第一份文件

在左侧文件列表中选择**新建 Eidos File**并输入名称。Eidos Lite 会创建一个 `.eidos` 文件，
然后在编辑器中打开。

创建数据表、添加几个字段，再输入第一条记录。修改会直接写入本地文件。

下一步阅读[从一份 Eidos File 开始](/zh-cn/user-guide/eidos-file-basics/)。

## 打开已有文件

如果 Space 中已经有 `.eidos` 文件，在左侧文件列表中点击即可打开。你也可以使用系统文件管理器
把文件复制到 Space，然后刷新文件列表。

只需要临时查看一个文件时，可以使用[Web 编辑器](/zh-cn/getting-started/browser/)。
