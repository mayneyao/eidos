Web Editor 直接在浏览器中创建和编辑单个 `.eidos` 文件。
它与 Lite 及 CLI Serve 使用相同的 Runtime 和编辑器界面。
它无需安装客户端，也无需注册账户。
若需要同时管理文件夹中的笔记与附件，请使用 [Eidos Lite](/zh-cn/getting-started/eidos-lite/)。

<Steps>

1. 打开 [editor.eidos.space](https://editor.eidos.space/)。

2. 选择 **新建** 创建空白文件，选择 **打开** 载入本地 `.eidos` 文件，或打开内置示例。

3. 添加记录、字段、表格或视图。在表格中双击单元格或按 <kbd>Enter</kbd> 开始编辑。

4. 选择 **保存** 更新本地文件。若浏览器不支持持续写入本地文件句柄，请使用 **另存为** 或 **下载副本**。

</Steps>

<Aside type="note" title="确认你正在编辑的文件副本">
  Chromium 内核浏览器通常可以在授权后直接写回原文件。
  其他浏览器通常会导入一份临时工作副本，需要通过下载保存。
  编辑器标题栏会显示当前文件的保存状态。
</Aside>

## 哪些内容保留在本地

所有文件数据、SQLite 查询与编辑修改均保留在当前设备。
在受支持的环境中，编辑器会在浏览器内部存储中保存未保存内容的应急副本。
该应急副本不能替代对 `.eidos` 文件的正常保存与备份。

下一步请阅读 [Eidos File 基础](/zh-cn/user-guide/eidos-file-basics/)或
[数据位置与安全](/zh-cn/user-guide/data-safety/)。
