从你要使用的文件开始。Eidos Lite 把包含 `.eidos` 和普通文件的本地文件夹
作为 **Space** 打开。网页编辑器和 CLI 直接操作单个 Eidos File，
使用相同的开放 SQLite 格式和 Runtime。

| 我想……                   | 从这里开始                                       | 保存位置                 |
| ------------------------ | ------------------------------------------------ | ------------------------ |
| 管理文件夹里的文件和笔记 | [Eidos Lite](/zh-cn/getting-started/eidos-lite/) | Space 中的本地文件       |
| 不安装应用，先试一个文件 | [网页编辑器](/zh-cn/getting-started/browser/)    | 保存到磁盘或下载工作副本 |
| 使用命令或智能体处理数据 | [CLI](/zh-cn/getting-started/cli/)               | 命令指定的文件路径       |

本地使用无需账户。Lite 提供本地 Graft 历史；
[Sync](/zh-cn/user-guide/sync/)是可选功能。

## 先完成一个小任务

1. 创建一个名为 `books.eidos` 的 Eidos File。
2. 添加 **Books** 表和 **Title** 字段。
3. 添加一本书，再创建 **Status** 单选字段。
4. 确认改动已经保存到 `books.eidos`。
5. 移动或备份文件时，也带上它引用的附件。

按[书单教程](/zh-cn/user-guide/eidos-file-basics/)操作。
如果这些名称还不熟悉，先读[Eidos 的文件模型](/zh-cn/concepts/)。

## 继续深入
