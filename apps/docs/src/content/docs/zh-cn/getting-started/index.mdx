**Eidos File** 是标准 SQLite 数据库，并为表、字段、记录和保存的视图定义了明确结构。
离开任何单一 Eidos 应用后，这种格式仍然可用。

## 选择 Host

| Host                | 适用场景                                     |
| ------------------- | -------------------------------------------- |
| Eidos Lite          | 管理包含本地文件的文件夹、版本历史与可选同步 |
| Eidos File Web      | 在兼容浏览器中打开单个 `.eidos` 文件         |
| Eidos CLI           | 从终端创建、检查、查询、修改和服务文件       |
| Eidos File packages | 在其他应用中嵌入 Runtime 或共享 React UI     |

## 体验 CLI

安装当前稳定版本，创建文件并打开本地编辑器：

```bash
curl --proto '=https' --tlsv1.2 -LsSf \
  https://download.eidos.space/cli/install.sh | sh

eidos create tracker.eidos --title "Project Tracker"
eidos serve tracker.eidos --open
```

Windows PowerShell：

```powershell
irm https://download.eidos.space/cli/install.ps1 | iex
```
