## 关于 Eidos File

**Eidos File** 是 SQLite application file，使用带版本的格式保存数据表、字段、记录、关系和
视图。Web Editor、Eidos Lite 与 CLI Serve 使用同一个 Runtime 读写文件。

进一步了解 Runtime、Space 和 Graft，请阅读[核心概念](/zh-cn/concepts/)；要继续编辑文件，
请前往[使用指南](/zh-cn/user-guide/)。
