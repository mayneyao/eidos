独立的 `eidos` CLI 直接操作 `.eidos` 文件。
它不依赖 Eidos Lite 或后台服务。

## 1. 安装 CLI

<Tabs syncKey="cli-install">
  <TabItem label="macOS / Linux">

```bash
curl -fsSL https://download.eidos.space/cli/install.sh | sh
```

  </TabItem>
  <TabItem label="Windows PowerShell">

```powershell
irm https://download.eidos.space/cli/install.ps1 | iex
```

  </TabItem>
</Tabs>

如果安装后 `eidos` 未进入 `PATH`，请重启终端。
运行 `eidos --help` 检查安装状态。

## 2. 可选：初始化智能体 Skill

CLI 内置面向 AI 编程助手的 Eidos Skill。
你不需要安装 Node.js 或 `npx`：

```bash
# 当前项目
eidos self skill init

# 全局配置，供所有项目使用
eidos self skill init --global
```

使用 `eidos self skill init --space <DIR>` 指定其他目标文件夹。
初始化工具不会在缺少 `--force` 参数的情况下覆盖已修改的 Skill 文件。

## 3. 创建带有表格的文件

```bash
eidos file new example.eidos \
  --table Tasks \
  --label-field Title \
  --fields '[{"name":"Title","type":"text"},{"name":"Status","type":"select"}]'
```

CLI 会将该初始表格设为文件默认表。
它会为表格自动创建第一个 Grid 视图。
字段默认允许为空值。

## 4. 打开本地编辑器

```bash
eidos serve example.eidos --open
```

本地服务默认监听 `127.0.0.1`。
它会在浏览器中打开共享的编辑器界面。
它会将提交的修改直接写入 `example.eidos` 文件。
若要在局域网内的其他设备上访问，请运行 `eidos serve example.eidos --lan`。
按 <kbd>Ctrl</kbd> + <kbd>C</kbd> 停止服务。

<Aside type="tip" title="检查文件完整性">

```bash
eidos file validate example.eidos --level full
```

</Aside>
