## Eidos File

Eidos File 是包含规范 metadata 与 data objects 的物理 SQLite 文件。Runtime 将这些对象映射为
带类型的表、字段、记录和视图；Host 不得重新解释这些语义。

## Space

在 Eidos Lite 中，Space 是用户打开的普通文件夹，可以包含多个 `.eidos` 文件和其他普通文件。
Eidos 不会把它替换为专有容器。

## Runtime 与 Host

可移植 Runtime 负责 query、Formula、Lookup、Relation、conversion、revision 与 validation 语义。
Browser、Desktop 和 CLI adapter 提供 SQLite connection 与平台能力，但不能改变结果。

## 共享 UI

`@eidos.space/eidos-file-ui` 是 Eidos File Web、Eidos Lite 与 `eidos serve` 共用的编辑器。
Grid、Gallery、Kanban、记录编辑、查询控件和语义主题 token 都是共享实现，不在 host 中分叉。

## 版本历史与同步

Eidos Lite 使用 Graft 管理本地 Space 历史，并可选连接认证远端。版本管理和同步不决定本地文件
是否可读；离线或退出账号后文件仍然可用。
