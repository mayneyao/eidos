**Eidos File** 是基于 SQLite 的开放结构化数据格式。
每个 `.eidos` 文件独立存储自身的 Schema 和记录数据。
兼容工具可以直接读写该文件，无需私有格式转换。

**Eidos Lite** 是管理本地文件夹的桌面应用，该文件夹即为 **Space**。
文件夹内可同时存放 `.eidos` 文件、Markdown 笔记、图片与附件。
Lite 提供本地版本历史记录与可选的同步功能。
本地编辑在离线或未登录状态下均可正常工作。

## 从一份书单开始

假设你需要记录阅读书单并保存读书笔记。
创建一个名为 `Research` 的 Space 文件夹。
将书单存入 `books.eidos`，将笔记写在 `notes.md` 中。

<FileMap lang="zh-cn" />

该文件夹可以直接在系统文件管理器中访问。
使用 Eidos Lite 打开文件夹不会将你的其他文档转变为私有数据库格式。

## Eidos File 内部构成

**表格**组织同类记录。
字段定义每列属性。
**视图**对表格数据进行筛选、排序并呈现。

| 组成部分     | 功能                     | 书单示例                     |
| ------------ | ------------------------ | ---------------------------- |
| 表格 Table   | 组织同类项目             | Books                        |
| 字段 Field   | 描述特定属性             | Title、Status                |
| 记录 Record  | 存储单个条目             | 一本书                       |
| 记录标题字段 | 提供记录的显示名称       | Title                        |
| 保存的视图   | 保存查询、筛选与布局设置 | 筛选 Status = Reading 的视图 |

文件存储表格结构、记录数据和视图配置。
File 字段可以关联本地外部附件。
移动或复制 `.eidos` 文件时，请同时带上这些关联附件。
详见[数据存储与安全](/zh-cn/user-guide/data-safety/)。

## 一张表格，多种视图

Grid 呈现行列网格。
Gallery 呈现卡片流。
Kanban 按特定字段对记录分组为看板列。
这些视图展示的是同一份底层表格数据。
创建新视图不会复制底层数据记录。

<ViewLab lang="zh-cn" />

筛选决定当前视图显示哪些记录。
编辑记录会更新其存储值。
若编辑导致某条记录不再满足筛选规则，该记录会从当前视图隐藏，但仍完整保存在表格中。

## 选择适合的打开方式

- **Eidos Lite：** 管理包含 `.eidos` 与普通文件的本地文件夹，使用本地历史与可选同步。
- **网页编辑器：** 在浏览器中直接打开单个 Eidos File。关闭标签页前请检查保存状态。
- **CLI：** 通过命令行或 AI Agent 脚本创建、检查、查询与更新文件。使用 `eidos serve` 启动本地编辑器。

Eidos File 为所有这些工具提供统一的可移植 Runtime。
Lite、网页编辑器与 CLI Serve 共享相同的编辑器界面。
所有工具中的数据约束与公式计算规则完全一致。

本地使用与局域网同步无需账户。
云端同步与 Web 发布是可选服务。
[对比保存、历史、Sync 与备份机制](/zh-cn/user-guide/data-safety/)。
