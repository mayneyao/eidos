## Eidos File

Eidos File 是带规范 metadata 与 data object 的 SQLite application file。Runtime
把它们映射为带类型的表、字段、记录、关系、公式和保存的视图。只有 `.eidos` 扩展名，不能让
任意 SQLite 数据库自动成为有效的 Eidos File。

## Runtime

Runtime 拥有 logical meaning：query、filter、sort、Formula、Lookup、Relation、
conversion、revision、mutation 与 validation 行为。Host 必须调用 Runtime，不能在 UI
代码或 raw SQL 中重复实现这些规则。

## Host 与 Adapter

Host 是 Runtime 周围的运行环境。浏览器负责文件授权与恢复；Lite 负责文件夹、本地进程与原生
文件对话框；CLI Serve 通过 HTTP 处理一个本地文件。Adapter 把 Runtime 连接到 SQLite 与
平台能力，但不能改变数据语义。

## Space

在 Eidos Lite 中，Space 是用户选择的普通文件夹，可以包含多个 Eidos File 和其他文件。
Space 描述桌面工作上下文，不是新的数据库格式。

## 共享 UI

`@eidos.space/eidos-file-ui` 是 Web、Lite 与 CLI Serve 共用的编辑器。Grid、
Gallery、Kanban、记录编辑、查询控件和主题角色都是共享实现。

## Graft、历史与同步

Graft 为 SQLite 文件和 Space 提供版本历史。Eidos Lite 可以把本地历史连接到可选的认证远端。
离线或退出账号时，本地文件仍然可用。

精确的 ownership 规则见[规范套件](/zh-cn/specifications/)。
