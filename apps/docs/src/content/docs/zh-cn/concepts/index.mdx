**Space** 是本地文件夹。**Eidos File** 是文件夹里的结构化文档。
**表**组织记录，**视图**选择并显示这些记录。

## 从一份书单开始

你想记录读过的书，并保留阅读笔记。创建一个名为 `Research` 的 Space，
把书单放进 `books.eidos`，把笔记写在 `notes.md` 中。

<FileMap lang="zh-cn" />

这个文件夹仍然可以在系统文件管理器中打开。
用 Eidos Lite 打开它，不会把其他文档转换成数据库记录。

## Eidos File 里面有什么

| 组成 | 作用 | 书单示例 |
| --- | --- | --- |
| 表 | 组织同一种内容 | Books |
| 字段 | 描述一种属性 | Title、Status |
| 记录 | 保存一个具体项目 | 一本书 |
| 记录标题字段 | 提供记录的显示名称 | Title |
| 保存的视图 | 保存查询和显示设置 | Status = Reading 的书 |

文件保存表结构、记录和视图。File 字段可以引用外部附件。
移动文件时，也要带上这些附件。详见[数据存储](/zh-cn/user-guide/data-safety/)。

## 一张表，可以有多个视图

Grid 按行显示，Gallery 按卡片显示，Kanban 对记录分组。
它们是表数据的不同显示方式。创建另一个视图不会复制记录。

<ViewLab lang="zh-cn" />

筛选改变你能看到哪些记录。编辑记录改变记录本身的值。
如果一次编辑让记录不再符合筛选条件，它会从当前视图消失，但仍在表中。

## 选择打开文件的工具

- **Eidos Lite：**管理文件夹、笔记、文件、本地历史和可选的 Sync。
- **网页编辑器：**在浏览器中打开一个 Eidos File。关闭前检查保存状态。
- **CLI：**通过脚本检查、查询和修改文件。用 `eidos serve` 打开本地编辑器。

本地使用无需账户。Sync 和发布是独立的可选服务。
[比较保存、历史、Sync 与备份](/zh-cn/user-guide/data-safety/)。
