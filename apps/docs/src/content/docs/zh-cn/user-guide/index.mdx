**Eidos Lite** 是为你电脑上的文件夹提供结构化数据管理、多重视图与笔记编辑能力的桌面应用。

你的 Space 就是一个普通的本地文件夹，可以自由混合存放 `.eidos` 表格、Markdown 文档、图片与各种日常文件。本地使用完全免登录，断网也能流畅使用。
