Eidos 把结构化数据保存在便携的 `.eidos` 文件中。这份手册按照真实工作流程组织：设计
数据表、录入和关联记录、建立视图、导入导出数据，并保证文件安全。

Web Editor、CLI Serve 和 Eidos Lite 共享同一套编辑模型。保存位置、附件获取、本地历史
和 Sync 等 Host 差异会在相关章节单独说明。

## 选择起点

- 第一次接触数据模型：从 [Eidos File 基础](/zh-cn/user-guide/eidos-file-basics/)开始。
- 正在设计数据库：阅读[数据表与字段](/zh-cn/user-guide/tables-and-fields/)。
- 需要找记录或建立工作流：阅读[视图与查询](/zh-cn/user-guide/views-and-querying/)。
- 不确定修改是否已经持久化：阅读[数据位置与安全](/zh-cn/user-guide/data-safety/)。
- 准备连接多个设备：启用 Sync 前先阅读[历史、恢复与同步](/zh-cn/user-guide/history-and-sync/)。

规范数据保存在 `.eidos` 文件中。编辑时，应用可能保留临时工作副本或恢复副本，因此关闭文件
前必须理解当前 Host 的保存状态。
