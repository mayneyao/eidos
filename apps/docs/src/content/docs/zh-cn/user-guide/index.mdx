Eidos Lite 把本地文件夹作为 **Space** 打开。
把 `.eidos` 文件、Markdown 笔记和附件放在一起。本地使用无需登录。

## 从建立书单开始

先[安装并打开 Space](/zh-cn/getting-started/eidos-lite/)，
再[创建第一张表](/zh-cn/user-guide/eidos-file-basics/)。
教程用同一个例子介绍字段、记录和视图。

## 让工作可以恢复

先了解[数据存储与备份](/zh-cn/user-guide/data-safety/)，
再学习[保存和恢复版本](/zh-cn/user-guide/history-and-recovery/)。

通过 [Sync](/zh-cn/user-guide/sync/)在不同设备上工作。
通过[发布](/zh-cn/user-guide/publishing/)把选定内容分享为托管页面。
文件或操作遇到问题时，查看[故障排查](/zh-cn/user-guide/troubleshooting/)。
