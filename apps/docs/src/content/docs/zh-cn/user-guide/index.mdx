Eidos Lite 将本地文件夹作为 **Space** 打开。
你可以在同一个文件夹中保存 `.eidos` 文件、Markdown 笔记和附件。
本地文件在离线或未登录状态下均可正常使用。
Eidos File 使用开放的 SQLite 文件存储结构化数据。
Lite 提供文件夹导航、本地历史记录和可选的同步服务。

## 从建立书单开始

首先[安装并打开 Space](/zh-cn/getting-started/eidos-lite/)。
