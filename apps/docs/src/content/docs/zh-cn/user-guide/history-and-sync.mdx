浏览器恢复、本地历史、同步和备份保护的是不同状态下的数据。

| 机制           | 防范的问题                            | 不能替代                         |
| -------------- | ------------------------------------- | -------------------------------- |
| 浏览器恢复副本 | 关闭或刷新页面时丢失未保存的 Web 编辑 | 保存文件或普通备份               |
| 系统废纸篓     | 从 Eidos Lite Explorer 删除文件       | 版本历史或异地备份               |
| Graft 本地历史 | 回到命名状态、查看受支持的变更        | 独立备份设备或远端               |
| Eidos Sync     | 在本地 Space 与认证远端之间保持连续性 | 本地所有权或显式冲突处理         |
| 普通备份       | 设备丢失、损坏或错误的历史操作        | Runtime 校验与经过测试的恢复流程 |

## Web 恢复

浏览器支持时，Web Editor 会在浏览器私有存储中保存可恢复工作。恢复后，应立即保存或下载
持久文件。清理站点数据可能会删除浏览器恢复内容。

## Lite 历史与同步

Eidos Lite 使用 Graft 提供本地 checkpoint 和记录级历史。本地工作不需要账号。同步是可选
能力，并明确显示登录、授权、拉取、检查、校验和推送状态。同步失败不会影响本地文件，应用也会
显示相应的恢复操作。

在 Lite 公开安装包发布前，请为 Web 或 CLI 工作流同时保留普通文件备份。
