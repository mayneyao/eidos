版本功能在本地记录 Space 的快照，用来查看早期工作或恢复已记录的状态。
使用它不需要账户。

## 启用历史

在 Eidos Lite 中打开 **Versions**，选择 **Enable versioning**。
初始版本记录 Space 的起始状态。
在 **Changes** 中查看当前改动，在 **History** 中浏览已保存的版本。

## 保存一个节点

1. 打开 **Changes**。
2. 检查新增、修改和删除的文件。
3. 输入版本说明，例如“整理书单前”。
4. 选择 **Save version**。

**检查结果：**History 中出现这条说明。

## 查看一个版本

打开 **History**，选择版本，再选择文件查看改动。
浏览历史不会修改当前文件。

## 恢复前确认范围

1. 在 History 中选择目标版本。
2. 检查准备恢复的状态。
3. 选择 **Restore this version**。
4. 阅读确认信息，再确认 **Restore Space**。

此操作作用于 Space，不只是选中的文件。
恢复后打开重要文件，检查内容。
另行保留独立备份，以应对设备丢失或磁盘故障。

## 排除临时文件

在 Space 根目录使用 `.gitignore` 或 `.graftignore`，
将临时内容排除在版本跟踪之外。例如：

```text
node_modules/
*.tmp
cache/
```

版本没有记录过的排除文件，不能从该版本恢复。
文件元数据管理使用的物理文件属性也需要单独检查备份是否覆盖。
详见[数据安全](/zh-cn/user-guide/data-safety/)。
