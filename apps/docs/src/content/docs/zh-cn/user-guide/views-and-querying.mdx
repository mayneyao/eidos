**视图（View）**是针对同一张数据表的定制化镜头。你可以为不同的日常任务创建专门的视图（例如“我的待办”、“进行中项目”、“按周归档”），而无需重复复制数据。

在一个视图中编辑数据，所有其他视图都会实时同步更新。

---

## 1. 四大常用视图

点击视图栏上的 **+** 即可新建视图，随时在不同的展示形式间自由切换：

| 视图类型 | 最佳使用场景 | 核心交互与特点 |
| :--- | :--- | :--- |
| **表格（Grid）** | 密集数据对比、批量录入、多列统计 | 像经典电子表格一样高效浏览所有列，支持自由调整列宽与隐藏列。 |
| **看板（Kanban）** | 任务流转、状态跟踪、阶段推进 | 按“状态”或“优先级”等单选字段分列陈列，直接拖拽卡片即可推进进度。 |
| **画廊（Gallery）** | 视觉素材库、设计图册、电影海报墙 | 将卡片封面设为图片或附件字段，以大图卡片墙沉浸式浏览。 |
| **日历（Calendar）** | 个人日程、排期发布、项目截止期规划 | 绑定日期字段，以月历或周历呈现。点击任意日期格子可直接新建该日期的记录。 |

:::tip[临时搜索 vs 长期保存视图]
- **顶部搜索框**：用于临时的快速过滤（如搜索特定关键词或人名），清空搜索框后视图会立即恢复原样。
- **视图保存**：当你设置了常用的筛选条件（例如“状态为进行中 且 优先级为高”）、排序规则或隐藏了某些列时，这些配置会被**永久保存在当前视图**中，每次打开都能直接使用。
:::

## 2. 强大的组合筛选（Filter）

点击工具栏上的 **筛选（Filter）** 按钮即可添加条件：

- **多条件组合**：
  - **符合以下所有条件（AND）**：所有规则必须同时满足。
  - **符合以下任一条件（OR）**：满足其中一条即可显示。
- **相对日期筛选**：
  - 日期字段支持极其实用的相对过滤规则，例如：**等于今天**、**在本周内**、**在过去 7 天内** 或 **在未来一个月内**。
  - 保存这些条件后，视图会随着现实时间的前进而自动动态更新，永远呈现“当前最新的待办”，无需每天手动修改日期参数！

---

## 3. 多级排序（Sort）

点击工具栏上的 **排序（Sort）** 按钮：

- 支持同时添加多个排序维度。例如：**第一优先级按“截止日期（升序）”**，在同一天截止的任务再**第二优先级按“重要程度（降序）”**。
- 随时拖拽调整排序规则的优先级，或一键切换升序/降序。

---

## 4. 字段显隐与卡片定制

为了让视图更加聚焦，你可以点击 **字段（Fields）** 菜单：

- **勾选显隐**：隐藏当前视图中不需要关注的辅助列，界面更清爽。隐藏列仅对当前视图生效，不会删除底层数据。
- **自定义卡片封面与属性**：在看板和画廊视图中，你可以自由勾选卡片正面需要展示哪些属性（例如只展示负责人头像、标签和截止日期），并为画廊挑选最合适的封面比例。
