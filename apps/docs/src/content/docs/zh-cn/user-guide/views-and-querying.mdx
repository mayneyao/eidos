保存的表格视图记录如何筛选、排序并展示记录。
为高频重复任务分别创建独立视图，例如“正在阅读”和“已读完”。

## 观察隐藏与修改的区别

1. 开启“只看未读完”，不符合条件的记录会从列表中隐藏。
2. 切换到 **Gallery** 画廊视图，符合条件的记录以卡片形式展示。
3. 将一本可见的书标记为“已读完”，它不再符合筛选条件，自动隐藏。
4. 清除筛选条件，所有记录依然完好保存在表格中。

## 根据使用场景选择视图布局

| 布局 | 用途 | 配置选项 |
| --- | --- | --- |
| Grid | 跨列对比字段，直接编辑行 | 调整列顺序、列宽与可见性 |
| Gallery | 以卡片形式浏览图文记录 | 配置卡片展示字段与封面图片字段 |
| Kanban | 按分类或状态分组展示 | 选择单选分组字段 |
| Calendar | 按日历时间轴查看记录 | 选择日期或日期时间字段 |
| Form | 提供便捷的表单录入界面 | 表单题目与提交行为设置 |
| Feed | 瀑布流连续阅读记录 | 配置需要流式呈现的字段 |

关于视图的底层技术规范，请参阅 [标准视图 1.0 规范](/zh-cn/specifications/standard-views-1-0/)。
在插件开发中，**page** 和 **file** 代表两类插件视图，定义插件在界面中的打开入口。
详情请参阅[插件概念说明](/zh-cn/plugins/concepts/)。

## 使用搜索快速定位

使用 **Search** 搜索框通过书名或关键词快速过滤。
清空搜索框即可返回保存视图的完整结果列表。
如需长期使用相同的条件，请将其保存为持久化筛选器。

## 组合多种筛选条件

打开 **Filter** 筛选面板。选择多条件的组合逻辑：

| 规则 | 示例 | 筛选结果 |
| --- | --- | --- |
| 全部满足（AND） | Status 是 Reading 且 Rating 是 5 | 仅显示同时符合两个条件的记录 |
| 任一满足（OR） | Status 是 Reading 或 Rating 是 5 | 显示符合其中任一条件的记录 |

不符合筛选规则的记录仍然完整保留在表格中。
使用相对日期筛选时，显示结果会随着系统日期变化自动动态调整。

## 配置结果排序

打开 **Sort** 排序面板，按优先级添加排序规则。
例如：先按 Status 排序，再按 Title 排序。
次级排序规则用于决定主排序值相同记录的前后次序。

## 控制字段可见性

打开 **Fields** 面板，按需显示或隐藏特定列，并调整字段顺序。
隐藏字段不会删除字段中的底层数据。
在卡片式布局中，可以独立配置封面与卡片正文。
被隐藏的字段不会渲染在卡片上。
