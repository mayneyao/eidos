保存的表视图记录如何选择和显示记录。
为重复任务分别创建视图，例如“正在读”和“已读完”。

## 试着区分隐藏和修改

1. 打开“只看未读完”，一条记录会消失。
2. 切换到 **Gallery**，同样的两条记录变成卡片。
3. 把一本可见的书勾选为“已读完”，它不再符合筛选条件。
4. 取消筛选，三条记录仍然都在。

## 按任务选择布局

| 布局 | 用途 | 配置 |
| --- | --- | --- |
| Grid | 比较字段，编辑行 | 字段顺序、宽度和可见性 |
| Gallery | 以卡片浏览记录 | 卡片内容和封面字段 |
| Kanban | 按状态分组 | 用于分组的单选字段 |
| Calendar | 按日期查看记录 | 日期或日期时间字段 |
| Form | 输入新记录 | 问题和提交设置 |
| Feed | 连续阅读记录 | 要显示的字段 |

布局契约见[标准视图](/zh-cn/specifications/standard-views-1-0/)。
在插件开发中，**page** 和 **file** 是两种 View，表示插件从哪里打开。
详见[插件概念](/zh-cn/plugins/concepts/)。

## 临时查找用搜索

通过 **Search** 查找标题或关键词。清除搜索后，回到保存的视图结果。
需要重复使用同一组条件时，保存筛选。

## 组合筛选条件

打开 **Filter**，选择条件的组合方式：

| 规则 | 示例 | 结果 |
| --- | --- | --- |
| 全部满足（AND） | Status 是 Reading，且 Rating 是 5 | 同时符合两个条件的书 |
| 任一满足（OR） | Status 是 Reading，或 Rating 是 5 | 符合至少一个条件的书 |

不符合筛选条件的记录仍然在表中。
相对日期筛选的结果可能随日期变化。

## 排序结果

打开 **Sort**，按优先级添加规则。
例如，先按 Status 排序，再按 Title 排序。
第一个规则的值相同时，由第二个规则决定顺序。

## 只显示需要的字段

打开 **Fields**，调整字段可见性和顺序。
隐藏字段不会删除其值。卡片布局的内容和封面单独设置；
隐藏的字段不会出现在卡片上。
