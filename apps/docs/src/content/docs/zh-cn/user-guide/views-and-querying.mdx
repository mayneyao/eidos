视图是一张数据表的保存阅读与工作方式，不会复制记录。在一个视图中修改值，所有视图都会看到
同一条记录的变化。

## 视图会保存什么

视图可以保存名称、类型、筛选、排序、可见字段、字段顺序和类型专用布局。临时搜索词、选择、
滚动位置、hover 状态和打开的详情面板不会保存进去。

不同任务应建立不同视图，例如**全部任务**、**我的未完成工作**、**本周到期**和**归档**，
而不是每天重建同一个复杂筛选。

## 选择 Grid、Gallery 或 Kanban

| 视图    | 适合的工作                     |
| ------- | ------------------------------ |
| Grid    | 密集录入、比较、排序和字段操作 |
| Gallery | 用封面与关键字段浏览卡片       |
| Kanban  | 在单选状态等分组之间移动记录   |

切换视图类型或卡片布局只改变展示。Kanban 移动可能更新配置的分组字段，因为移动卡片本身表达
了一次数据修改。

## 临时搜索

搜索会在受支持字段和记录标题的可展示片段中匹配。它只缩小当前视图，不会改变保存筛选。清空
搜索框即可回到视图的完整保存结果。

已知标题、选项、关联记录标签或文件名的一部分时使用搜索；明天仍应生效的条件使用保存筛选。

## 建立筛选组

打开**筛选**并添加条件。**全部匹配**表示 AND，**任一匹配**表示 OR。嵌套组可以表达：

> 状态不是已完成 AND（优先级是高 OR 截止日期相对本周）

空值和否定条件使用完整 Boolean 逻辑。“不是”与“不包含”可以包含空的 scalar 值，不会泄漏
SQL 的第三种 unknown truth value。

## 日期与时间条件

日期和日期时间字段提供：

- **是**
- **早于** / **晚于**
- **不晚于** / **不早于**
- **介于**两个包含首尾的端点
- **相对今天**
- **为空** / **不为空**

相对条件组合一个方向和单位：

| 方向 | 含义                                      |
| ---- | ----------------------------------------- |
| 过去 | 截止到 reference 的一个滚动日、周、月或年 |
| 未来 | 从 reference 开始的一个滚动日、周、月或年 |
| 本期 | 包含今天的 calendar 日、ISO 周、月或年    |

**本期周**使用周一到周日。移动月或年时会 clamp 月末日期，因此闰年 2 月 29 日的一年后在
需要时会落到 2 月 28 日。保存的是方向与单位，新查询会重新计算；日历预览中的日期不会被
冻结到视图里。

一次查询只捕获一个 reference instant。所有相对条件和 continuation page 使用同一个值，
因此时间前进时，记录不会在分页过程中跳动。

## 添加多级排序

排序按顺序计算：第一个是主排序，第二个用于处理相同值，依此类推。排序方向只改变行顺序，
不会改变记录。

如果编辑改变了排序字段，行可能移动。它仍在视图内时，编辑器可以跳到新位置；如果不再满足
筛选，它会离开视图，因为保存查询已经不成立。

## 选择可见字段

打开**字段**可以：

- 在当前视图显示或隐藏字段；
- 拖动字段改变视图顺序；
- 直接打开字段属性，而不用寻找列菜单。

隐藏字段不会删除数据。Grid 还可以冻结前部区域并保存字段宽度；Gallery 与 Kanban 保存各自
适用的卡片字段顺序、封面和其他布局属性。

## 示例视图

### 本周到期

- 状态**不是**已完成
- 截止日期**相对今天 → 本期 → 周**
- 截止日期升序，然后优先级降序

### 最近活跃

- 更新时间**相对今天 → 过去 → 周**
- 更新时间降序

### 指定日程区间

- 开始日期**介于**选择的开始与结束日期
- 开始日期升序

## 理解保存状态

应用筛选、排序或字段设置会修改视图，因此会改变 File revision。输入临时搜索词不会。如果
另一编辑器先修改了同一视图，Eidos 会刷新，而不是静默覆盖较新的定义。

需要与其他系统交换数据时，继续阅读[导入与导出](/zh-cn/user-guide/import-and-export/)。
