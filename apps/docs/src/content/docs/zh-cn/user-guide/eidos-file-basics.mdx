完成本教程后，`books.eidos` 将包含一份书单，
以及一个只显示正在阅读书籍的视图。

先在 [Lite](/zh-cn/getting-started/eidos-lite/)、
[网页编辑器](/zh-cn/getting-started/browser/)或
[CLI Serve](/zh-cn/getting-started/cli/) 中打开一个 Eidos File。

## 1. 创建表

创建名为 **Books** 的表。把名为 **Title** 的文本字段设为记录标题字段。
Eidos 用这个字段显示每本书的名称。

添加名为 **Status** 的单选字段，设置三个选项：
**To read**、**Reading** 和 **Finished**。

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| Title | Text | 书名，同时作为记录标题字段 |
| Status | Select | 一个阅读状态 |

## 2. 添加记录

添加三条记录，分别输入书名并选择状态。

| Title | Status |
| --- | --- |
| The Little Prince | Reading |
| A Room of One's Own | Finished |
| Walden | To read |

**检查结果：**Books 包含三条记录，每条记录代表一本书。

## 3. 保存阅读视图

添加名为 **Reading now** 的 Grid 视图。
打开 **Filter**，添加条件 `Status = Reading`。

**检查结果：**视图只显示 **The Little Prince**。
另外两条记录仍然在 Books 中，清除筛选即可看到。

创建 Gallery 视图，以卡片显示书籍。
在其中修改一本书的 Status，Grid 中的同一条记录也会变化。

## 5. 确认保存

在 Lite 和 CLI Serve 中，已提交的编辑会写入本地文件。
在网页编辑器中，检查保存状态，并按可用选项使用
**Save**、**Save As** 或 **Download a copy**。

移动 `books.eidos` 时，也要带上附件字段引用的本地文件。
[了解需要备份什么](/zh-cn/user-guide/data-safety/)。

下一步：[选择字段](/zh-cn/user-guide/tables-and-fields/)，
或[配置视图](/zh-cn/user-guide/views-and-querying/)。
