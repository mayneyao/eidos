## 文件的组成

| 部分   | 含义                                                         |
| ------ | ------------------------------------------------------------ |
| 数据表 | 一组带类型的记录，例如任务或书籍                             |
| 字段   | 每条记录共有的属性，例如状态、截止日期或评分                 |
| 记录   | 带稳定 identity 的一行数据                                   |
| 视图   | 数据表的一种保存展示方式，包含可见字段、筛选、排序与视图属性 |

Grid、Gallery 与 Kanban 都是同一组记录的视图。在一个视图中修改记录，结果会出现在其他
视图中，不会产生另一份数据副本。

## 从一份可用文件开始

在 Web Editor 中选择**新建**或模板。使用 CLI 时，可以在创建文件时同时创建第一张表：

```bash
eidos create tasks.eidos \
  --table Tasks \
  --label-field Title \
  --fields '[{"name":"Title","type":"text"},{"name":"Priority","type":"select"}]'
```

每张表都有一个 record-label 字段。其他表引用这条记录时，Eidos 会用它作为人类可读名称。

## 视图与搜索

视图会保存筛选、排序、可见字段和布局。搜索是临时的；清空搜索框后会回到已保存的视图。
