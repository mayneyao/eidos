**Eidos File**（`.eidos` 文件）是一份独立、轻便且功能强大的本地结构化文档。你可以像复制普通文件一样随手备份或发送给同事，也可以在无需联网的情况下毫秒级打开使用。

---

## 1. 理解核心组成要素

一份 `.eidos` 文件由以下几个层次构成：

| 元素 | 说明 | 示例 |
| :--- | :--- | :--- |
| **数据表（Table）** | 描述一类特定事物的数据集合，一份文件可包含多张表 | `任务列表`、`客户档案`、`影视清单` |
| **字段（Field）** | 数据表的列，定义记录具有的属性和格式 | `标题`（文本）、`优先级`（单选）、`截止日期`（日期） |
| **记录（Record）** | 数据表的每一行，代表一个具体的数据实体 | 一项具体的任务、一位客户、一部电影 |
| **视图（View）** | 对同一张表数据的不同展示与过滤方式 | 表格明细、任务看板、海报画廊、排期日历 |

:::tip[修改一处，处处联动]
所有视图（表格、看板、画廊等）都是同一份底层数据的不同镜头。你在看板中将一张卡片从“进行中”拖到“已完成”，切换回表格视图时，该行的状态同样已实时改变，绝不会产生两份互相冲突的副本。
:::

## 2. 创建你的第一张数据表

打开新建的 `.eidos` 文件后，你可以直接使用默认表，也可以点击表头标签栏的 **+** 新建数据表：

1. **命名数据表**：输入具有明确含义的名称（例如 `待办事项`）。建议一张表只专注于一种事物，不要将客户和发票混在同一张表里。
2. **选择记录标题字段（Label Field）**：
   - 每张数据表都有一个核心字段作为“记录标题”（通常是第一列）。
   - 它是每条记录的身份证，在卡片视图、看板标题以及跨表关联时都会直接显示它。
   - 建议选用人眼易识别的字段，例如 **任务名称**、**姓名** 或 **项目主题**，避免使用复杂的内部编码或时间戳。

---

## 3. 录入数据与配置字段

### 快速新建记录
- 点击表格底部的 **添加记录**，或者在任意单元格按下快捷键 <kbd>⌘</kbd> + <kbd>Enter</kbd>（Windows 上为 <kbd>Ctrl</kbd> + <kbd>Enter</kbd>），即可快速在下方插入一行并立即输入。
- 支持键盘按键流转：按 <kbd>Tab</kbd> 跳到下一个单元格，按 <kbd>Enter</kbd> 保存当前单元格。

### 自由添加自定义字段
点击表格最右侧的 **+（添加字段）**：
- 输入列名（如“优先级”）。
- 选择字段类型（如 **单选**）。
- 点击选项设置，添加你的预设选项（例如“高”、“中”、“低”），还可以为不同选项设置直观的颜色。
- 你还可以为单选字段勾选 **默认选项**：之后每次新建记录时，该字段会自动填入默认值（如“中”）。

详细字段类型与用法见[数据表与字段设计](/zh-cn/user-guide/tables-and-fields/)。

---

## 4. 一秒切换：从表格到任务看板

当你录入了一些数据后，可以随时创建专属的工作流视图：

1. 点击视图栏右侧的 **+（添加视图）**。
2. 视图类型选择 **看板（Kanban）**。
3. 选择按哪个单选字段进行分组（例如“状态”或“优先级”）。
4. 点击创建，原本密集的表格数据瞬间变成整洁的卡片看板！
5. 在看板中，通过鼠标直接拖拽卡片，就能实时更新其状态属性。

详细视图玩法与筛选排序见[多重视图与高级筛选](/zh-cn/user-guide/views-and-querying/)。

---

## 5. 编辑即保存，数据随手带走

- **自动持久化**：Eidos Lite 采用实时保存机制，你在界面上的每一次敲击、每一次拖拽都会立即安全写入本地硬盘中的 `.eidos` 文件，无需手动按保存。
- **便携流转**：关闭 Eidos Lite 后，你可以直接把这个 `.eidos` 文件丢进 U 盘或发到微信，它依然是一份完整包含所有表格、字段和视图的独立数据库。
