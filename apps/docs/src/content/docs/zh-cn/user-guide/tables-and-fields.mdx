数据表用于组织同类项目。
字段用于描述项目的具体属性。
例如，Books 表格中的每条记录代表一本书，Title 和 Status 是字段。

## 从两个字段开始

创建 **Title** 文本字段。
创建 **Status** 单选字段。
为 Status 配置三个选项：**To read**、**Reading** 与 **Finished**。
将 Title 设为记录标题字段（Record Label Field）。

**检查结果：** 添加一本书并选择 Reading。
标题用于识别该条记录。
状态可直接用于视图筛选。
根据需要随时添加更多字段。
完整操作请参考[书单快速入门教程](/zh-cn/user-guide/eidos-file-basics/)。

## 创建和命名数据表

使用标签页创建、重命名、调整顺序或删除数据表。
表名易于阅读，且支持随时修改。
Eidos 为每张表维护稳定的内部 ID。
已保存视图与关联关系不依赖于当前的显示表名。

如果记录包含长篇笔记或文章，可在建表时勾选**添加 Markdown 正文**。
Eidos 会添加一个文本字段作为记录正文。
你可以随时在**数据表设置**中更改该**正文字段**。
在 Lite 中新建 `.eidos` 文件时，展开**高级选项**即可为初始表格开启正文字段。
未配置正文字段的表格仍是完整的结构化表格。
文件映射表的路径等系统只读属性不能用作正文字段。

表名应简明一致。
名为 **Projects** 的表格应当每条记录代表一个项目。
避免在同一张表格中混合项目、客户与零散笔记。

## 选择记录标题字段

每张表格必须且仅有一个记录标题字段。
Eidos 在记录标题、Gallery 卡片、Kanban 卡片和关联引用中使用该字段。

打开表格菜单，选择**数据表设置**即可修改。
好的标题字段应便于人类辨识与区分记录。
修改标题字段不会重写关联 ID。
关联记录的标签会直接从新字段读取。

删除当前标题字段前，请先指定替代字段。
Eidos 不允许表格缺少记录标题字段。

## 选择字段类型

| 字段类型 | 适用场景 | 关键行为 |
| --- | --- | --- |
| 文本 Text | 标题、备注、代码与自由文本 | 支持搜索。保留输入文本 |
| 数字 Number | 测量值与小数 | 有限十进制数值 |
| 整数 Integer | 数量与计数 | 精确的 64 位有符号整数 |
| 单选 Select | 单一受控分类或状态 | 单选值。可设置默认选项 |
| 多选 Multi-select | 标签与多项分类 | 有序选项列表。无隐式默认值 |
| 复选框 Checkbox | 是/否布尔状态 | 支持保持留空 |
| 评分 Rating | 星级评分展示 | 以整数值存储 |
| URL | 网页地址 | 经宿主策略检查后可点击跳转 |
| 日期 Date | 无时区的日历日期 | 适用于无需具体时刻的日期 |
| 日期与时间 Date & time | 精确时间戳 | 规范存储，按选定时区展示 |
| 文件 File | 附件与图片引用 | 文件获取取决于宿主能力 |
| 公式 Formula | 基于本表字段计算的值 | 只读计算结果 |
| 关系 Relation | 关联另一张表的记录 | 存储稳定的目标记录 ID |
| 查找/汇总 Lookup | 跨关系读取或汇总字段值 | 只读派生结果 |

优先选择最精确的字段类型。
状态应使用单选，而非普通文本。
生日应使用日期，而非日期时间。
关联人员应使用关系字段，而非重复输入姓名。

## 配置单选选项与默认值

字段属性支持添加、重命名、更改颜色、排序和删除选项。
选项名称是持久化的逻辑值。
颜色仅用于界面呈现。

单选字段的**默认选项**控制新记录的初始值：

- **无默认值**：未赋值的字段保持为空。
- 选择默认选项后：新建记录若未提供该字段，会自动使用默认值。
- 显式清空或传入其他值会覆盖默认值。
- 历史记录不会自动回填默认值。
- CSV 导入不会自动推断默认值。
- 重命名选项会同步更新默认值引用。
- 删除选项会清除对应的默认值配置。

多选字段不支持默认值。
隐式列表可能掩盖用户是否真正主动选择了标签。

## 使用关系与查找连接表格

正向关系从当前表格指向目标表格的一条或多条记录。
存储值为有序的目标行 ID 列表。
编辑器解析目标记录的当前标题字段以供展示。

使用查找（Lookup）显示或聚合跨关系的数据。
查找结果为派生值。
如需修改，请直接编辑源记录或关系本身，不要尝试覆盖查找结果。

删除被引用的表格或字段前，请检查依赖关系报告。
隐藏视图或派生字段可能仍依赖该字段。

## 使用公式计算字段值

公式字段根据同一表格中的其他字段计算结果。
编辑器在保存定义前会预览并检查表达式。
公式计算结果为只读，当输入字段变更时自动刷新。
具体受支持函数、语法与示例请参阅 [公式表达式](/zh-cn/user-guide/formula/)。

双击公式单元格，或选中后按 Enter 或空格键，即可在单元格旁打开公式编辑器。
当前选中记录将作为实时预览样本。
你可以对照当前行检查表达式的计算结果。
从字段设置中打开公式编辑器时，将使用 Runtime 提供的通用示例数据。

对于确定性的派生值使用公式。
对于需要人工干预修改的值，不要使用公式。
跨表格数据读取请使用查找字段。

## 重命名、排序、转换与删除字段

- **重命名**：更改显示名称与存储名称。Runtime 会按稳定 ID 更新系统引用。
- **排序**：调整字段列顺序，不影响存储数据。
- **隐藏**：仅作用于当前视图，不会删除字段或数据。
- **转换**：修改字段类型。确认前请仔细阅读影响分析。
- **删除**：永久删除字段存储的数据，并可能影响依赖该字段的公式。

### 类型转换支持概览

每一行代表当前字段类型，每一列代表目标类型：

- `✓`：所有已有数据均通过校验时允许转换。
- `⚠`：支持转换，但可能丢失精度或发生截断。Eidos 会给出提示并要求确认。
- `•`：当前类型相同，无需转换。
- `—`：类型菜单不提供直接转换路径。

以下字段使用专用配置流程，不在通用类型转换菜单中：

| 字段 | 直接转换 | 修改方式 |
| --- | :---: | --- |
| 文件 | — | 创建新的文件字段并手动迁移附件 |
| 关系 | — | 使用关系字段配置流程 |
| 公式 | — | 使用公式编辑器并指定输出类型 |
| 查找 / 汇总 | — | 使用查找配置面板与聚合选项 |
| 记录 ID / 创建时间 / 更新时间 | — | 系统内部字段不可修改 |

评分字段属于整数呈现形式，只接受 0 至 5 之间的整数值。
文本与单选转换必须符合目标格式规范。
例如，文本转为复选框仅接受小写的 `true` 或 `false`。
底层转换规则与具体算法请参阅 [Runtime 1.0 规范](/zh-cn/specifications/runtime-1-0/)。

结构修改包含版本检查机制。
若在生成修改方案后文件被其他操作修改，Eidos 会刷新方案，不会直接将旧方案应用到新状态。

## 实用的任务管理表结构

| 字段 | 类型 | 配置说明 |
| --- | --- | --- |
| Title | 文本 | 记录标题字段 |
| Status | 单选 | Todo、Doing、Done。默认值：Todo |
| Assignee | 关系 | 关联至人员表 |
| Due | 日期 | 无需具体时刻 |
| Tags | 多选 | 受控标签列表 |
| Days open | 公式 | 根据创建时间自动计算已开放天数 |
| Team | 查找 | 从负责人关联记录中读取所属团队 |
