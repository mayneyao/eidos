一张表应该只描述一种事物，例如任务、人员、书籍、订单或项目；字段描述这些记录共有的属性。
边界清楚后，筛选、关系、导入和自动化才会保持可预测。

## 创建和命名数据表

通过数据表标签页可以创建、重命名、排序或删除数据表。名称面向人，并且可以日后修改；Eidos
使用稳定内部 ID，因此保存视图和关系不会依赖当前显示名称。

表名应简洁且保持一致。名为**项目**的表应当每条记录代表一个项目，而不是混合项目、客户与
随手笔记。

## 选择记录标题字段

每张表必须且只能有一个记录标题字段（Record Label Field）。Eidos 用它显示记录标题、
Gallery/Kanban 卡片、关系选项和已关联记录的名称。

打开数据表菜单，选择**数据表设置**即可更换。合适的标题字段应该容易识别，通常还应足以区分
记录。更换标题字段不会重写关系 ID；关联标签会从新字段刷新。

如果准备删除当前标题字段，应先选择替代字段。Eidos 不允许数据表失去记录标题。

## 选择字段类型

| 字段类型   | 适合的数据                 | 重要行为                         |
| ---------- | -------------------------- | -------------------------------- |
| 文本       | 标题、备注、代码和自由输入 | 可搜索；保留输入文本             |
| 数字       | 测量值和小数               | 有限十进制数                     |
| 整数       | 数量和精确整数             | 精确的有符号 64 位值             |
| 单选       | 一个受控状态或分类         | 一个选项；可配置创建默认值       |
| 多选       | 标签和多个受控分类         | 有顺序的选项列表；没有隐式默认值 |
| 复选框     | 是/否状态                  | nullable 时可以为空              |
| 评分       | 五星评分展示               | 以整数式数值保存                 |
| URL        | 网页地址                   | 通过 Host policy 检查后才可打开  |
| 日期       | 不带时区的日历日期         | 不关心一天中的具体时刻时使用     |
| 日期与时间 | 一个精确时刻               | 规范保存，并按选定时区展示       |
| 文件       | 便携的附件与图片引用       | 获取与预览取决于 Host capability |
| 公式       | 根据本表其他字段计算的值   | 只读结果                         |
| 关系       | 另一张表中的记录           | 保存稳定目标记录 ID              |
| 查找/汇总  | 通过关系读取或汇总字段     | 只读派生结果                     |

优先选择能准确表达数据的最窄类型。状态通常应使用单选而不是文本；生日应使用日期而不是日期
时间；人员关系应使用关系而不是复制姓名。

## 配置单选选项和默认值

字段属性可以添加、重命名、换色、排序和删除单选/多选选项。选项名称是保存的逻辑值，颜色只是
展示属性。

单选字段的**默认选项**控制新建记录：

- **无默认值**会让未提供的字段保持为空。
- 选择某项后，创建操作省略该字段时会自动分配。
- 显式清空或提供其他值会覆盖默认值。
- 不会回填已有记录。
- CSV 导入不会推断这个默认值。
- 重命名默认选项会在同一原子操作中更新默认关系。
- 删除默认选项会清除默认值。

多选不提供此设置，因为隐式列表会掩盖创建者是否真的选择过标签。

## 用关系和查找连接数据表

正向关系从当前表指向目标表的一条或多条记录。保存值是有顺序的稳定 Row ID 列表；编辑器
读取目标表当前记录标题用于展示。

需要展示或聚合关系另一端的字段时使用查找。查找是派生结果：应该编辑源记录或关系，而不是
尝试覆盖查找值。

删除被引用的表或字段前，应阅读完整 dependency report；隐藏视图和派生字段也可能依赖它。

## 用公式计算值

公式字段根据同一张表的字段计算声明类型的结果。编辑器会在提交定义前预览和校验表达式。
公式结果只读，并在依赖项改变后刷新。

双击公式单元格，或选中后按 Enter、Space，即可在该单元格旁打开公式编辑器。当前记录会
作为预览示例，因此修改表达式时看到的是刚才正在检查的那条记录。从字段设置打开编辑器时，
则使用 Runtime 提供的常规样本记录。

可重复推导的值使用公式；需要人工覆盖的值不要使用公式。跨关系读取数据使用查找。

## 重命名、排序、转换或删除字段

- **重命名**改变显示名与物理字段名，Runtime 按稳定 ID 重写受支持引用。
- **排序**只改变展示，不改变记录值。
- **隐藏**属于视图，不会删除字段或数据。
- **转换**可能是仅元数据、无损、显式有损或禁止。应阅读 preflight 影响，不能只看少量样本。
- **删除**永久移除保存值，也可能影响依赖项。

结构修改受 revision 检查保护。如果计划生成后文件已经被其他修改改变，Eidos 会刷新计划，
而不是把旧计划应用到新状态。

## 一张实用的任务表

| 字段       | 类型 | 配置                               |
| ---------- | ---- | ---------------------------------- |
| 标题       | 文本 | 记录标题字段                       |
| 状态       | 单选 | 待处理、进行中、已完成；默认待处理 |
| 负责人     | 关系 | 关联到人员表                       |
| 截止日期   | 日期 | 不包含具体时刻                     |
| 标签       | 多选 | 受控主题名称                       |
| 已开放天数 | 公式 | 根据创建时间派生                   |
| 团队       | 查找 | 从负责人关联记录读取               |
