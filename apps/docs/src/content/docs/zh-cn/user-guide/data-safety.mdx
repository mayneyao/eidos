Eidos Lite 直接使用你电脑上的文件。打开一个 Space，实际上就是打开一个普通文件夹；编辑内容时，修改会保存到这个文件夹里的原文件。

本地使用不需要登录，也不会因为打开或编辑文件而自动上传数据。

## `.eidos` 文件里有什么

`.eidos` 文件保存表格、字段、记录和视图等结构化数据。它是一个标准 SQLite 文件，可以像其他文件一样复制、移动和备份。

图片、PDF 和其他附件是 Space 中的独立文件，**不会保存在 `.eidos` 文件里面**。Eidos File 只记录它们的位置。因此，只复制 `.eidos` 文件可能会漏掉附件。

移动带有附件的工作内容时，请移动整个 Space，或同时保留原来的文件夹结构。

## 备份一个 Space

最稳妥的方式是备份整个 Space 文件夹：

1. 等待当前编辑完成，确认没有文件仍在保存。
2. 在 Finder 或文件管理器中复制整个 Space 文件夹。
3. 把副本保存到另一个磁盘或你信任的备份位置。
4. 偶尔打开备份副本，确认文件能够正常使用。

CSV 适合交换表格数据，但不是完整备份。它不会保留视图、关系、公式以及附件引用等信息。

## 版本、同步和备份的区别

- **版本**帮助你回到 Space 之前的状态。
- **同步**帮助你在自己的设备之间继续工作。
- **备份**在电脑丢失、磁盘损坏或整个 Space 被误删时保留另一份副本。

三者用途不同。即使开启了版本或同步，也建议保留独立备份。

## 避免文件冲突

不要同时用多个应用修改同一个 `.eidos` 文件。如果 Eidos Lite 提示文件正在使用、被锁定或已在外部修改，请先关闭另一个应用，再重新打开文件。

你可以用 SQLite 工具读取 `.eidos` 文件。需要直接修改数据库时，请先关闭 Eidos Lite 并做好备份；普通编辑仍建议在 Eidos Lite 或 Eidos CLI 中完成。
