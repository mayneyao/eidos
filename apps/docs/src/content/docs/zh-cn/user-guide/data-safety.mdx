## 数据保存在哪里

| 使用方式                | 持久数据                            | 写入方式                                           |
| ----------------------- | ----------------------------------- | -------------------------------------------------- |
| Web Editor 直接文件模式 | 你选择的 `.eidos` 文件              | 浏览器授权并完成冲突检查后，**保存**写回文件       |
| Web Editor 导入副本模式 | 你另存或下载的文件                  | 浏览器内工作副本不是原文件，需使用**另存为**或下载 |
| CLI 命令                | 传给 `eidos` 的路径                 | 命令成功后，修改会直接写入该文件                   |
| CLI Serve               | 传给 `eidos serve` 的路径           | 编辑器中每次成功的修改都会写入文件                 |
| Eidos Lite              | 普通 Space 文件夹中的 `.eidos` 文件 | 修改写入本地文件，版本历史单独保存                 |

查询和编辑 Eidos File 都不需要上传文件。

## 安全习惯

1. 对重要 `.eidos` 文件或整个 Space 做普通文件备份。
2. 不要用多个应用同时编辑同一文件。出现占用、锁定或外部变更提示时，先关闭另一个应用。
3. 关闭浏览器标签页前检查标题栏保存状态。
4. 无法获得写权限，或原文件已被外部修改时，使用**另存为**。
5. 自动化写入完成后执行完整校验。

```bash
eidos important.eidos validate --level full
```

## Raw SQLite 访问

可以使用 SQLite 工具检查 Eidos File，但不要直接执行 SQL 写入。直接写入可能绕过版本、字段值、
关系、派生字段和校验规则。修改文件请使用 Runtime 或 CLI。
