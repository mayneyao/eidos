Eidos Sync 用来在自己的设备之间同步 Space。每台设备上得到的仍是普通本地文件夹，
没有网络时也可以打开和编辑。

:::note
同步功能正在小范围测试。加入候补名单后，请以账户页显示的权限为准。
:::

## 首次同步

1. 打开要同步的 Space。
2. 前往**设置 → 账户与服务**，登录 Eidos 账户。
3. 开启本地版本管理，并在**变更**中保存一个版本。
4. 点击标题栏中的**同步**。
5. 检查将要同步的内容，然后确认连接。

首次上传完成后，这个 Space 会出现在账户的同步列表中。

同步范围是整个 Space，而不只是当前打开的 `.eidos` 文件。确认前，请先移走不希望上传的文件。

## 在另一台设备继续工作

1. 安装 Eidos Lite，并登录同一个账户。
2. 打开**同步**，选择已有的 Space。
3. 选择一个空文件夹作为本地保存位置。
4. 等待下载完成，然后打开 Space。

下载完成后，它和其他本地文件夹一样使用。你可以离线编辑，联网后再同步已保存的版本。

## 同步新的改动

完成一组改动后，在**变更**中保存一个版本。只有保存过的版本会同步；尚未保存的改动只留在当前设备。

打开**同步**可以查看当前状态。如果显示“等待同步”或“稍后重试”，可以继续使用本地文件，
Eidos 会在连接恢复后继续处理。

## 如果两台设备都改过同一内容

Eidos 不会直接覆盖任何一边，而是暂停同步，并在**变更**中列出冲突。

逐项选择要保留的内容，保存合并后的版本，再重新同步。如果暂时不确定，可以先退出处理；
原来的本地文件不会被替换。

## 常见问题

**提示没有同步权限**

前往**设置 → 账户与服务**查看当前权限。加入候补名单不代表已经开通。

**提示先保存版本**

打开**变更**，保存当前改动，再重新同步。

**首次同步无法继续**

按检查结果移走不支持或不希望上传的文件，然后重试。

同步用于在设备之间继续工作，不代替日常备份。关于本地版本和恢复方式，参阅
[历史与恢复](/zh-cn/user-guide/history-and-sync/)。
