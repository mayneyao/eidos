Sync 通过云端在设备之间传递 Space 的改动。
使用它需要账户和符合条件的服务方案。
离线或退出登录后，本地文件仍可使用。

## 连接第一台设备

1. 在 Eidos Lite 中打开 Space。
2. 通过 Settings 登录账户。
3. 打开 Sync 面板并启用 Sync。
4. 等待面板报告完成，或显示需要处理的操作。

连接指示本身不代表全部改动已到达。
切换设备前，检查面板中的状态。

## 在另一台设备上打开

在第二台设备上登录同一账户。
使用同步已有云端 Space 的选项，选择对应 Space，等待初次下载完成。

**检查结果：**打开一个熟悉的文件，确认内容后再开始编辑。

## 检查一次传递

1. 在第一台设备上做一个容易辨认的小改动。
2. 等待 Sync 完成。
3. 在第二台设备上打开文件，确认改动。

这能帮助你确认两台设备连接的是预期的 Space。

## 离线工作

断网时可以继续编辑本地文件。
网络恢复后检查 Sync 面板。
如果 Sync 要求检查改动，先查看报告的内容，并按提供的步骤处理，再继续操作。

## 单独保留备份

Sync 会传递改动，也可能传递不需要的编辑或删除。
请保留独立[备份](/zh-cn/user-guide/data-safety/)。

当前方案和存储额度以[账户面板](https://eidos.space/account)为准。
无法继续使用 Sync 不会移除设备上已有的本地文件。
