title: 同步
description: 选择同步方式，并按独立操作指南完成设置。
---

同步让每台设备保留一份 Space 本地副本，断网时仍可使用本地文件。

## 选择同步方式

| 你想做什么                   | 操作指南                                               | 需要什么                                    |
| ---------------------------- | ------------------------------------------------------ | ------------------------------------------- |
| 在同一局域网内同步手机与电脑 | [局域网同步](/zh-cn/recipes/sync-lan/)                 | Lite、移动端应用和同一局域网，无需云端账号  |
| 通过官方服务同步多台电脑     | [Eidos Sync](/zh-cn/recipes/sync-eidos/)               | 具有 Sync 权限的 Eidos 账号                 |
| 使用自己的服务器同步电脑     | [连接自托管服务器](/zh-cn/recipes/sync-custom-server/) | 每台电脑激活 Spark，以及兼容的 Graft 服务器 |

还没有服务器？先按[在 Cloudflare 部署 Graft](/zh-cn/recipes/deploy-graft-cloudflare/)完成一键部署和首次设置。

## 连接后怎么用

打开 Space 的 **Sync** 面板，选择 **Cloud sync** 或 **LAN sync**。
云端同步通过 **Server** 选择 Eidos Sync 或已保存的服务器，支持 macOS、Windows 和 Linux。
每个 Space 同时使用一个云端服务；局域网共享可以独立开启。

**Versions** 管理本地改动和版本历史，**Sync** 管理连接、传输和冲突。
云端连接建立后，按[云同步日常操作与恢复](/zh-cn/recipes/manage-cloud-sync/)发送和接收版本、处理冲突或恢复访问。

## 保留独立备份

同步也会把删除操作传到其他设备，不能替代[独立备份](/zh-cn/user-guide/data-safety/)。
云端同步的端到端加密保护远端副本，不会加密本地文件夹。
