title: 同步

同步让每台设备保留一份 Space 本地副本，断网时仍可使用本地文件。

## 选择同步方式

| 你想做什么                   | 操作指南                                               | 需要什么                                    |
| ---------------------------- | ------------------------------------------------------ | ------------------------------------------- |
| 在同一局域网内同步手机与电脑 | [局域网同步](/zh-cn/recipes/sync-lan/)                 | Lite、移动端应用和同一局域网，无需云端账号  |
| 通过官方服务同步多台电脑     | [Eidos Sync](/zh-cn/recipes/sync-eidos/)               | 具有 Sync 权限的 Eidos 账号                 |
| 使用自己的服务器同步电脑     | [连接自托管服务器](/zh-cn/recipes/sync-custom-server/) | 每台电脑激活 Spark，以及兼容的 Graft 服务器 |

还没有服务器？先按[在 Cloudflare 部署 Graft](/zh-cn/recipes/deploy-graft-cloudflare/)完成一键部署和首次设置。

## 连接后怎么用

打开 Space 的 **Sync** 面板，选择 **Cloud sync** 或 **LAN sync**。
云端同步通过 **Server** 选择 Eidos Sync 或已保存的服务器，支持 macOS、Windows 和 Linux。
每个 Space 同时使用一个云端服务；局域网共享可以独立开启。

**Versions** 管理本地改动和版本历史，**Sync** 管理连接、传输和冲突。
云端连接建立后，按[云同步日常操作与恢复](/zh-cn/recipes/manage-cloud-sync/)发送和接收版本、处理冲突或恢复访问。

## Lite 自动同步

在 **设置 → 账号与服务 → Sync → 自动同步** 中选择：

- **每 10 分钟**（默认）：大约每十分钟同步已打开并连接的 Space。
- **变更后**：已保存的变更经过短暂等待后同步，同时仍每十分钟检查远端更新。
- **关闭**：在 Sync 面板手动发送和接收版本。

默认设置也适用于已有连接和自定义服务器。它不会为仅在本地使用的 Space
建立连接，也不会同步窗口已关闭的文件夹。Lite 在前台时等待三十秒无交互，
转到后台后等待一个短暂间隔；使用其他应用不会阻止后台同步。
休眠和错过的同步周期不会积累成待执行任务。

自动同步先按手动检查点相同的忽略规则，为已保存的变更建立本地检查点，
再检查远端并发送或接收版本。任意标签页中的未保存文本草稿都会让自动同步等待。
离开电脑前请保存草稿，以便将这些改动同步。

回到 Lite 或操作键盘、鼠标时，后台扫描和传输会取消。已开始替换本地文件的快进
必须先完成验证并安全重开文件，随后才能继续编辑；这个本地安全步骤不能中断。
手动同步优先于自动任务。

网络和临时服务器错误会按逐渐增加的间隔重试，本地退避最长十五分钟；服务器要求更长冷却期时会遵守。
密码、账号、容量和历史冲突会显示在现有 Sync 面板中，自动同步不会处理分叉历史，
也不会弹出恢复对话框。在面板中解锁、恢复权限或处理冲突后，手动同步一次即可恢复自动任务。

挂起的传输若需要重启后台进程，会丢失仅在当前会话中保留的解锁状态。
设备无法从安全存储恢复已记住的密码时，Sync 面板会要求重新输入密码，本地文件仍可使用。

## 保留独立备份

同步也会把删除操作传到其他设备，不能替代[独立备份](/zh-cn/user-guide/data-safety/)。
云端同步的端到端加密保护远端副本，不会加密本地文件夹。
