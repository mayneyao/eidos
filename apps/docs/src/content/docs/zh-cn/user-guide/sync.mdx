Eidos Sync 让同一个 Space 的已保存版本出现在你的其他设备上。它不会把 Space 变成只能联网使用的云端空间：每台设备上都有一个完整的本地文件夹，离线时仍然可以打开和编辑。

Eidos Sync 是 Eidos 提供的订阅服务。账户需要开通 Sync，并在当前测试阶段获得使用资格，才能连接 Space。本地使用 Eidos Lite 不需要订阅。

:::note
Sync 正在小范围测试。登录账户不代表已经开通，是否可以使用以账户页面显示的权限为准。
:::

## Sync 如何工作

1. 你先在本地文件中工作。
2. Eidos Lite 把一组改动保存为一个版本。
3. 已连接 Sync 的 Space 会在后台上传这个版本。
4. 其他设备检查到新版本后，把它下载到各自的本地 Space。

没有网络时，改动仍然保存在当前设备。恢复网络后再继续同步即可。

## 第一次连接前

开始前请确认：

- 账户已经获得 Sync 权限。
- Space 已开启[版本功能](/zh-cn/user-guide/history-and-recovery/)。
- **Changes** 中的改动已经保存为一个版本。
- 重要内容已经有一份独立备份。
- Space 中没有你不希望上传的文件。

Sync 会处理**整个 Space**，包括其中的 `.eidos` 文件、文档、图片和其他普通文件，而不只是当前打开的文件。没有保存成版本的改动不会上传。

## 连接当前 Space

1. 打开要同步的 Space。
2. 点击窗口右上角的云朵按钮。
3. 如果尚未登录，点击“继续登录（Sign in to continue）”，然后在浏览器中完成登录。
4. 等待“首次上传检查（First upload check）”完成。
5. 处理检查结果，然后点击“连接此 Space（Connect this Space）”。
6. 等待界面显示“同步已就绪（Sync is ready）”。

首次上传可以在后台继续。关闭同步面板不会取消上传，也不影响你继续使用本地文件。

### 看懂首次上传检查

| 检查结果           | 需要做什么                                                                             |
| ------------------ | -------------------------------------------------------------------------------------- |
| **连接前需要处理** | 这些文件会阻止连接。移走过大的文件，删除或替换符号链接，并处理不支持的文件类型。       |
| **上传前请确认**   | 这些文件可能是隐藏文件、疑似包含隐私信息，或体积较大。确认内容适合上传后，勾选确认项。 |
| **不包含**         | 系统文件、临时文件以及被 Space 设置忽略的文件不会上传。                                |

检查页面会显示本次同步的文件数量、总体积和 Eidos File 数量。确认前先查看列表，不要把密码、密钥或其他私密文件放进要同步的 Space。

## 在另一台设备上打开

不要先手动复制 Space。让 Eidos Lite 为这台设备创建本地副本：

1. 在另一台设备安装 Eidos Lite。
2. 在开始页面点击“打开已同步 Space（Open Synced Space）”。
3. 登录同一个 Eidos 账户。
4. 从列表中选择 Space。
5. 选择本地保存位置，等待下载和检查完成。

Eidos Lite 不会覆盖已有文件夹。如果选择的位置不能使用，请换一个空目录后重试。

下载完成后，这个文件夹和其他本地 Space 一样使用。你可以断网编辑，之后再同步。

## 日常同步

已连接的 Space 在保存版本后，会自动把同步任务加入后台队列。手动保存的版本和自动保存的版本都会进入这个流程。

推荐的使用顺序是：

1. 换到另一台设备工作前，先打开同步面板，点击“检查（Check now）”或下载可用更新。
2. 完成本地改动后，打开版本面板，在 **Changes** 中保存版本。
3. 观察右上角云朵按钮；上传可以在后台完成。

如果你刚保存了多个版本，Eidos Lite 会合并等待中的任务，不需要逐个点击上传。

### 常见状态

| 状态                         | 含义与下一步                                            |
| ---------------------------- | ------------------------------------------------------- |
| **Everything is up to date** | 本地与云端一致，可以继续工作。                          |
| **Unsaved changes**          | 当前改动还不是一个版本。先打开 **Changes** 并保存版本。 |
| **Saved versions to upload** | 本地有新版本等待上传，可以立即上传或等待后台任务。      |
| **Updates are available**    | 云端有新版本，先下载再继续编辑。                        |
| **Sync queued**              | 任务已经进入后台队列，无需重复点击。                    |
| **Sync will try again soon** | 网络或服务暂时不可用。Eidos 会重试，本地文件仍然安全。  |
| **Download only**            | 可以下载云端更新，但当前设备的新改动不会上传。          |

## 两台设备修改了同一内容

如果本地和云端从同一个版本开始，各自都产生了新改动，Eidos Lite 会暂停同步，不会直接覆盖任意一边。

1. 在同步面板点击“查看改动（Review changes）”。
2. 在 **Changes** 中打开每个有冲突的文件。
3. 根据文件类型处理冲突：
   - `.eidos` 文件可以按文件、表格、记录或单元格选择保留本地内容或云端内容。
   - 文本文件可以比较本地与云端版本，并保存最终结果。
   - 图片等二进制文件无法自动合并，需要完整保留本地版本或云端版本。
4. 处理完所有项目后，填写合并说明并点击“完成合并（Complete Merge）”。
5. 返回同步面板，继续同步合并后的版本。

这里的 **Local** 是当前设备上的内容，**Hosted** 是云端已有的内容。选择前可以查看共同版本、本地版本和云端版本的差异。

如果不想继续本次合并，可以点击“中止合并（Abort Merge）”。这会退出合并流程，不会替你选择任意一边。

## 不确定时先创建恢复副本

出现冲突后，同步面板提供两个安全出口：

如果冲突编辑器已经打开，请先点击“中止合并（Abort Merge）”，再回到同步面板创建恢复副本。

- **Keep a local copy**：把当前设备上的内容复制成一个不参与合并的新 Space。
- **Open a cloud copy**：把云端内容下载成另一个新 Space。

恢复副本会在新窗口打开，不会覆盖当前 Space。你可以先保留两边，再决定如何整理或合并。

## 权限和存储空间

同步面板的 **Connection** 会显示当前访问状态：

- **Download and upload**：可以接收和上传版本。
- **Download only**：只能接收已有云端内容；新的本地版本会留在当前设备。

**Storage** 会显示云端已用空间、总额度和等待上传的空间。如果当前上传超过额度，点击 **Manage storage** 处理后再试。

本地 Space 的文件大小不一定等于云端计费空间。版本历史和重复数据处理会让两者有所不同，以同步面板显示的云端用量为准。

退出账户不会删除设备上的本地 Space。即使权限到期或服务暂时不可用，本地文件仍然可以继续使用。

## 遇到问题

- **Sync access required**：当前账户尚未开通 Sync，请到账户页面查看权限。
- **Sign in again**：登录状态已过期，重新登录即可，本地文件不会受影响。
- **Manage storage**：云端空间不足，先处理存储额度。
- **Try again**：检查网络后重试；如果已经进入自动重试状态，可以等待下一次尝试。
- 无法打开已同步 Space：换一个空的本地目录，不要覆盖现有文件夹。

问题持续出现时，在同步面板底部点击 **Copy diagnostics**，必要时再打开日志目录，并按照[Eidos Lite 故障排查](/zh-cn/user-guide/troubleshooting/)提供信息。

## Sync 不能替代备份

同步会传递删除和修改，因此不能替代独立备份。重要内容仍应按照[数据、附件与备份](/zh-cn/user-guide/data-safety/)中的方式备份整个 Space。
