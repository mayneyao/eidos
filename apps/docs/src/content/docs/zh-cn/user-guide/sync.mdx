Sync 在每台设备上保留一份完整的本地 Space。

| 连接方式     | 使用条件                                                       | 数据传输路径                               |
| ------------ | -------------------------------------------------------------- | ------------------------------------------ |
| 局域网同步   | 电脑运行 Eidos Lite，手机 App 支持局域网同步，处于同一本地网络 | 手机与电脑之间点对点直接传输。无需云端账户 |
| Eidos Sync   | 拥有同步权限的账户                                             | 通过官方服务传输，使用端到端加密           |
| 自定义服务器 | 每台电脑已激活 Spark，并有兼容的 Graft 服务器                  | 直接通过自己的服务器传输，使用端到端加密   |

离线状态下本地文件完全可用。打开**同步**即可查看当前 Space 的状态与下一步操作。
在侧边栏选择**云同步**或**局域网同步**。在**云同步**的**服务器**中选择 Eidos Sync
或已保存的服务器。已连接的 Space 在面板中显示服务器；点击 **⋯** 可管理连接和服务器。

每个 Space 同时使用一项云端服务。局域网共享独立运行，既可以与任一云端服务同时使用，
也可以完全不连接云端。设置完成后，**在其他设备上使用**会引导你在另一台电脑打开已有连接。
点击底部菜单中的**同步设置**，即可管理对应的账户、容量和断开连接等操作。
通过**管理服务器**添加或编辑自定义服务器配置。

本地改动、已保存版本和版本历史统一在**版本**中管理。同步侧边栏显示连接与传输状态、
上传和接收操作，以及需要处理的冲突或恢复步骤。

本教程首先介绍局域网同步。

## 配对手机与电脑

1. 将两台设备连接至同一个局域网（例如家庭 Wi-Fi）。在配对和传输期间，保持电脑端 Eidos Lite 运行且手机端保持在前台。系统提示时，授予本地网络权限。
2. 在电脑端打开 Space 的**同步**，选择**局域网同步**。按提示开启此电脑的局域网服务。
3. 选择配对新设备并显示配对码。无需打开 Space 时，也可以通过**设置 → 设备**配对。
4. 在手机端打开 **同步** 面板，点击 **扫描配对二维码**。或选择 **使用配对码** 手动输入代码。
5. 当手机显示 **等待电脑授权** 时，在电脑端核对设备名称并点击允许。

若授权窗口被遮挡，可通过系统通知回到 Eidos Lite。
配对码有效期为 5 分钟。
若配对码过期或被拒绝，请重新生成并重试。

配对仅允许访问你显式开放共享的 Space。
所有数据传输均通过绑定设备公钥身份的端到端加密通道完成。

## 开放 Space 并下载至手机

1. 在电脑端 Eidos Lite 中打开需要共享的 Space。
2. 打开**同步 → 局域网同步**，按提示将此 Space 共享给已配对设备。
3. 在手机端的 **同步** 页面选择已配对的电脑。在 **这台电脑的 Spaces** 列表中，点击对应 Space 旁的 **下载**。
4. 等待首次全量下载完成。下载完成后该 Space 会显示在 **资料** 列表中，支持完全离线使用。
5. 正式使用前，请打开常用笔记或表格记录，检查附件是否完整。

手机端拥有完全独立的本地副本。
若首次下载意外中断，系统不会显示未就绪的 Space。
请在同步页面重新点击下载。
若需共享其他 Space，仅需在电脑端开启并直接在手机端下载，无需重复配对。

部分文件可能依赖电脑端专属特性。
手机端会完整保留这些原始文件，即使当前无法直接预览或编辑。

只要 Eidos Lite 在后台运行，切换 Space 或关闭窗口不会中断共享。
退出应用会停止局域网服务。
重启 Eidos Lite 后，会恢复已开启的局域网服务和仍可访问的共享 Space。
主动关闭局域网服务后，应用不会在重启时恢复，直到你再次开启。
系统会保留已授权的设备列表。

## 双向同步文件改动

局域网同步由手机端手动触发。
本地文件保存不会自动推送改动至另一台设备。

1. 完成文件编辑并确保保存。
2. 在手机端打开 **同步**，选择目标电脑，点击对应 Space 旁的 **同步**。
3. 保持两台设备连接，直到同步完成。查看传输进度、传输字节数与最新同步时间戳。
4. 在另一台设备上打开修改过的文件，检查内容是否一致。

首次使用建议进行双向验证：在电脑端修改测试笔记，从手机端发起同步并检查。
然后从手机端修改该笔记，再次同步并在电脑端检查。
在线状态指示仅代表网络连通，请等待传输进度全部完成。

## 离线工作与冲突处理

你可以完全在离线状态下编辑已下载的文件。
当两台设备重新连接至同一网络后，从手机端发起同步。
如需中止，点击 **停止同步** 取消当前传输。
不要通过删除本地 Space 的方式来排查传输问题。

电脑端会自动合并无冲突的并发改动。
若两端修改了同一条记录发生冲突，手机端会保留本地文件。
手机端会引导你前往电脑端的 **Sync** 面板解决冲突。
在电脑端解决冲突后，再从手机端发起同步。
等待期间手机上的新编辑会包含在下一次同步中。

关于连接报错排查，请参阅[局域网同步故障排查](/zh-cn/user-guide/troubleshooting/#局域网同步无法连接或找不到-space)。

## 停止共享与解除设备配对

- 打开**同步 → 局域网同步**并停止共享，仅关闭当前 Space 的访问。
- 在 **设置 → 设备** 中关闭 **局域网服务**，可停止所有局域网数据传输。已配对关系继续保留。
- 点击 **解除配对** 可吊销设备访问权限。解除配对会保留已下载的本地文件与历史。重新连接需要重新走配对流程。

## 使用云端同步

macOS、Windows 和 Linux 上的 Eidos Lite 均支持端到端加密云同步。

官方 Eidos Sync 使用端到端加密，通过 Eidos 账户连接各台电脑上的独立本地副本。
你需要拥有同步权限的账户。离线时，本地文件仍然可用。

### 连接第一台电脑

1. 在 Eidos Lite 中打开需要同步的文件夹。
2. 打开**同步 → 云同步**，选择 **Eidos Sync**，登录有同步上传权限的账户。按提示点击**启用本地版本**，即可在当前设置流程中完成准备。
3. 查看文件数量、大小和不包含的文件。
4. 按提示设置并确认**同步密码**。将其保存在密码管理器中，另一台电脑需要使用相同密码。同步密码与 Eidos 账户密码相互独立。
5. 点击**连接这个 Space**并等待首次上传完成。面板会返回当前 Space 的同步状态。

首次同步开始后，设置表单会替换为当前阶段。关闭面板后可以继续工作，重新打开仍显示
同一项任务。展开**同步详情**可查看传输信息；连接失败时，面板会显示原因和对应的恢复操作。

已有连接的 Space 可在**云同步**中选择另一项服务并配置。确认连接新服务之前，
面板仍会标明当前连接。

macOS 以及使用受支持系统密钥环的 Linux 可以在本机记住密码。
Windows 或无法保存密码的环境需在重启后重新输入。同步密码不会发送给同步服务端。

隐藏文件以及 `secret-garden.jpg` 这样的文件名都会按普通文件处理，不需要额外确认。
文件检查只会拦截不支持的条目、符号链接和大于 1 GiB 的单个文件。
忽略规则会排除尚未进入版本历史的文件；将已有版本记录的文件加入 `.graftignore`，
不会移除已保存历史，也不会停止包含该文件。

### 在另一台电脑打开

在第一台电脑选择**同步 → 云同步 → 在其他设备上使用**，即可查看当前连接的使用指引，
不会修改同步服务。

1. 在 Eidos Lite 中登录同一个 Eidos 账户。
2. 打开 Space 菜单，选择**打开已同步空间**，再选择云端 Space。
3. 输入这个 Space 的同步密码。如果已在**设置 → 账户与服务 → 同步**中保存相同密码，Lite 可直接使用。对于使用其他密码的 Space，选择**输入其他同步密码**。
4. 选择一个新的目标文件夹，等待下载完成。
5. 打开一条已知记录和一个附件，检查恢复的副本后再开始编辑。

密码错误不会生成一个未完成的本地 Space。请使用这个 Space 建立连接时的密码重试。
重新登录或重置账户密码都不会改变同步密码。

### 发送和接收改动

云端上传和下载时，Lite 会显示已传输字节数；当传输总量已知时，还会显示百分比。
准备等总量未知的阶段使用活动指示。传输达到 100% 后，验证和本地文件准备仍可能继续；
请等待同步完成后再关闭应用。

保存文件会更新本地副本。打开**版本**，核对并选择改动的文件，再点击**保存所选文件**，
将它们记入本地历史。返回**同步 → 云同步**，上传已保存的版本。
后台检查用于发现远端更新，不会上传改动。

在另一台电脑上，如果面板显示版本已是最新，可以点击**立即同步**。
Lite 会检查远端，并在需要时接收或上传已保存的版本。否则，点击**检查远端更新**，
再按面板提示接收版本。接收前请先将本地改动保存为版本。
离线或尚未检查的 Space 不能证明两份副本一致，应等待面板显示版本已是最新。

如果两台电脑分别保存了不同改动，同步会要求你检查合并结果。
核对文本或记录选择，保存结果后再上传。二进制文件需要选择保留哪一份，或分别保存副本。
不要通过删除某个 Space 来消除冲突。保留本地工作的方式见[历史与恢复](/zh-cn/user-guide/history-and-recovery/)。

### 断开云端同步

在 Space 的**同步 → 云同步**面板中打开当前连接旁的**同步设置**，点击**断开云端连接**并确认。
本次操作会解除这台电脑的连接并清除待运行的后台检查。本地文件、未保存为版本的改动和
Graft 历史保留在原文件夹内。云端副本及其他电脑的连接不会被删除。

离线、退出登录或云端仓库已被删除时，也可以断开连接。
需要创建另一份云端副本时，在同一目录重新启用同步即可。
Lite 会使用同步密码上传本地已保存的历史，无需复制或改名文件夹。
其他电脑需要打开新的云端 Space，不会自动切换连接。

### 密码和恢复

**设置 → 账户与服务 → 同步**中的密码是这台电脑为新 Space 使用的默认密码。
每个 Space 仍有独立的加密密钥。修改此设置只影响新连接，**不会**修改已有云端 Space 的密码。
Lite 目前不提供单个 Space 的密码更换操作。修改默认密码时，请保留已有 Space 使用过的密码。

如果忘记同步密码，已经下载到电脑上的文件仍然可读，也可以备份。
仍记得密码的电脑可能继续同步。在重装应用或清除应用数据前，请先保留该电脑上的本地文件。
Eidos 无法找回密码，也无法代你解密云端副本。如果既没有可用本地副本，也没有密码，
重置账户密码无法恢复加密内容。

退出 Eidos 账户会停止官方同步访问并清除其已解锁会话，不会删除本地文件，也不会断开
自定义服务器。退出 Lite 可清除所有服务的当前同步会话。
同步需要再次解锁时，Lite 可以使用安全保存的密码，或提示你重新输入。
端到端加密保护云端副本，不会加密本地文件夹、SQLite 文件或附件。
请使用操作系统的磁盘加密保护丢失的电脑。

### 服务端能看到什么

文件内容、文件路径、版本说明和分支名称会在上传前加密。
服务端仍能看到账户、云端 Space 显示名称、仓库标识、存储字节数、请求时间，
以及用不透明标识表达的版本关联。因此，不要在云端显示名称中填写保密信息。
加密不会隐藏全部活动，也不能代替独立备份。

Sync 服务不会收到解密密钥，无法读取加密内容。
该保护不适用于你另外发送到 Eidos Publish 的内容。

云端存储包含版本历史及加密产生的额外数据，可能大于当前本地文件夹的大小。
删除当前文件不会立即移除它的历史副本或释放对应配额。
可在[账户控制台](https://eidos.space/zh/account)查看存储和访问限制。
如果配额或账户权限阻止上传，可继续在本地工作，解决限制后再重试。

### 删除云端仓库

打开[账户 → 同步 → 仓库](https://eidos.space/zh/account?tab=sync&view=repositories)，
核对仓库名称和创建日期，点击**删除**，再确认永久删除。
清理完成前会显示**正在删除…**；如果清理仍在后台进行，可刷新页面查看最新状态。
云端清理完成后，存储用量会相应更新。

删除仓库会永久移除其中全部云端文件和版本历史，无法撤销。
各台电脑的本地文件和本地历史仍然保留，其他设备已经下载的副本也不会被远程删除。
已删除的连接不能继续上传或下载。从电脑移除本地副本前，请先备份需要保留的内容。
删除仓库不会取消订阅。

## 使用自定义服务器

macOS、Windows 和 Linux 上的 Eidos Lite 支持通过 Spark 连接自定义服务器。
每台电脑沿用现有 Spark 激活，服务器不占设备名额，也不要求官方 Sync 订阅。

使用[个人 Graft Cloudflare 模板](https://github.com/eidos-space/graft-cloudflare)，
或兼容其服务发现和仓库管理 API 的服务。Lite 只连接端到端加密仓库。
通用 Graft 协议端点不一定提供 Lite 所需的仓库列举和创建 API。

### 添加服务器

1. 在本机的**设置 → 账户与服务**激活 Spark。如果 Spark 已激活但新功能仍锁定，
   点击**刷新 Spark 权益**。
2. 部署服务器，将 HTTPS 地址和访问密钥保存在密码管理器中。
3. 按需启用本地版本历史，将要上传的改动保存为版本。
4. 打开**设置 → 账户与服务 → 同步 → 添加服务器**，填写名称、
   **服务器地址**和**访问密钥**，点击**测试并保存**。保存时会验证访问权限，并将配置保存在本机。
5. 返回同步面板，在**服务器**中选择已保存的服务器；已有连接时使用**切换服务器**。
   如有需要，在同步设置中设置同步密码，然后点击**连接**或查看切换方案。
   等待加密上传和验证完成。

选择另一项云端服务或保存服务器配置，不会改变现有连接。
在**管理服务器**中可以编辑名称、更新访问密钥、移除本机保存的配置。
移除配置不会删除远端数据。更换地址时，应添加一个新服务器。

服务器访问密钥用于授权访问，同步密码用于解密 Space，两者互相独立。
Lite 不会将同步密码发送给服务器，也不会将服务器密钥发送给 Eidos 账户服务。
服务器地址必须使用 HTTPS。

个人模板的所有仓库和设备共用一个访问密钥。更换密钥后，需要在每台电脑更新，
但不会改变 Space 的同步密码或加密身份。

### 在另一台电脑下载

在另一台电脑激活 Spark，再添加相同服务器地址和访问密钥。
选中加密 Space，点击**下载**，输入这个 Space 的同步密码，选择新的目标文件夹，
等待下载完成。编辑前先检查一条已知记录和一个附件。

之后按前文的步骤检查更改、上传、接收更新和处理冲突。
每个 Space 同时连接一个云端服务，不同 Space 可以使用不同服务器。

### 授权与更换服务

已有 Spark 用户成功刷新一次权益即可领取此功能。之后本机可以离线验证签名授权，
退出 Eidos 账户后仍可使用；日常自定义同步直接访问自己的服务器。
释放本机 Spark 授权后会停止后续自定义同步操作，本地文件、历史和服务器数据仍保留，
也可以继续断开连接。

更换 Space 的同步服务前，请保留完整本地副本与历史。打开**同步 → 云同步 → ⋯ → 切换服务器**，选择目标服务。
配置目标服务，点击**确认切换方案**，再确认切换。
Lite 会创建新的加密仓库并上传已保存历史。不要直接替换旧远端 URL，或将服务器密文对象
复制到另一个仓库。先在另一台电脑下载、检查新副本，再考虑删除旧服务器上的副本。
其他电脑需要各自连接新的仓库。
当前连接与目标服务器会分别显示；取消操作会保留原连接。
上传失败时，Lite 会恢复原连接；若本机未保存原同步密码，可能需要重新解锁。
切换过程中应用意外退出时，重新打开 Space 会恢复未完成的本地连接操作。

自定义服务器适用所选服务商的存储和请求限制。官方 Sync 的账户配额与账户网页的仓库
删除入口不管理你的自定义服务器。请遵循服务器自己的运维指南，并保留独立备份。

## 始终保留独立备份

任何双向同步机制都可能将误删除同步至其他关联设备。
请始终保持独立的离线[数据备份](/zh-cn/user-guide/data-safety/)。
