发布功能把 Space 中选定的内容生成托管页面。
发布完成后，你的电脑可以离线。
本地编辑只有重新发布后才会更新到网页。

## 发布文件

1. 在侧边栏右键 Markdown 或 Eidos File。
2. 选择 **Publish…**。
3. 设置网址路径和访问方式。
4. 检查内容后选择 **Publish**。
5. 打开返回的链接，检查结果。

| 访问方式 | 谁可以打开 |
| --- | --- |
| Public | 可以访问该网址的人 |
| Password | 提供密码的访客 |
| Private | 已登录的发布者 |

可用方式取决于内容和服务方案。
发布的 Eidos File 对访客只读，浏览页面不会编辑你的本地文件。

## 收集表单回复

1. 在表中创建 Form 视图。
2. 打开 Eidos File 的 **Publish…**。
3. 在 **Publish as** 中选择表单。
4. 配置提交权限并发布。
5. 在托管表单中提交一条测试回复。
6. 回到 Lite，打开 **Manage Publish…**，选择 **Collect now**。

**检查结果：**本地表中出现提交的回复。
发布表单和收集回复是两个独立操作。

## 普通文件与插件 View（staging 预览）

staging 构建可以把普通文件发布为下载链接。
如果已启用的插件提供兼容的只读 file View，
可以在 **Publish as** 中选择它，把文件呈现为网页。

此 Pro 预览将源文件和插件一起保存为快照，两者分别限制为 16 MiB。
View 只能读取已发布的文件，访客无需安装插件。
详见 [CLI 兼容要求](/zh-cn/cli/publish/)。

## 更新或移除页面

本地内容变化后，打开 **Manage Publish…** 重新发布。
重新发布会更新原网址上的内容。
不再需要页面时，通过管理操作取消发布。

**检查结果：**每次操作后打开网址，确认状态符合预期。

## 检查服务权限

发布需要符合条件的账户和方案。
可用功能及当前额度以[账户面板](https://eidos.space/account)为准。

需要分享可编辑的本地文件时，请看[数据存储与附件](/zh-cn/user-guide/data-safety/)。
