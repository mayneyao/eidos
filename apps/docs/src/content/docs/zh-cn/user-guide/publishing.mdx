Eidos Publish 用来分享 Space 中的一个指定文件。发布完成后，内容会有一个固定网址；你可以关闭 Eidos Lite，电脑也不需要保持在线。

Eidos Publish 是 Eidos 提供的订阅服务。账户开通 Publish 后，才能发布和更新线上内容。本地使用 Eidos Lite 不需要订阅。

可以发布：

- `.eidos` 文件：发布为可浏览的只读文件，或发布其中的表单视图。
- `.md`、`.markdown` 文件：发布为网页。

Publish 与 Sync 分别开通，开通其中一项不会自动开通另一项。

## 发布一个文件

1. 在左侧文件列表中右键点击要发布的文件。
2. 选择 **Publish…**。
3. 在 **Resource slug** 中设置网址路径。
4. 在 **Access** 中选择访问权限。
5. 点击 **Publish**。

发布完成后，可以在进度面板中复制链接或直接打开网页。

发布 `.eidos` 文件时，如果 **Publish as** 显示为 **Interactive Eidos File**，访客可以浏览其中的数据和视图，但不能修改你的本地文件。

## 设置访问权限

- **Public**：任何获得链接的人都能打开。
- **Password**：需要输入你设置的密码。
- **Private**：只有登录后的发布者可以打开。

密码保护和私有访问是否可用，取决于当前 Publish 套餐。

## 更新已发布内容

修改本地文件不会自动改变线上内容。需要更新时：

1. 右键点击原文件。
2. 选择 **Manage Publish…**。
3. 找到已有的发布项，点击重新发布按钮。

重新发布后，原网址保持不变。

## 发布表单

`.eidos` 文件中存在表单视图时，可以把其中一个表单发布出去：

1. 右键点击这个 `.eidos` 文件，选择 **Publish…**。
2. 在 **Publish as** 中选择要发布的表单。
3. 选择谁可以填写，以及是否允许同一账户多次提交。
4. 设置网址和访问权限，然后点击 **Publish**。

表单回复先保存在 Publish 服务中，不会自动写入本地文件。需要导入回复时，打开 **Manage Publish…**，在对应表单旁点击 **Collect now**。

修改表单问题或字段后，需要重新发布，线上表单才会更新。

## 附件如何发布

附件仍然是 Space 中的独立文件，不在 `.eidos` 文件里面。发布时，Eidos 会查找源文件引用的附件，并把需要的文件一同上传。

为了让 Eidos 正确找到附件，请把它们放在源文件所在目录或其子目录中，并保持原来的相对路径。发布只包含所选文件及其引用的附件，不会公开整个 Space。
