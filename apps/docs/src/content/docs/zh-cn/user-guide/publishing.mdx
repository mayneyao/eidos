发布功能将 Space 中选定的内容生成在线托管网页。
发布完成后，你的电脑可以安全离线。
本地编辑只有在重新发布后才会更新到在线网页。

## 发布单个文件

1. 在侧边栏右键点击目标文件。
2. 选择 **Publish…**。
3. 设置网址访问路径与权限模式。
4. 检查内容后点击 **Publish**。
5. 打开生成的链接，检查发布效果。

| 访问模式 | 允许访问的人群         |
| -------- | ---------------------- |
| Public   | 拥有该网址链接的任何人 |
| Password | 输入正确访问密码的访客 |
| Private  | 仅限已登录的发布者本人 |

可用模式取决于文件类型与你的服务方案。
已发布的 Eidos File 对外只读。
访客浏览网页不会修改你本地的原始文件。

## 收集表单回复

1. 在表格中创建一个 Form 视图。
2. 打开该 Eidos File 的 **Publish…** 面板。
3. 在 **Publish as** 下拉菜单中选择该表单。
4. 配置表单提交权限并发布。
5. 在托管表单中提交一条测试数据。
6. 回到 Lite 客户端，打开 **Manage Publish…** 并点击 **Collect now**。

**检查结果：** 提交的表单回复出现在本地表格中。
发布表单和收集回复是两个独立的操作步骤。

## 普通文件与插件视图发布

在 **Publish as** 中选择 **Download file**，可将普通文件发布为下载链接。
若已启用的插件提供兼容的只读文件视图（file View），可以选择该视图将文件直接渲染为交互式网页。

此 Pro 特性会将源文件与插件打包保存为版本快照。
每项资源大小限制为 16 MiB。
该视图仅能读取已发布的文件内容。
外部访客无需自行安装插件。
未配置插件视图的文件仍可作为直接下载链接发布。
直接文件下载支持最大 1 GiB 文件，具体受账户配额约束。
详见 [CLI 兼容规范要求](/zh-cn/cli/publish/)。

## 更新或下线页面

本地文件修改后，打开 **Manage Publish…** 重新发布。
重新发布会直接更新原网址上的页面内容。
当不再需要公开页面时，通过管理面板取消发布即可下线。

**检查结果：** 每次操作后打开对应网址，检查页面状态是否符合预期。

## 检查服务权限

发布功能需要有效的账户与服务方案。
可用功能及配额详情请查阅[账户控制台](https://eidos.space/account)。

若需要与他人共享可直接编辑的本地文件，请参阅[数据存储与附件](/zh-cn/user-guide/data-safety/)。
