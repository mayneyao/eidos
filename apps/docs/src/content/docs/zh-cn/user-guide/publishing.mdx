Eidos Lite 可以直接从 Space Explorer 发布 `.eidos`、`.md` 或 `.markdown` 文件。
发布后的资源只读、URL 稳定；发布完成后，无需保持 Eidos Lite 或本机在线。

## 发布前准备

在**设置 → 账户与服务**中登录并开通 Publish。本地构建与预览始终免费，但创建或继续提供
托管 URL 需要有效的 Publish 订阅。Publish 与 Eidos Sync 相互独立。

## 发布文件

1. 在 Space Explorer 中右键点击一个 `.eidos`、`.md` 或 `.markdown` 文件；
2. 选择**发布…**；
3. 输入资源 slug，它会成为分配给你的 `*.eidos.ink` 域名后的访问路径；
4. 选择访问方式，然后点击**发布**。

**品牌标识**设置可以保留当前选择、显示 **Built with Eidos**，或隐藏它。
新资源默认显示该标识。

点击发布后，配置面板会立即收起为左下角的后台任务条。文件校验、摘要计算、上传、
Serving Target 准备和版本激活会继续执行，不会阻止你浏览或编辑其他文件。点击任务条可以展开
查看详细进度，再次点击最小化按钮即可收起。任务完成后可以复制链接或在浏览器中打开；
失败时可展开错误详情并重试。

任务条只表示当前操作。发布成功后，Lite 会在应用私有状态中保存当前 Space 文件、Eidos
账户、Publish 环境与远端资源之间的绑定。关闭任务条或重启 Lite 都不会丢失该关系；再次右键
点击源文件并选择**管理发布…**，即可复制或打开链接、选择目标重新发布，或收集已发布 Form
的回复。Registry 不保存密码或账户 token。

每条已发布资源会显示**已是最新**、**有更新待发布**或暂时无法判断。Lite 只读取 source 与
附件的轻量 metadata 来更新这个状态，打开管理面板不会扫描 1 GiB 文件。再次发布未变化的
资源时，Lite 会向服务端核对保存的完整 Source Bundle fingerprint 和当前 Version；证据一致
后直接完成，不再制作快照、逐字节计算摘要或创建重复 Version 历史。

超过 95 MiB 的 source 或附件对象会自动使用分片上传，无需手动拆分。进度会显示当前对象与
分片，同时整个 Bundle 的已上传字节会持续累计。

发布 Eidos File 时，Lite 会短暂暂停写入并关闭 SQLite Runtime，再复制一致性快照；Markdown
按普通 UTF-8 文档复制。上传和云端准备都读取临时 source。Eidos File 的相对 File 字段附件，
以及 Markdown 的相对链接和图片，都从原源文件所在目录读取、计算摘要、去重并随快照上传。
无论成功还是失败，临时副本都会被删除。

Markdown 会被渲染为不含脚本的静态页面，原始 HTML 不会执行。正文上限为 16 MiB，单个附件
上限为 1 GiB。

已发布的 Eidos File、Markdown 文档和 Form 都会显示紧凑的 **Built with Eidos** 品牌链接。
Markdown 和 Form 在文档底部居中展示；Eidos File 放在表格底栏右侧，不再同时显示文件名、
只读状态或 SQLite 版本等文案。Gateway 会在响应时应用当前品牌设置，因此更新样式不需要
重新发布资源。Publish 可以按资源从 Eidos Lite 或 Publish 账号页隐藏、恢复标识，不会
创建新的内容 Version。

## 发布 Form 并收集回复

先在 Eidos File 中创建 Form View，并保持该文件打开，再选择**发布…**。**发布为**控件会在
完整、只读的 Eidos File 之外列出其中的 Form View。选择 Form View 时只发布公开表单
definition，不会上传目标 Table 的可变副本。

Publish 面板还可以单独控制谁能填写：选择**任何获得链接的人**，或要求填写者先登录
eidos.space。选择登录用户后，可以关闭**允许多次填写**，让每个账户只能提交一次。该填写
策略与资源的公开、密码保护、私有访问彼此独立；重新发布即可调整，不会写入本地 Form View。

访客可以提交受支持的文本、数字、日期、选项、复选框、评分、URL 和 File 字段。已完成的
回复与提交附件会等待在该资源的私有 Publish Inbox。发布任务完成后选择**立即收集**，或者
之后通过**管理发布…**重新进入，都可以把当前等待的回复导入原来的本地文件。Lite 会短暂
关闭该文件的 Runtime，完成导入、校验并重新打开；其他文件仍然可以使用。

发布 Form 的 Lite 实例会成为该资源的 Collector。Lite 不会在后台轮询 Inbox，也不会自动把
回复写入本地文件；需要导入回复时，请从**管理发布…**中选择**立即收集**。如果另一台设备曾
接管该资源，显式收集会由当前设备重新取得 Collector ownership。

文本问题默认使用单行输入框。如果回复需要输入多行内容，可在问题选项中启用**长文本**；
发布后的表单会保留同样的多行输入形式。

每个 Row 与对应导入回执都在同一个 SQLite transaction 中写入。即使网络 ACK 丢失，下次
收集也只会确认已有回执，不会重复创建 Row。附件使用本地 SHA-256 内容存储，相同 bytes
只保存一次。

每次发布都会创建不可变 Form revision。本地 schema 后续变化不会静默修改线上表单；需要
重新发布 Form View 才会激活新 revision。如果本地 Form schema 与接收回复的 revision 不再
一致，收集会停止并明确报告不匹配。

## Slug 与版本

一个 slug 表示一个长期存在的资源。再次把新内容发布到同一 slug，会创建新的不可变
Version，同时保持 URL 不变；source 与附件相同则继续使用活动 Version。选择**保持当前
设置**可保留已有资源的访问方式；新 slug
默认公开。

## 链接到指定表格或视图

在发布 URL 后添加稳定的 Eidos ID，即可直接打开指定表格和视图：

```text
https://{hostname}/{slug}?table={table-id}&view={view-id}
```

`table` 和 `view` 使用 Eidos File 内保存的小写 UUIDv7 ID，而不是显示名称。提供 `view`
时可以省略 `table`，Publish 会找到该视图所属的表格。ID 不存在或已经删除时，会安全回退
到文件的默认表格和默认视图。密码验证和账号私有登录跳转也会保留这些参数。

## 访问方式

| 设置         | 可以访问的人                 |
| ------------ | ---------------------------- |
| 公开         | 任何获得链接的人             |
| 密码保护     | 知道共享密码的人             |
| 私有         | 登录后的资源所属账户         |
| 保持当前设置 | 保留已有设置；新资源默认公开 |

密码长度为 8–128 个字符。Eidos Lite 只通过受保护的主进程边界发送密码，不会把密码加入
命令参数或日志；发布成功后也会从面板状态中清除。

Publish 提供一个独立 Publish 域名、10 GiB 去重后内容存储、每月 5,000 条已完成 Form 回复、
5 GiB Inbox、30 天历史，以及密码与私有访问。单个 Form 提交附件上限为 100 MiB；标准
`.eidos` 文件上限为 256 MiB，source 附件的单对象上限为 1 GiB。需要更高 `.eidos` 上限和
独立 Runtime 容量时，可以联系 Eidos 开通 Custom 方案。资源 slug 数量不作为套餐配额。历史保留期从活动 Version 被替换时开始；
失败或从未激活的 Version 在 24 小时后清理，当前活动 Version 永远不受历史保留期影响。
解释已收集回复所需的 Form 定义快照独立保留。最新额度以账户页和价格页为准。

如需使用可读域名，请打开 Publish 账号页，在 **Publish 域名**中输入符合规则的 Handle 并
认领。Handle 属于 Publish Site，不会修改账户 username。Staging 使用
`handle-staging.eidos.ink`，production 使用 `handle.eidos.ink`；系统分配的 `u-*` hostname
会继续作为稳定后备地址，并重定向到当前规范域名。

## 常见问题

**提示“登录后才能发布”**

点击发布面板中的登录操作，或前往**设置 → 账户与服务**登录后重试。即使没有启用 Sync，
Publish 仍需要 Eidos 账户。

**已达到 Publish 存储上限**

删除不需要的未激活 Version，或减少数据库/附件体积。相同内容只计量一次；需要更高总存储
时可以点击**查看套餐**。

**本地附件无法发布**

确认链接或 File entry 使用目录内相对 URI，附件仍位于源文件旁的对应路径，并且路径中没有
符号链接。Eidos File 附件还必须与声明大小一致。

**提示 Publish engine 不可用**

请安装当前版本的 Eidos Lite。源码构建还需要编译 `apps/cli`；正式安装包会自动包含匹配的
发布引擎。

终端与自动化用法见[发布文件](/zh-cn/cli/publish/)。
