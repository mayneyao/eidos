Eidos Publish 可以把 Space 中的一个文件发布到固定网址。发布后，你可以关闭 Eidos Lite，
也不需要让电脑保持在线。

发布和同步相互独立。使用前，请在**设置 → 账户与服务**中登录并开通发布服务。

## 发布一个文件

1. 在左侧文件列表中找到要发布的 `.eidos`、`.md` 或 `.markdown` 文件。
2. 右键点击文件，选择**发布…**。
3. 设置访问地址，并选择**公开**、**密码保护**或**私有**。
4. 点击**发布**。

发布完成后，可以直接复制链接或在浏览器中打开。访客只能阅读已发布的内容，不能修改你的本地文件。

如果文件引用了同一 Space 中的图片或附件，Eidos 会在发布时一并处理。这些附件仍是独立文件，
不会保存在 `.eidos` 文件里面。

## 更新已经发布的内容

1. 在左侧文件列表中右键点击原文件。
2. 选择**管理发布…**。
3. 检查访问地址和权限，然后再次发布。

原来的网址不会改变。访客再次打开时，会看到最新发布的内容。

## 发布表单

1. 在 Eidos File 中创建一个表单视图。
2. 在左侧文件列表中右键点击这个 `.eidos` 文件，选择**发布…**。
3. 在**发布为**中选择表单，并设置谁可以填写。
4. 发布后，把链接发给填写者。

表单回复不会自动写入本地文件。需要收集回复时，右键点击原文件，选择
**管理发布… → 立即收集**。Eidos 会把等待中的回复导入原来的表格。

如果修改了表单的问题或字段，请重新发布，让线上表单使用新的内容。

## 选择访问权限

- **公开**：任何获得链接的人都可以打开。
- **密码保护**：输入正确密码后才能打开。
- **私有**：只有登录后的发布者可以打开。

## 常见问题

**提示需要登录或开通发布服务**

前往**设置 → 账户与服务**，登录并检查发布服务状态。

**附件没有出现在发布结果中**

确认附件仍在 Space 内，并且原文件使用相对路径引用它。

**发布失败或达到额度**

打开任务详情查看原因。当前文件大小和存储额度以账户页与价格页为准。

如果要从终端发布，请参阅[使用命令行发布](/zh-cn/cli/publish/)。
