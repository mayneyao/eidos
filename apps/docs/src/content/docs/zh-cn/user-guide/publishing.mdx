**Eidos Publish** 能让你一键将 Space 中的单个 Markdown 笔记、只读数据表格或信息收集表单发布为可在浏览器中直接打开的在线网页。

发布完成后，你的电脑无需保持开机，访客也不需要安装任何应用或注册账号，即可通过专属链接流畅浏览。

---

## 1. 一键发布文件

1. 在左侧文件树中，右键点击你要发布的文件（支持 `.md` 笔记或 `.eidos` 表格文件）。
2. 在弹出菜单中选择 **Publish…（发布）**。
3. **自定义网址（Slug）**：输入你喜欢的网址后缀（例如 `project-roadmap`）。
4. **访问权限（Access）**：
   - **Public（公开）**：任何获得链接的人均可直接阅读。
   - **Password（密码保护）**：访客输入你设置的密码后方可阅读。
   - **Private（私有）**：仅允许登录后的发布者本人访问。
5. 点击 **Publish** 按钮，几秒钟内即可生成专属的公网链接，点击即可复制并分享给好友或客户。

:::tip[访客无法篡改你的本地文件]
发布 `.eidos` 表格时，线上网页呈现为交互式只读页面。访客可以在网页端自由筛选、排序和查看卡片，但绝无法修改你电脑上的原始本地数据。
:::

---

## 2. 发布表单并收集回复

如果你在 `.eidos` 表格中设计了**表单视图（Form）**，可以将其一键发布到互联网上收集问卷调查、需求登记或活动报名：

1. 右键该 `.eidos` 文件，选择 **Publish…**。
2. 在 **Publish as** 下拉框中，选择你要发布的表单视图。
3. 设置提交权限与个性化网址，点击 **Publish**。
4. 任何访客均可在手机或电脑浏览器中填写并提交表单。
5. 回收数据：在 Eidos Lite 中右键原文件，选择 **Manage Publish…**，点击 **Collect now** 即可一键把线上收集的所有表单回复自动拉取到本地数据表中！

---

## 3. 更新与取消发布

- **安全的手动更新**：你在本地对文件进行的草稿修改不会立刻反映在线上，避免未完成的内容意外泄露。当你准备就绪后，右键文件选择 **Manage Publish…**，点击重新发布即可，**原本的分享网址保持不变**。
- **随时下线**：在 Manage Publish 窗口中点击撤回发布，该网页链接即可立即失效。

---

## 4. 套餐与额度支持

- **Publish Free**：所有已验证邮箱的 Eidos 账户均可免费使用，支持发布多达 10 个公开 Markdown 页面。
- **Publish Pro**：支持发布交互式 `.eidos` 表格、在线收集表单以及开启密码保护等能力。可前往 [账户管理页](https://eidos.space/zh/account) 或 [价格页](https://eidos.space/zh/pricing#publish) 随时开通。
