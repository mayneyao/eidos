在日常整理本地的视频、设计图稿、摄影素材或合同文件时，系统的文件管理器通常只能展示文件名与修改时间，无法直接给文件添加标签、评分、记录审核状态或备忘。

**文件元数据管理**可以将一个普通的本地文件夹以结构化表格的形式打开。你在表格中记录的每一项自定义属性，都会直接保存在物理文件本身上，让你轻松对本地数字资产进行分类、打标与筛选。

---

## 1. 快速上手

开启文件元数据管理只需三步：

1. **新建文件**：在 Eidos Lite 侧边栏中点击新建文件（快捷键 `Cmd/Ctrl + N`），文件类型选择 **Eidos**。
2. **开启开关**：勾选底部的 **文件元数据管理** 开关，文件名为默认的 `files.eidos`（也可重命名为你喜欢的名称），点击**创建**。
3. **开始打标**：打开创建的表格后，点击列头右侧的 **+（添加列）**，输入你要记录的属性名称（如“审核状态”、“星级”或“分类标签”），即可像填写普通表格一样直接为文件录入信息。

---

## 2. 日常使用与文件安全

- **原文件零拷贝，安全无损**：你的所有物理文件依然留在原磁盘目录中。Eidos 既不会生成重复的副本浪费磁盘空间，也不会修改文件本体的原始内容。
- **自动感知磁盘变动**：当你在操作系统中添加、重命名或删除了某个文件，表格会自动感知并实时更新，无需手动刷新。
- **即时全屏预览**：点击记录中的文件或附件图标，即可随时呼出大图或文档预览，无需离开当前工作界面。

---

## 3. 管理范围与作用域

**开启元数据管理的 `.eidos` 文件会扫描其所在文件夹及所有子目录。**

它不会向上扫描父目录，也不会跟随符号链接；被忽略的项目不在扫描范围内。在子目录新建的表格则扫描该子目录及其后代目录。

## 4. 多级文件夹与属性共用机制

在复杂的项目目录中，经常会有多层子文件夹（例如大项目下包含专属的素材子目录）。当父文件夹与子文件夹各自创建了 `files.eidos` 时：

<FileTree>

- 创意项目库/
  - **files.eidos** 包含子目录中的文件
  - 项目规划.pdf
  - 预算明细.xlsx
  - 视觉设计/
    - **files.eidos** 独立管理子目录
    - 主视觉海报.png
    - 矢量标志.svg
    - 产品插画.jpg
  - 参考资料/
    - 竞品分析.md
    - 灵感合辑.png

</FileTree>

### 独立排版，互不干扰
父级文件夹下的 `.eidos` 与子文件夹下的 `.eidos` 是**各自完全独立**的文件：
两边的表格排版、视图模式、过滤规则和排序条件相互独立。子目录无论是否创建 `.eidos` 文件，其中的文件都可能出现在父级表格中。

### 物理文件公用属性字段
由于自定义属性是直接记录在具体物理文件自身的扩展属性中：
- **存储标识决定是否共享**：默认的 `tags` 和 `rating` 字段使用共享存储键。后来新增的字段会获得独立的存储键；仅仅名称相同，不会自动共享值。
- **重命名保留数据**：字段重命名后仍使用原存储键。命名空间和存储键相同的表格，会在下次查询时读到同一份属性值。

### 必须了解的注意事项

1. **编辑会修改文件自身的属性**：使用相同存储键的表格可以读到彼此的修改。显示名称相同不代表数据共享。
2. **移动文件**：同一文件系统内的普通重命名会保留属性。复制或传输是否保留属性取决于文件系统和工具；目标表格需要相同的命名空间和存储键才能读取已有值。
3. **“删除字段”与“清空单元格”的区别**：
   - **删除某一列（字段）**会移除该列，并清理表格所包含文件上的对应属性。这也会影响共享该属性的其他表格；
   - **清空单元格内容**会移除对应文件上的该属性值。
4. **属性随身携带的范围**：
   - macOS/Linux 使用扩展属性，Windows 使用备用数据流，要求文件系统支持。不要假定 Graft 历史、Sync、备份或仅复制 `.eidos` 文件能保留这些外部属性；请单独验证备份工具。
   - 若将文件单独通过某些不支持扩展属性的第三方纯网络工具传输（如微信传输单个文件）或拷入精简格式的 FAT32 介质，附加属性可能会被系统忽略。
5. **事务边界**：进程运行期间，普通事务和保存点回滚会恢复元数据。回滚日志保存在内存中，不提供崩溃原子性，也不能隔离其他程序对同一属性的修改。

## 5. 系统内置只读字段

表格会自动扫描并提供以下底层物理属性（系统只读，无法手动覆写）：

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `name` | 文本 | 物理文件名（如 `Photo.jpg`） |
| `path` | 文本 | 文件在当前文件夹内的相对路径，作为记录标题与唯一标识 |
| `extension` | 文本 / 标签 | 文件后缀名（如 `jpg`、`mp4`、`pdf`） |
| `size` | 文本 / 整数 | 文件大小（自动格式化为易读的 KB、MB、GB） |
| `mimetype` | 文本 | 媒体格式类型（如 `image/jpeg`、`video/mp4`），便于一键筛选同类媒体 |
| `file` | 附件引用 | 本地文件实体引用，用于卡片缩略图生成与点击全屏预览 |
