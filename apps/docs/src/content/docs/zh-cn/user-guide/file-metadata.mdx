**像管理表格一样管理文件，支持自定义字段、筛选和排序。**
文件元数据管理是 Spark 高级特性之一。Spark 是独立于订阅的一次性买断权益。

## 进入文件管理

在 Space 文件树中右键文件夹，选择**管理文件**。
管理整个 Space 时，点击 Space 标题旁的**管理文件**，或右键标题选择**管理文件**。
当侧边栏正在显示子文件夹时，标题操作管理该文件夹。

首次进入时，Eidos 在 Space 中创建 `.eidos/files.eidos`，之后重复使用。
所有文件夹都打开同一份配置。私有目录 `.eidos` 不出现在文件树、文件搜索和管理表格的扫描结果中。
普通**新建文件**创建独立文档。

## 目录范围与共享视图

Space 根目录显示全部受管理文件。子文件夹显示该目录及所有后代目录中的文件。
窗口标题栏中的面包屑显示当前范围，点击上级可扩大范围。
后退、前进和刷新通过页面地址保留目录范围。

字段、字段选项和保存的视图在整个 Space 中共享。
添加状态、星级或标签等字段，即可像操作表格一样编辑单元格。
使用搜索、筛选、排序和字段工具组织视图。

目录范围与所选视图的筛选条件共同生效。
切换文件夹不会改写保存的筛选条件，也不会新建另一份视图。
例如，按“状态 = 已就绪”筛选的视图，从其他文件夹进入后仍只显示已就绪的文件。

## 打开与预览文件

只读 `file` 单元格通过系统查看器打开物理文件。
在行菜单选择**在侧边栏打开**，即可保留表格，在右侧预览文件。
预览沿用配置的打开方式，包括自定义 File View。
本地大文件无需将全部内容读入编辑器；图片缩略图仍有大小限制。

收到文件系统变化通知后，表格会刷新。
扫描不跟随符号链接，并排除原生扫描器忽略的目录，包括 `.graft` 和 `.eidos`。

## 配置与物理文件属性

`.eidos/files.eidos` 保存字段定义、选项和视图。
自定义值保存在物理文件属性中：macOS 和 Linux 使用扩展属性，Windows 使用备用数据流。
编辑自定义单元格修改属性，不修改文件内容字节。
仅复制配置文件不会复制打标结果。

新建自定义字段使用准确的字段名作为存储键。
元数据字段不能重命名；已有的自动生成存储键保留原映射。
共享命名空间和存储键的表格读取同一物理属性。

- 清空单元格会清除单个文件的对应属性。
- 删除自定义字段会清除表格完整扫描范围内文件上的对应属性。目录筛选不会限制结构变更范围，其他共享该键的配置也可能受到影响。
- 同一文件系统内重命名可以保留属性。跨盘复制、备份工具及其他传输方式取决于文件系统与工具的支持。
- 文件内容的历史或同步成功不能证明属性得到保留。备份、恢复和搬运工作流需要单独验证属性保留情况。
- 属性回滚使用内存日志，不提供崩溃原子性，也不能防止其他程序并发修改。

## 已有配置

已有元数据 `.eidos` 文件仍可直接打开使用。
进入 Space 文件管理不会移动、合并或删除它们，也不会导入其字段定义或视图。
如果它们与全局配置共享命名空间和存储键，仍可读取同一物理属性。

## 内置字段

系统字段只读，包括 `name`、`path`、`extension`、`size`、`mimetype`、`file`、创建时间与修改时间。
Space 全局表格中的 `path` 相对于 Space 根目录。
文件系统驱动的 `files` 表格不支持通过普通行操作新建或删除物理文件，也不能作为 Relation 关联的源或目标。
