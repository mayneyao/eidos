在 Eidos Lite 中，可以打开单个文件的**文件属性**，也可以进入**管理文件**，用表格整理整个 Space 的文件。
文件保留在磁盘原位。标签、评分等自定义属性可以同时在属性窗口和管理表格中查看。

## 查看一个文件的属性

1. 在 Space 文件树中右键文件，选择**文件属性**。
2. 在独立窗口的**通用**区域查看类型、文件大小、位置、创建时间和修改时间。
3. 点击位置旁的复制按钮，即可复制文件所在文件夹的路径。

这些基础属性只读，**不需要激活 Spark，也不需要先创建文件管理配置**。
文件系统没有提供创建时间时，该项显示为 `—`。
属性窗口打开后，会随主窗口当前打开的文件切换。

## 添加标签、评分或自定义属性

创建和编辑文件元数据需要在当前电脑激活 **Spark**。Spark 是独立于订阅的一次性买断权益。
未激活时，可以查看基础属性，以及已有配置中的自定义属性；属性窗口会显示只读提示和**激活 Spark**入口。

激活后，可以直接在文件属性窗口添加属性。例如，为文件增加审核状态：

1. 在**自定义属性**区域点击 **+（添加属性）**。
2. 输入名称“审核状态”，类型选择**单选**。
3. 输入“待处理”和“已完成”，每行一个选项，然后创建。
4. 为当前文件选择“待处理”。

新属性的定义在整个 Space 中共享；每个文件分别保存自己的值。
再次打开其他文件的属性窗口，也可以使用“审核状态”。

属性窗口支持文本、数字、整数、复选框、单选、多选、评分、日期、日期与时间、URL。
新配置自带 `tags` 多选和 `rating` 评分字段，也可以直接使用它们。
再次点击当前评分的星级，可以清空可留空的评分。

更改会自动提交，无需点击保存。文本和数值在移开焦点后提交，选项、勾选和评分在操作后提交。
保存失败时，窗口会显示错误及**重试**入口；关闭窗口时也会尝试提交尚未保存的内容。

## 用表格管理文件

在 Space 或当前文件夹标题旁点击**管理文件**，也可以在文件树中右键文件夹，选择**管理文件**。

激活 Spark 后，首次打开文件属性或进入文件管理时，Eidos 会自动创建 `.eidos/files.eidos`，之后重复使用。
不需要手动新建这份配置。默认提供 **All Files** 表格视图和 **Gallery** 画廊视图。

- 从 Space 根目录进入，显示扫描范围内的全部文件。
- 从子文件夹进入，只显示该文件夹及其后代目录中的文件。
- 点击窗口顶部面包屑中的上级目录，可以扩大范围；后退、前进和刷新保留当前范围。

整个 Space 共用同一份字段、选项和已保存视图。
例如，在一个文件夹中添加“审核状态”，其他文件夹也会使用这一定义。
目录范围与视图的筛选条件同时生效；切换文件夹不会改写保存的筛选条件。

已有配置未激活 Spark 时仍可打开、查看、搜索、切换已有视图和浏览目录范围。
新增或编辑属性、更改筛选和排序、调整视图配置需要 Spark。
筛选和排序属于保存的视图设置，搜索框中的临时搜索不修改视图。

## 筛选 Space 文件树

点击 Space 标题旁的筛选图标，再搜索或选择属性。可以从**文件名**、**后缀**或**文件路径**开始；已有文件管理配置中的自定义属性也会显示在同一个选择列表中。

运算符和值使用与表格筛选相同的控件。后缀支持多选，也可以输入 `.md`、`.tar.gz` 等任意后缀。添加更多条件后，选择**全部满足**要求每个条件都成立，**任一满足**则只需满足其中一个。

编辑条件后结果实时更新。包含匹配文件的父目录会保留，尚未展开的文件夹也会参与筛选；当前编辑器保持打开。关闭弹层后，筛选图标显示生效条件的数量，重新打开即可编辑、移除或清空条件。

文件树筛选是临时状态，不会修改表格保存的视图，也不需要激活 Spark。打开筛选不会创建文件管理配置。

## 直接从列标题筛选 MP4 文件

在管理表格中，可以从要筛选的字段直接开始：

1. 点击 `extension` 列标题，打开菜单。
2. 选择**筛选此字段**。
3. 将条件设为**是**，值选择 `mp4`，不带前面的点。
4. 点击**应用**。

表格现在只显示当前目录范围内、同时满足其他已有条件的 MP4 文件。
筛选不会移动或删除文件。要取消筛选，在顶部**筛选**面板中移除对应条件，再点击**应用**。

同样可以从其他列标题添加筛选，或通过顶部的**筛选**、**排序**和**字段**组织视图。
如需长期使用不同条件，可以分别保存视图。更多操作见[用视图查找记录](/zh-cn/user-guide/views-and-querying/)。

## 打开与预览文件

点击 `file` 单元格的打开操作，通过系统默认应用打开文件。
在行菜单选择**在侧边栏打开**，可保留表格，在右侧预览；预览沿用配置的打开方式，包括自定义 File View。
本地大文件通过系统应用打开时，无需先将全部内容读入编辑器。

文件系统中的新增、重命名、删除或属性变化被检测到后，表格会刷新。
扫描不跟随符号链接，并排除 `.eidos`、`.graft` 等私有目录。

## 数据保存在哪里

| 数据                                 | 保存位置                                                      |
| ------------------------------------ | ------------------------------------------------------------- |
| 字段定义、选项、保存的视图与筛选排序 | Space 内的 `.eidos/files.eidos`                               |
| 每个文件的标签、评分等自定义值       | 文件自身的属性：macOS/Linux 扩展属性，Windows NTFS 备用数据流 |
| 文件内容                             | 原来的物理文件                                                |

编辑自定义值不会修改文件内容字节。
`.eidos` 是 Space 的私有目录，不出现在文件树、文件搜索和管理表格的扫描结果中。

新字段使用输入的字段名作为属性存储键，元数据字段不支持重命名。
清空单元格只清除当前文件的对应值。
**删除字段会清除整个表格扫描范围内文件上的对应属性**，不受当前文件夹或视图筛选限制。
共享同一命名空间和存储键的其他配置也可能受到影响。

同一文件系统内重命名可以保留属性；复制、跨盘移动、压缩、备份或其他传输方式是否保留属性，取决于文件系统和工具。
仅复制 `.eidos/files.eidos` 不会备份文件上的标签和评分。
文件内容或配置进入版本历史、完成 Sync，也不能据此认定文件属性已同步或可恢复。
备份和恢复时应单独检查属性是否保留，详见[知道数据保存在哪里](/zh-cn/user-guide/data-safety/)。

## 系统字段与使用限制

系统字段只读，包括 `name`、`path`、`extension`、`size`、`mimetype`、`file`、创建时间和修改时间。
全局表格中的 `path` 相对于 Space 根目录。
自定义属性用于描述文件；文件管理表格不能通过普通增删行操作创建或删除物理文件，也不能作为 Relation 关联的源或目标。

已有的其他元数据 `.eidos` 文件仍可直接打开使用。
进入 Space 文件管理不会移动、合并或删除它们，也不会导入其中的字段和视图。
已有存储键保留原映射；共享命名空间和存储键的配置仍可读取同一文件上的属性。
