## 直接设置属性

在 Eidos Lite 文件侧栏中右键文件或文件夹，选择 **属性**，也可以选中后按 **Alt + Enter**。

属性侧栏默认提供标签、评分和状态，复用表格记录的属性编辑组件，单选和标签选项的颜色也保持一致。打开标签可选择选项；尚未配置选项时，输入标签后按 Enter 添加。文本、数字和评分在离开字段时保存，数字和评分也可按 Enter 保存；状态选中后立即保存。字段旁的清除按钮会移除对应值。保存失败时可重试或放弃修改。

选中多个文件或文件夹后打开属性，可批量修改。值不一致的字段显示“混合值”；应用后只修改该字段，保留其他属性。如果部分项目无法写入，侧栏会列出路径和错误，已成功的修改仍会保留。

文件夹属性属于文件夹自身，不会自动应用到子项或之后创建的文件。

## 添加自定义属性

在侧栏点击 **添加属性**，输入名称并选择文本、数字、评分、复选框、单选或标签。单选和标签的选项用逗号分隔。字段旁的铅笔按钮可编辑定义；已有属性保留名称和类型。

整个 Space 共用根目录的一份 `files.eidos`，属性定义就是其中的字段。首次添加自定义属性时会创建这个文件；默认标签、评分和状态可以在创建前直接设置。侧栏与表格界面共用字段定义和物理文件属性值。会影响已有值的选项修改，需要在表格界面中检查后应用。

属性值保存在各个文件或文件夹的 `space.eidos.meta` 命名空间中，只复制 `files.eidos` 不会复制属性值。

## 管理文件夹下的属性

右键文件夹选择 **管理文件夹下的属性**，或点击该文件夹属性侧栏中的同名按钮。
Eidos Lite 会打开文件夹属性视图，复用表格和画廊界面，只显示该文件夹下的项目，包括嵌套文件夹和空文件夹。首次使用时在 Space 根目录创建共享目录索引，不会在选中的文件夹内创建索引。

使用搜索、筛选、排序和字段管理来组织项目、编辑属性。标题通过 **Space › Projects › 属性** 这样的面包屑显示范围。点击上级文件夹可管理其下项目，点击 Space 名称可查看整个 Space。刷新、前进和后退会保留范围、当前视图及打开的记录。范围不写入共享的保存视图；保存的筛选条件会与文件夹范围共同生效。

在项目的行菜单中选择 **在侧边栏打开**，可保留表格，在右侧查看对应文件。文件沿用你配置的打开方式，包括自定义 File View。

在 Eidos Lite 中，行菜单打开后按住 macOS 的 **Option** 或 Windows/Linux 的 **Alt**，即可显示拖动手柄。拖动操作调整顺序，或选择 **恢复默认顺序**。顺序保存在本机的应用偏好设置中，对所有表格生效。拖动文件预览的标题栏可移动桌面窗口。

点击文件侧栏顶部搜索旁的 **管理文件属性**，可管理当前文件夹；在根目录时管理整个 Space。直接打开 `files.eidos` 会显示整个 Space。已有同名的普通文件不会被覆盖。

## 存储与文件安全

修改属性会写入原生文件属性，保留文件内容。符号链接和 Space 外的路径会被拒绝；Unix 上原生写入还会拒绝具有多个硬链接的文件。

文件系统需要支持原生属性存储：macOS、Linux 使用扩展属性，Windows 使用备用数据流。同一文件系统中的重命名通常会保留属性；复制、备份和传输是否保留取决于所用工具和文件系统。

## SQL 与自定义视图

共享的 `files.eidos` 是标准 Eidos File，支持表格、画廊和自定义视图。可以在 SQL 界面执行高级查询；文件夹范围限定编辑器的数据查询，SQL 查询使用自己明确指定的条件。

已有的文件元数据索引仍可使用，无需迁移属性值。只要命名空间和存储键一致，各索引便读取相同的物理属性。

编辑列会修改物理文件或文件夹的对应属性；清空单元格会移除值。删除自定义列会清除索引范围内项目的对应属性，也会影响使用同一命名空间和存储键的其他读取者。

文件夹也显示为行，包括空文件夹。只读的 `is_dir` 复选框在文件夹行勾选，在文件行未勾选；可用它筛选仅文件夹或仅文件。文件夹的 `file` 附件为空；大小为原生目录项大小，并非递归统计值。名称、路径、扩展名、大小、修改时间等只读字段来自文件系统。
