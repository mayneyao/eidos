在使用 Eidos Lite 的过程中如果遇到疑问或异常提示，可以根据以下常见现象快速对照解决。

---

## 1. 常见问题速查

### 提示“文件正在使用或被锁定”
- **原因**：另一个窗口、外部 SQLite 工具或备份进程正在独占写入该 `.eidos` 文件。
- **解决方法**：关闭其他打开该文件的窗口或外部程序，稍等 2 秒后在 Eidos Lite 中重新打开即可。

### Space 文件夹或文件打不开
- **检查路径与权限**：确认文件夹没有在系统 Finder / 资源管理器中被重命名、移动或放入废纸篓。
- **确认是有效格式**：`.eidos` 文件是包含特殊结构的格式化数据库；手动将一个普通空文本文件改名为 `.eidos` 是无法直接读取的。

### 恢复历史或同步时提示“请先保存当前改动”
- **解决方法**：点击右上角时钟图标打开版本面板，在 **Changes** 中点击 **Save version**（或舍弃不需要的临时改动），保存后再进行恢复或同步操作。

### 不小心误删除了文件，如何找回？
1. **查看系统废纸篓**：从 Eidos Lite 侧边栏删除的常规文件会优先进入操作系统的废纸篓（Trash / Recycle Bin），可直接放回原处。
2. **从版本时光机恢复**：如果开启了版本功能，点击右上角时钟图标，在 **History** 列表中找到包含该文件的历史版本，点击恢复即可还原。

## 2. 常用快捷键速查

| 快捷键（macOS） | 快捷键（Windows/Linux） | 对应功能 |
| :--- | :--- | :--- |
| <kbd>⌘</kbd> + <kbd>N</kbd> | <kbd>Ctrl</kbd> + <kbd>N</kbd> | 快速新建文件对话框 |
| <kbd>⌘</kbd> + <kbd>Enter</kbd> | <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | 在表格下方快速添加新的一行记录 |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | 单元格向右 / 向左流转切换 |
| <kbd>Space</kbd> | <kbd>Space</kbd> | 选中复选框单元格时快速切换勾选状态 |
| <kbd>Esc</kbd> | <kbd>Esc</kbd> | 取消当前单元格编辑并恢复原值 |
| <kbd>⌘</kbd> + <kbd>Z</kbd> | <kbd>Ctrl</kbd> + <kbd>Z</kbd> | 撤销上一步操作 |
| <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> | <kbd>Ctrl</kbd> + <kbd>Y</kbd> | 重做 |

## 3. 导出诊断信息与联系支持

如果遇到了无法排查的界面异常：

1. 前往 **软件设置 → About（关于）**。
2. 点击 **Copy diagnostics**（复制诊断信息）。
3. 如果需要日志文件，可点击 **Show logs folder**。
4. 前往官方社区或 [GitHub Issues](https://github.com/mayneyao/eidos/issues) 提交反馈，并附上你刚才的操作流程与诊断信息。
