先看 Eidos Lite 显示的消息，再按下面对应情况排查。

## 文件正在使用或被锁定

关闭其他正在写入同一文件的窗口或工具，再重试。
消息仍然出现时，检查是否还有进程占用文件。
不要通过删除锁文件或数据库附属文件来绕过提示。

## 无法打开文件或 Space

1. 检查路径是否仍然存在。
2. 检查当前账户是否能读写文件夹。
3. 对于 Eidos File，确认它是通过创建 Eidos File 的方式生成的。

把任意文件改名为 `.eidos` 不会创建所需的表结构。
文件损坏时，先保留副本，再尝试修复。

## 一条记录消失了

清除临时搜索，检查视图筛选条件。
编辑可能让记录不再符合当前视图。
先在未筛选的视图中检查，不要直接认定记录已删除。

## 恢复或 Sync 要求先保存改动

在 **Versions → Changes** 中检查当前工作。
按提示保存版本，再重试操作。
只有确定不需要这些改动时，才选择丢弃。

## 恢复误删文件

先查看操作系统的废纸篓或回收站。
如果没有，再查找包含该文件的版本或独立备份。
确认恢复前阅读影响范围：恢复 Space 不只影响选中的文件。
详见[版本恢复](/zh-cn/user-guide/history-and-recovery/)。

## 收集诊断信息

局域网同步问题可先按下方步骤排查。其他问题或反复出现的同步错误，可以在电脑端收集诊断信息：

1. 打开 **Settings → About**。
2. 选择 **Copy diagnostics**。
3. 记录触发问题的步骤和显示的消息。
4. 在 [GitHub](https://github.com/mayneyao/eidos/issues) 提交问题。

需要日志时，使用 **Show logs folder**。
分享前检查诊断信息和日志是否包含私人路径或内容。

编辑快捷键见[日常编辑](/zh-cn/user-guide/records-and-editing/)。

## 局域网同步无法连接或找不到 Space

1. 确认手机与电脑位于可互相访问的同一局域网，Eidos Lite 正在运行，手机 App 位于前台。检查系统的本地网络权限及防火墙是否允许 Eidos Lite 通信。访客 Wi-Fi 或设备隔离可能阻止互相访问。
2. 在电脑检查 **设置 → 设备 → 局域网服务**，再检查目标 Space 的 **Sync → 局域网同步** 是否开启。配对本身不会开放 Space；重启应用后需要重新开启共享。
3. 在手机选择正确的电脑，从菜单点击 **刷新设备状态**。电脑在线时，也可能尚未开放对应 Space。
4. 如果配对停在等待授权，检查电脑弹窗或 **设置 → 设备**。配对码过期后生成新码；无法使用相机时，改用复制的配对码。

## 局域网下载超时或校验失败

保留电脑上的源 Space 和手机已有的本地副本。检查连接后，从手机同步页面重试。首次下载未完成时，不能将它当作已下载的可用 Space。不要通过跳过校验、删除数据库、历史或锁文件来强制打开。

如果再次失败，记录完整报错、页面显示的文件和阶段、传输方向、两端 App 版本，以及是首次下载还是后续同步。遇到卡顿时，也记录已等待时间和传输字节量，并附上前述电脑诊断信息。在线状态或字节计数都不代表同步已经完成。

如果手机提示前往电脑处理冲突，打开电脑的 **Sync** 面板检查并解决冲突，再从手机发起同步。详见[同步指南](/zh-cn/user-guide/sync/)。
