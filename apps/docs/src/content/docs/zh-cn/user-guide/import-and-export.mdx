Eidos Lite 支持与通用标准 CSV 格式进行顺畅的数据互通，让你能够轻松将已有的 Excel、Numbers 或其他工具中的表格迁移过来，或者将整理好的数据导出供外部使用。

---

## 1. 从 CSV 导入为新数据表

如果你电脑上已有整理好的表格数据（从 Excel、Google Sheets、飞书等多维表格导出的 `.csv` 文件），可以一键将其导入为 Eidos 数据表：

1. 在当前 `.eidos` 文件中，点击数据表标签栏的 **+**，选择 **导入 CSV**。
2. 选择你要导入的 `.csv` 文件。
3. **配置与确认**：
   - **数据表名称**：默认使用文件名，可自由修改。
   - **记录标题字段**：选择哪一列作为该表的核心标识（如“商品名称”或“客户姓名”）。
   - **字段类型推断**：Eidos 会智能识别各列的类型（数字、日期、文本、复选框等）。如果识别有偏差，可在下拉菜单中手动修正。
4. 点击 **开始导入**，系统会以极快速度将数据转化为结构化记录。

导入完成后，你可以根据需要随时为单选列补充颜色、添加看板视图或建立跨表关联。

---

## 2. 导出当前视图为 CSV

如果你只需要导出当前经过特定筛选或排序后的报表（例如“本月已完成的所有任务”）：

1. 打开目标视图（如“八月报表”）。
2. 点击视图右上角的菜单，选择 **将当前视图导出为 CSV**。
3. Eidos 会严格按照当前视图的可见列、筛选结果和排版顺序生成纯净的 CSV 文件，非常适合直接发送给外部同事或导入统计工具。

---

## 3. 导出整张数据表为 CSV

如果你希望导出该数据表的所有原始记录（不受当前视图隐藏字段或筛选条件的限制）：

1. 打开数据表菜单。
2. 选择 **将整个表格导出为 CSV** 并保存到本地。

---

## 4. CSV 格式与 .eidos 的区别

- **CSV 适合数据交换**：CSV 是通用的扁平纯文本格式，适合在不同系统间迁移纯数据。
- **.eidos 适合完整保存与备份**：CSV 无法记录你的看板布局、画廊封面设置、多条件筛选规则、公式计算逻辑以及附件图片。若需完整备份工作区或分享完整功能给同事，**请直接备份或复制 `.eidos` 物理文件**。
