用 CSV 与其他工具交换表格行。
需要保留文件结构和保存的视图时，使用 Eidos File，并带上它引用的资源文件。

## 导入为新表

1. 将源电子表格导出为 CSV。
2. 在 Eidos File 中打开添加表的菜单，选择 **Import CSV**。
3. 选择 CSV 文件。
4. 检查表名、记录标题字段和推断的字段类型。
5. 开始导入。

**检查结果：**对照源文件检查行数和部分值。
重点检查日期、空值，以及带前导零的编码。
例如，必须保留 `00127` 的前导零时，选择 Text 类型。

CSV 导入不会推断单选字段在创建记录时使用的默认值。
继续操作前，检查导入后的空值。

## 选择导出范围

| 需要什么 | 操作 | 结果 |
| --- | --- | --- |
| 当前视图的报告 | Export Current View to CSV | 视图选中的记录和显示字段 |
| 一张表的全部记录与字段 | Export Entire Table to CSV | 不受视图筛选限制的表数据 |

打开对应的视图或表菜单进行导出。
发送给别人之前，打开 CSV，检查表头和行数。

## CSV 不会保留什么

CSV 保存平面数据值，不会保留完整的 Eidos 表结构、
保存的布局、可继续计算的公式字段定义、关联关系或附件文件。
导出 CSV 不等于完整备份。

保留完整工作请看[数据存储与备份](/zh-cn/user-guide/data-safety/)。
导出前需要调整报告时，查看[视图与筛选](/zh-cn/user-guide/views-and-querying/)。
