CSV 适合交换扁平表格数据，但无法保留所有 Eidos 概念。需要关系、视图、选项目录、公式、历史
或完整附件元数据时，应保留 `.eidos` 文件。

## 把 CSV 导入为新表

选择**导入 CSV**，应用前检查分析结果：

1. 选择 CSV 文件。
2. 确认建议的数据表名称。
3. 选择哪个源列作为记录标题字段。
4. 检查每个字段名称和推断类型。
5. 修正不明确的文本、数字、复选框、日期、日期时间或 URL 类型。
6. 开始导入并观察字节进度，直到完成。

CSV 导入会新建数据表。它不会因为 header 同名就猜测已有字段、修改另一张表，或把一次逻辑
导入静默拆成部分提交的 row batch。

## 理解导入边界

- Header 文本只是建议，不是稳定 Field ID。
- 不会隐式推断单选或多选选项目录。
- 单选的创建默认值不会应用到导入记录。
- 公式、关系、查找和文件语义需要在扁平 CSV 导入后显式建立。
- 无效日期、数字、名称或资源限制会停止校验，不会静默 coercion。
- 取消分析或导入后，应根据结果判断取消是否完成；不能假设关闭 popover 回滚了未知操作。

导入完成后，可以打开字段属性，添加受控选项目录、建立关系并选择更合适的展示设置。

## 导出当前视图

打开视图菜单并选择**将当前视图导出为 CSV**。导出会遵循：

- 视图的筛选和排序；
- 当前存在的临时搜索词；
- 可见字段顺序；
- 通过有界分页读取的全部匹配记录。

关系会输出当前可读标签；文件输出附件名称；多选输出逗号分隔的展示值。这让 CSV 适合人阅读，
但不足以重建稳定关系 ID 或完整 File entry。

## 导出整张表

如果不希望受到视图筛选或隐藏字段限制，打开数据表菜单，选择**将整个表格导出为 CSV**。
把它当作备份前，应先检查下载结果。

## CSV 不是备份格式

CSV 不会保留：

- 稳定的 Table、Field、View 或 Row identity；
- 视图定义和布局；
- 单选颜色与默认值；
- 公式、关系与查找定义；
- 所有歧义文本中精确的逻辑列表边界；
- 作为完整单元的附件 URI、media type、大小和历史。

恢复用途应复制 `.eidos` 文件或整个 Eidos Lite Space，并测试恢复过程。参见
[数据位置与安全](/zh-cn/user-guide/data-safety/)。

## 自动化移动数据后执行校验

脚本或外部工作流生成文件后，执行完整校验：

```bash
eidos imported.eidos validate --level full
```

可重复 pipeline 和 JSON 输出见 [CLI 自动化工作流](/zh-cn/cli/automation-workflow/)。
