记录是表格中的单个数据条目。
同一条记录可以显示为 Grid 表格中的一行、Gallery 画廊中的一张卡片，或 Kanban 看板中的一个卡片项。

## 修改单元格的值

1. 在 Grid 表格中选中目标单元格。
2. 按 **Enter** 键或双击进入编辑模式。
3. 输入新值并提交修改。
4. 检查更新后的数值。

按 **Escape** 键可取消当前正在编辑的内容。
使用 **Tab** 和 **Shift + Tab** 在单元格之间快速移动。
Formula 公式与 Lookup 查找等派生字段不能直接编辑。
请直接修改提供输入的源字段。

## 添加新记录

选择 **Add record** 按钮，或在 Grid 表格中按 macOS 的 **Cmd + Enter**（Windows/Linux 上按 **Ctrl + Enter**）。
在记录标题字段中输入清晰的识别名称。

若新建的记录未出现在当前视图中，请检查视图的筛选条件。
该记录可能不符合当前的筛选规则。

## 批量粘贴单元格数据

从外部电子表格中复制多行多列数据。
在 Grid 表格中选中起始目标单元格并粘贴。
检查各列数据是否正确对齐。
检查日期与数字格式是否准确解析。
对于完整数据集的迁移，请使用 [CSV 导入](/zh-cn/user-guide/import-and-export/)。

## 打开记录详情卡片

使用行首的展开按钮打开单条记录的详情面板。
该面板为长文本字段、关联关系和附件提供更充足的显示与编辑空间。

## 关联另一张表的记录

1. 点击打开 Relation 关联单元格。
2. 在弹出的目标表格中搜索相关记录。
3. 选中该记录完成关联。

关联字段存储目标记录的唯一 ID。
显示的文本标签来自目标表格的记录标题字段。
修改目标记录的标题不会破坏已建立的关联。

## 添加文件附件

使用 File 字段添加文件与图片附件。
具体的导入与预览方式取决于运行 Eidos File 的宿主环境。
移动或复制数据库文件时，请一并带上引用的外部附件。
详见[数据存储与安全](/zh-cn/user-guide/data-safety/)。

## 撤销误操作

在 macOS 上按 **Cmd + Z**（Windows/Linux 上按 **Ctrl + Z**）撤销当前编辑器的操作。
撤销后请检查执行结果。
如需恢复更早保存的文件状态，请使用[版本历史](/zh-cn/user-guide/history-and-recovery/)。
撤销操作不能替代常规的数据备份。
