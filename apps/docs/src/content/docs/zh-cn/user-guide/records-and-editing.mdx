记录是表格中的单个数据条目。
同一条记录可以显示为 Grid 表格中的一行、Gallery 画廊中的一张卡片，或 Kanban 看板中的一个卡片项。

## 修改单元格的值

1. 在 Grid 表格中选中目标单元格。
2. 按 **Enter** 键或双击进入编辑模式。
3. 输入新值并提交修改。
4. 检查更新后的数值。

按 **Escape** 键可取消当前正在编辑的内容。
使用 **Tab** 和 **Shift + Tab** 在单元格之间快速移动。
Formula 公式与 Lookup 查找等派生字段不能直接编辑。
请直接修改提供输入的源字段。

## 添加新记录

选择 **Add record** 按钮，或在 Grid 表格中按 macOS 的 **Cmd + Enter**（Windows/Linux 上按 **Ctrl + Enter**）。
在记录标题字段中输入清晰的识别名称。

若新建的记录未出现在当前视图中，请检查视图的筛选条件。
该记录可能不符合当前的筛选规则。

## 批量粘贴单元格数据

从外部电子表格中复制多行多列数据。
在 Grid 表格中选中起始目标单元格并粘贴。
检查各列数据是否正确对齐。
检查日期与数字格式是否准确解析。
对于完整数据集的迁移，请使用 [CSV 导入](/zh-cn/user-guide/import-and-export/)。

## 打开记录详情卡片

使用行首的展开按钮打开单条记录的详情面板。
该面板为长文本字段、关联关系和附件提供更充足的显示与编辑空间。

在记录中点击属性名，可重命名字段、更改类型或选项、删除字段。这些操作影响整张表的所有记录，
需要写入权限，转换和删除仍需按原流程确认。更改已有字段前请先保存正文草稿。
列表下方的“添加属性”会向表中添加字段，并保留未保存的正文草稿。
悬停属性名时，类型图标会变为拖动柄。
可拖动名称区域，或通过拖动柄使用指针或键盘调整属性顺序。

“在此设备的记录页中隐藏”和属性顺序按文件、表保存在当前设备或浏览器。
列表下方的“另外 N 个属性”可临时展开隐藏项，“收起 N 个属性”会再次折叠它们。
若需持续显示某项，可展开后点击其名称，在菜单中选择“在此设备的记录页中显示”。这些个人偏好不影响视图列。

在表格工具栏的“字段”菜单中，“展开记录 · 此表”控制记录 ID、创建时间和更新时间的显隐。
可选择“隐藏系统字段”“显示系统字段”，或选择“跟随应用默认”恢复继承。
显式表设置保存在文件中，对同表的所有视图生效，不改变当前视图的列勾选。
Eidos Lite 的“设置 → 偏好设置 → 在记录页中隐藏系统字段”提供个人默认；Web 和 CLI Serve
在没有宿主默认时显示系统字段。
这些设置不影响记录标题或 Content 正文。

## 关联另一张表的记录

1. 点击打开 Relation 关联单元格。
2. 在弹出的目标表格中搜索相关记录。
3. 选中该记录完成关联。

关联字段存储目标记录的唯一 ID。
显示的文本标签来自目标表格的记录标题字段。
修改目标记录的标题不会破坏已建立的关联。

## 添加文件附件

使用 File 字段添加文件与图片附件。
具体的导入与预览方式取决于运行 Eidos File 的宿主环境。
移动或复制数据库文件时，请一并带上引用的外部附件。
详见[数据存储与安全](/zh-cn/user-guide/data-safety/)。

## 撤销误操作

在 macOS 上按 **Cmd + Z**（Windows/Linux 上按 **Ctrl + Z**）撤销当前编辑器的操作。
撤销后请检查执行结果。
如需恢复更早保存的文件状态，请使用[版本历史](/zh-cn/user-guide/history-and-recovery/)。
撤销操作不能替代常规的数据备份。
