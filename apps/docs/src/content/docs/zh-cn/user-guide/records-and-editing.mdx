记录是一行带类型且具有稳定 identity 的数据。Grid 单元格、卡片和记录详情面板只是同一行数据的
不同编辑器。

## 新建记录

使用界面中的**添加记录**。在 Grid 中，默认快捷键是 macOS 的 <kbd>⌘</kbd> +

<kbd>Enter</kbd>，其他平台是 <kbd>Ctrl</kbd> + <kbd>Enter</kbd>；Host
可以在设置中 提供快捷键自定义。

创建后，Grid 会聚焦可编辑字段。如果单选字段设置了默认选项，只有创建操作省略该字段时，
Runtime 才会填入。公式、查找、系统时间和 Row ID 由系统生成。

## 在单元格中编辑

打开单元格编辑器、输入值并提交。Escape 会取消当前 draft。编辑器会区分 draft 与规范数据，
提交成功后使用 Runtime 返回的完整行替换 draft。

多单元格粘贴在 negotiated limit 内属于一次原子编辑。只要一个值无效，就不会静默提交其余
单元格。更大的结构化数据应使用 CSV 导入，而不是一次超大粘贴。

## 展开完整记录

长文本、多个关系或文件不适合在 Grid 中阅读时，使用**打开记录**。详情面板显示适用字段，也
可以把记录打开到独立标签页。这里的编辑会更新当前视图中的同一行。

记录标题始终来自当前数据表的记录标题字段。

## 关联和打开相关记录

在关系编辑器中：

1. 按目标表的记录标题搜索。
2. 根据字段 cardinality 选择一条或多条记录。
3. 使用已选项旁的打开入口检查目标记录，而不修改关系。
4. 取消选择时只移除那个稳定 Row ID。

如果目标无法解析，Eidos 会显示其 Row ID 和不可用状态，而不是静默删除关联。

## 添加文件与图片

文件字段保存便携的 file-entry 元数据。根据 Host policy，可以选择本地文件或显式添加 HTTPS
URL。预览、打开与下载都是需要 Host 授权的明确操作；仅仅展示或滚动一行不会获得通用文件或
网络权限。

图片可以显示缩略图。即使无法预览，原始文件名、media type、大小和 URI 仍可通过详情或复制
操作获取。

## 复制值

即使 Grid 对长值做了截断，复制也应提供完整逻辑值。关系字段用可读标签帮助识别记录，但底层
关系仍然是稳定 ID。CSV 导出会有意使用关系标签和附件名称；它适合数据交换，却不能无损克隆
Eidos File。

## 撤销与重做

撤销和重做是新的、经过 Runtime 校验的修改，不是字节级回滚。会话还持有相应 undo token 时，
受支持的记录编辑可以撤销。结构修改会清除记录撤销历史，因为原来的字段形状可能已失效。

如果后续修改覆盖了相关值，撤销会进入冲突流程，而不是覆盖新数据。提交前取消编辑不是撤销，
只是丢弃 draft。

## 谨慎删除记录

删除针对当前选择解析出的稳定 Row ID。应用前检查数量和关系影响。当前 Host 与 Runtime 提供
mutation undo 时，成功删除可以进入相同撤销流程，但不能把它当成备份。

删除不是“删除现在位于这个视觉位置的行”。筛选和排序可能让行移动，因此 Eidos 会先把选择
解析为 ID。

## 编辑被拒绝时

- **值无效：**按照字段类型和约束修正 draft。
- **Revision 过期：**刷新并比较当前值，只在安全时重新应用。
- **结果未知：**让 Host 完成 reconciliation 后再提交同一修改。
- **字段只读：**改源字段、关系，或公式/查找定义。

使用[视图与查询](/zh-cn/user-guide/views-and-querying/)控制工作时出现的记录和字段。
