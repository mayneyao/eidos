一条记录代表表中的一个项目。同一条记录可以显示为 Grid 中的一行、
Gallery 中的一张卡片，或其他视图中的项目。

## 修改一个值

1. 在 Grid 中选择单元格。
2. 按 **Enter** 或双击进入编辑。
3. 输入新值并提交编辑。
4. 检查显示的结果。

按 **Escape** 取消当前单元格的编辑。
用 **Tab** 和 **Shift + Tab** 在单元格间移动。
Formula、Lookup 等计算字段不能直接编辑，需要修改它们的输入值。

## 添加记录

使用 **Add record**，或在 Grid 中按 macOS 的 **Cmd + Enter**、
Windows/Linux 的 **Ctrl + Enter**。在记录标题字段中输入易辨认的名称。

如果当前视图看不到新记录，检查筛选条件。新记录可能不符合条件。

## 粘贴多行多列

从电子表格复制行和列，选择目标单元格后粘贴。
检查列是否对应，以及日期、数字是否正确。
导入完整数据集时，使用 [CSV 导入](/zh-cn/user-guide/import-and-export/)。

## 阅读较长的记录

使用行上的展开操作打开记录详情。
长文本、关联和附件在详情中有更多显示空间。

## 关联另一条记录

1. 打开 Relation 单元格。
2. 在目标表中搜索记录。
3. 选择要关联的记录。

关联保存记录的 ID，显示名称来自目标表的记录标题字段。
修改显示名称不会破坏关联。

## 添加附件

通过 File 字段添加附件。导入和预览方式取决于打开 Eidos File 的应用。
移动数据时，也要带上引用的本地附件。
详见[数据存储](/zh-cn/user-guide/data-safety/)。

## 撤销编辑

对当前编辑器支持撤销的操作，在 macOS 按 **Cmd + Z**，
Windows/Linux 按 **Ctrl + Z**。撤销后检查结果。
恢复更早保存的状态时，使用[版本](/zh-cn/user-guide/history-and-recovery/)；
撤销不能替代备份。
