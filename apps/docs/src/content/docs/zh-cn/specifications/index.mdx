同一 abstraction 的内建变体共用一份 companion 规范。因此 Standard Views 统一记录
Grid、Gallery、Kanban、Calendar 与 Form；单独的 optional profile 只留给 baseline
之外的扩展。

规范源文件位于
[`docs/specs`](https://github.com/mayneyao/eidos/tree/dev/docs/specs)。
