中文页面是参考译本。

## 开始阅读

实现完整技术栈时，按照以下层级顺序阅读：

```text
文件格式 → Runtime → Adapter → 界面
```

先阅读文件格式和 Runtime。需要把 Runtime 接入具体平台时阅读 Adapter；需要构建编辑器或
查看器时阅读界面规范。
