Eidos 是一款独立开发的开源产品。本地功能永久免费，但部分高级场景（跨网络数据接收、同步等）需要云端计算资源——我们称之为 **Add-on 服务**。

Spark License 通过两项核心权益解锁高级云端功能：

## 1. 新功能抢先体验

新功能上线时第一时间使用：

| 功能           | 状态                                |
| -------------- | ----------------------------------- |
| **自定义同步** | ✅ 现已可用（AWS S3、R2、MinIO 等） |
| **Relay**      | ✅ 现已可用                         |
| **官方同步**   | ⏳ 即将推出                         |
| **发布服务**   | ⏳ 即将推出                         |

## 2. Add-on 服务免费配额

Spark 用户享有云端资源免费配额：

### Relay

| 参数             | Spark                   | Free¹                  |
| ---------------- | ----------------------- | ---------------------- |
| **Channel 数量** | 100 个                  | 5 个                   |
| **存储空间**     | 100 MB（约 5 万条消息） | 10 MB（约 5 千条消息） |
| **消息保留期**   | 14 天                   | 3 天                   |
| **单条消息大小** | 128 KB                  | 128 KB                 |
| **API 调用频率** | 1000 次/小时            | 1000 次/小时           |

¹ Free 版 Relay 目前处于推广体验期，未来将转为订阅制。

:::note
上述配额为**动态配额**，采用**共享配额池模式**运作。我们**不保证**永久提供固定配额的云端资源——配额可能根据基础设施容量和服务增长进行调整。

**示例**：当前存储为 100 MB。随着更多 Spark 用户加入，基准额度可能下调至 50 MB 以保证可持续性。但早期支持者永久保留**2 倍基础配额**（或更高，取决于档位），因此仍享有 100 MB，而新用户从 50 MB 开始。
:::
