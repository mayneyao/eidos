## What's new

### Install Eidos Lite as a Debian package

Linux releases now include native `.deb` installers for amd64 and arm64 alongside
the existing AppImages. Debian, Ubuntu, and Linux Mint users can install the
matching package with `apt`, while existing AppImage installs remain supported.

### Eidos Files stand out in the file tree

Files with the `.eidos` extension now use the Eidos mark in the Space explorer,
making structured data files easier to distinguish from ordinary documents.

### Long lines wrap in the text editor

Long lines in text and Markdown source editors now wrap to the available width
instead of requiring horizontal scrolling.

### URL cells remain editable around their links

Clicking the link text in a URL cell still opens it, while clicking elsewhere in
the cell now preserves normal selection and editing behavior.

No migration is required.
