Eidos Lite 0.25.1 restores encrypted transfer progress and fixes Windows titlebar and sidebar layouts.

## Bug fixes

- **Encrypted Sync progress**: First uploads, opening a cloud Space and later transfers now show transferred bytes and speed. When the total size is unknown, the progress bar stays active without an inaccurate percentage or remaining-time estimate.
- **Windows window controls**: Titlebar actions stay aligned and proportioned to the native minimize, maximize and close buttons when application zoom changes.
- **Sidebar headers**: File preview, History and Sync reserve space for Windows window controls. Actions sit beside the sidebar title and remain visible when long titles are truncated.
