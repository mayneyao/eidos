## What's new

### Install plugins from GitHub

Press **⌘K** on macOS or **Ctrl+K** on Windows and Linux. Paste a public GitHub repository, release, or `.eidos-plugin` asset link and press **Enter**. Review the plugin and its requested permissions before installing it in your current Space.

### Choose default file editors by Space

When installing a plugin that opens a file type, you can make it the default in your current Space. For example, choose Canvas for `.canvas` files.

Choose **Open file settings** in the plugin details to jump to that file type. In **Settings → Files**, switch between the current Space and **This device (global)**. Choose **Follow device** to use the device setting for a file type in that Space.

### Filter folders in Manage files

Use the `is_dir` field to show folders or files. Choose **Checked** for folders and **Unchecked** for files, including files with no extension.

## Bug fixes

- **Files Gallery.** Folders and empty text files now have visible covers. Cards stay in place while another Gallery view loads.
- **File extension filters.** **Is empty** now finds folders and files with no extension.
- **Record menus.** Context menus in Gallery, Kanban, Calendar, and Feed open where you clicked.
- **Plugin details.** Uninstalling an installed plugin returns you to Plugins.
