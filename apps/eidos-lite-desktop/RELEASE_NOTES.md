## Bug fixes

- **Record Content images**: Images stored alongside an Eidos File now display correctly in record Content pages, including relative paths in Markdown and HTML image elements.
- **Sync setup**: Spaces that are not yet connected now use the same compact Sync panel and account menu as connected Spaces. First-upload checks remain available without duplicate account and storage sections.
- **Multi-select conversion**: Converting a Text field containing a JSON string array, such as `["Work","Personal"]`, now creates separate choices instead of one choice containing the entire array. Plain text remains a single choice.
