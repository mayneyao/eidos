New end-to-end encrypted cloud connections remain disabled in production in this beta. Updating Lite does not enable them. Local files and local version history remain available offline.

## What's new

### Preview files beside a table

Choose **Open in sidebar** from a file row's menu to view the file while keeping your table visible. The preview uses your configured file editor or File View.

### Arrange table actions

Hold **Option** on macOS or **Alt** on Windows/Linux while a table's row menu is open, then drag actions into your preferred order. Lite remembers the order across tables. Choose **Restore default order** to reset it.

## Improvements

- **Sync**: A simpler setup panel shows the files included in an upload, excluded files, password settings and actionable retry states. Supported hidden files, large files and filenames containing words such as “secret” no longer require a separate confirmation.
- **Account settings**: Sync access, storage and password settings use the same compact layout as other settings.

## Bug fixes

- **Markdown**: Clicking below the last block places the caret without marking the document as edited. Saving before typing preserves the original Markdown without adding an empty line.
- **Updates**: Prerelease builds no longer offer older releases as updates. The floating update action aligns with the other footer controls.
