## 新功能

### 用表格整理本地文件

在新建文件中选择 **Eidos**，开启**文件元数据管理**，即可将所在文件夹及其子目录作为表格浏览。无需导入原文件，就能添加标签和评分、自定义字段、筛选文件并预览附件。重命名字段会保留已有值。

这些值保存在物理文件自身的属性中，不在 `.eidos` 数据库内。删除自定义字段会清理对应属性。备份和传输工具必须保留扩展属性或备用数据流；不要仅依靠复制 `.eidos` 文件或 Sync 来保留这些值。

### 为普通文件构建插件

插件 API 2.0 提供统一的文件系统接口，用于授权范围内的文件访问、媒体查看器，以及字幕等配套文件。插件可以响应不同类型文件的变动，并提供针对文件的操作。

**插件需要升级：**可执行插件必须迁移到 `ctx.fs`，并声明 `requires.pluginApi: "2.0.0"`。旧的可执行插件在更新前无法运行。纯 API 1.6 主题插件仍然兼容。

## 改进

- **新建菜单**：新建文件、新建文件夹和导入统一放在搜索旁边的 **+** 菜单中。简化后的新建文件弹窗将 Eidos 和 Text 选项放在标题旁，切换时高度保持稳定。
- **插件浏览**：插件市场条目可以展示截图，方便安装前了解插件。

## 问题修复

- **文件树**：将子目录文件拖到空白区域即可移回根目录。移动文件减少了不必要的整树刷新；拖动滚动条到底部并保持按住时，不再反复跳动。
- **终端外观**：切换明暗模式时，终端颜色和字体会跟随主题插件更新。
