Eidos Lite 0.24.2 在 macOS 和 Linux 上带来端到端加密云同步。使用同步密码连接各台电脑上的 Space，本地文件和本地版本历史仍可离线使用。

## 新功能

### 端到端加密云同步

登录有同步权限的账户，打开**同步 → 云同步**，设置**同步密码**，再点击**启用同步**。Lite 会在设备上加密文件内容、路径、版本说明和分支名称后上传。在另一台支持的电脑上打开云端 Space 时，输入相同密码即可。

同步密码与账户密码相互独立，请将它保存在密码管理器中：Eidos 无法找回密码，也无法代你解密云端副本。加密保护云端副本，本地文件仍然可读。Windows 和手机端目前不能打开这些加密云端 Space。

### 在表格旁打开文件

在文件行的菜单中选择**在侧边栏打开**，即可在保留表格的同时阅读或编辑文件。Lite 会使用你配置的文件编辑器或 File View 打开预览。

### 调整表格行菜单的操作顺序

打开表格的行菜单，按住 macOS 的 **Option** 或 Windows/Linux 的 **Alt**，拖动操作即可调整顺序。Lite 会记住排序并应用于其他表格。选择**恢复默认顺序**可恢复原来的排列。

## 改进

- **启动**：欢迎页面减少了不必要的后台加载，插件详情和嵌入表格编辑器在打开时加载。
- **同步设置**：在更精简的面板中查看上传文件的数量、大小和不包含的文件，并使用相邻的密码设置和明确的重试操作。支持的隐藏文件、大文件，以及文件名含有“secret”等词语的文件，不再需要额外确认。
- **账户设置**：同步权限、存储和密码控件采用与其他设置页面一致的紧凑布局。

## 问题修复

- **文件浏览**：后台刷新使目录缓存失效后，已展开的文件夹会重新加载内容，无需先收起再展开即可继续访问文件。
- **Markdown 编辑**：点击最后一个内容块下方可移动光标，不再将文件标记为已修改。尚未输入时保存，会保留原始 Markdown，不会新增空行。
- **检查更新**：不再将比当前运行版本更旧的版本作为更新提供。悬浮的更新操作也与其他底部操作对齐。
