## 新功能

### 从 GitHub 安装插件

在 macOS 上按 **⌘K**，在 Windows 和 Linux 上按 **Ctrl+K**。粘贴公开的 GitHub 仓库、发布页或 `.eidos-plugin` 文件链接，再按 **Enter**。查看插件及其所需权限后，即可安装到当前 Space。

### 按 Space 设置文件的默认打开方式

安装支持打开某类文件的插件时，可以将它设为当前 Space 的默认打开方式。例如，用 Canvas 打开 `.canvas` 文件。

在插件详情中点击 **打开文件设置**，可以直接跳到对应的文件类型。在 **设置 → 文件** 中可切换当前 Space 和 **本设备（全局）**。为某个文件类型选择 **跟随设备**，当前 Space 就会使用设备设置。

### 在文件管理中筛选文件夹

用 `is_dir` 字段区分文件夹和文件。筛选已勾选的项可查看文件夹，筛选未勾选的项可查看文件，其中也包括无扩展名的文件。

## 问题修复

- **文件图库。** 文件夹和空文本文件现在有可见封面。切换图库视图时，原有卡片会保留到新视图加载完成。
- **扩展名筛选。** 选择 **为空** 可以找到文件夹和无扩展名的文件。
- **记录菜单。** 图库、看板、日历和动态视图的右键菜单会出现在点击位置。
- **插件详情。** 在详情中卸载插件后，自动返回插件首页。
