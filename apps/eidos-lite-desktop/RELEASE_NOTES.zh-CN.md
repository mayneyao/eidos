## 新功能

### 折叠标题与整节重排

标题现在带有折叠控件。折叠标题即可隐藏其内容，再次展开即可恢复；也可一次性折叠或展开全部标题。拖动标题旁的把手可将整节（标题及其内容）一步移动。新增文档快捷键：切换折叠（`⌘/Ctrl+Alt+[`）、折叠全部（`⌘/Ctrl+Alt+0`）和展开全部（`⌘/Ctrl+Alt+Shift+0`），均可在设置中重新绑定。

### 插入 Callout 提示块

在块插入菜单中新增 Callout。新 Callout 默认类型为 Note，标题自动首字母大写，可直接修改类型或标题。Callout 在编辑器与发布页面中使用一致样式。

### 拖动调整图片宽度

将鼠标悬停或聚焦到独立图片上会显示左右宽度把手。拖动可在内容栏内按比例缩放，或按左/右方向键（8 像素，按住 Shift 为 32 像素）。宽度使用现有的 `![alt|width](url)` 语法保存，一次拖动为一步撤销。只读文档与行内图片保持原有行为。

### 自定义文档快捷键并更快切换 Markdown 模式

“键盘快捷键”设置新增“文档”分组：折叠标题、上移/下移列表项与块、加粗和斜体，与已有的工作区和表格命令并列。可重新绑定、清除或恢复默认快捷键，并会就地提示冲突和系统保留组合。新增 `⌘/Ctrl+2` 快捷键，用于在富文本与 Markdown 源码编辑之间切换，其绑定会显示在“打开方式”菜单中。

## 改进

- **发布页面**：发布文档改用静态 HTML 渲染，与编辑器共享数学公式、Callout、属性、高亮和图片尺寸等语法。样式表随页面打包，发布内容无需编辑器运行时，也无需额外请求样式表。

## 问题修复

- **同步**：退出后重新登录或切换账号后，同步不再卡住，会自动恢复身份验证。
- **导航**：在视图、文件和记录之间切换时使用统一的导航历史，前进与后退会回到正确的记录。
- **快速打开**：快速打开改为模态对话框，打开期间键盘焦点保留在对话框内。
- **版本历史**：选择版本不再重新加载其详情，面板保持响应。
- **界面**：修正资源管理器的右键菜单尺寸与排版，并对齐设置分区与应用品牌标识。
- **字段**：字段弹窗中的系统字段标签已对齐。
- **Markdown 编辑器**：编辑器在打开时聚焦文档开头，嵌套列表不再出现多余的行间距。
