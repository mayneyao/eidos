## 新功能

### 对记录运行插件动作

插件现在可以在表格右键菜单中添加动作。对选中的记录或当前筛选结果运行操作，在可最小化或展开的任务窗口中查看进度，并撤销或重做支持的修改，无需重新执行动作。

插件也可以通过**打开方式**为 `.eidos` 文件提供独立工作界面。连接地址、模型和 API Key 在插件设置中统一管理，API Key 加密保存在本机。

## 改进

- **插件安装**：将 `.eidos-plugin` 文件拖入插件页面即可安装或更新。
- **插件兼容性**：安装和运行前检查插件要求的 API。不兼容的更新会保留已安装版本，不兼容插件仍可查看和卸载。
- **编辑器标题**：标题栏在文件名旁标明当前插件或 Markdown 编辑模式。

## 问题修复

- **深色模式**：Feed 和记录详情中的 Markdown 跟随应用主题，即使系统外观与应用设置不同。
- **版本历史**：历史列顺序不同时，差异值仍与列名正确对应。
- **插件页面**：避免出现不必要的页面滚动条。
