## 新功能

### 按自己的方式浏览文件夹

右键文件夹并选择「显示此文件夹」，即可将文件浏览器聚焦到该目录。支持按名称、修改时间或文件类型排序，文件夹始终在前，并记住你的排序偏好。

### 自定义侧边栏

固定常用插件页面并调整顺序，让常用入口随手可达。插件还可提供完整的文件浏览器：在插件管理中选择，也可随时切回内置文件浏览器。

### 双击安装插件包

双击 `.eidos-plugin` 包，查看插件身份信息和权限后即可安装或更新。更新会保留各个 Space 的启用状态；新安装的插件需要手动启用。

## 改进

- **文件元数据配置继承**：在子目录创建 `files.eidos` 时，会复制最近父目录配置中的自定义字段、选项、显示设置和属性映射。后续修改父级配置不会覆盖已有子级配置。
- **插件开发**：Plugin API 3.1 新增原生文件属性读写和自定义侧栏文件浏览器接口。现有 API 3.0 插件继续受支持。

## 问题修复

- **记录打开偏好**：记住以侧边面板或完整页面打开记录的选择，重启后无需重新设置。
- **单元格编辑器对齐**：新增记录的编辑器在布局变化后仍与单元格对齐，同时保留正在输入的内容和焦点。
