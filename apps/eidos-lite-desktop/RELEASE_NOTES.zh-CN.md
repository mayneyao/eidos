## 新功能

### 通过局域网连接手机

将 Android 或 iOS 版 Eidos 与 Eidos Lite 配对，即可在同一局域网内下载和同步 Space。每台设备保留可离线使用的副本，局域网同步无需云账号。在电脑上确认配对请求、按设备查看传输进度，重启 Lite 后继续共享。发生编辑冲突时，可在桌面端查看和处理。

### 组合文件与已保存的视图

插件 API 3.2 支持将已保存的表格视图与普通文件组合为只读展示，在“新建文件”中提供插件自己的文件模板，并通过宿主的保存对话框导出生成的文件。插件文件编辑器支持统一的保存操作，包括 Command-S 或 Ctrl-S。现有 API 3.0 和 3.1 插件仍可使用。

## 改进

- **发布文件视图**：将普通文件通过插件的 file View 发布为网页，例如在地图中展示 GPX 路线。发布时一并保存文件与插件的快照，访客看到的是已发布版本。需要 Pro。

- **新建文件**：直接选择文件类型，自由决定文件名。文本文件可以没有扩展名，也可以使用 `.graftignore` 这样的点文件名。
- **设备传输**：同步界面按设备展示活动，并使用本地化的进度说明。

## 问题修复

- **Markdown 待办列表**：空的已完成和未完成待办项在保存、重新打开后保留状态，支持嵌套列表和带空行的列表。
- **本地历史**：历史服务不可用时显示可操作的错误提示，不再留下空白面板。内置 Graft 依赖与版本检查保持一致。
- **编辑器焦点**：将焦点切回 Markdown 内容时恢复光标位置，方便继续使用键盘编辑。
