Eidos Lite 0.25.0 新增 Windows 加密云同步，并支持在保留本地文件和版本历史的同时，更换云端连接。

**降级前请注意**：本版使用加密同步后，旧版 Lite 无法在这台电脑继续该云端连接；重新安装 0.25.0 或更新版本即可恢复同步。本地文件和已保存的历史不会被删除。

## 新功能

### Windows 加密云同步

Windows 现在可以连接加密云端 Space，与 macOS 和 Linux 双向同步改动。登录有同步权限的账户，打开**同步 → 云同步**，输入该 Space 的同步密码即可。Windows 仅在当前会话使用密码，重启后需要重新输入；当前版本暂不支持在 Windows 保存默认同步密码。

### 在原文件夹断开并重新连接

在同步面板选择**断开云端连接**，即可移除这台电脑的连接。确认框会说明保留范围：本地文件、未保存的改动和 Graft 历史都留在原处，云端副本不会被删除。云端仓库已删除或服务不可用时，也能执行此操作。

再次启用同步，即可从原文件夹创建新的加密云端仓库，无需复制或重命名 Space。

## 改进

- **加密同步可靠性**：首次加密上传及其重试会保留开始连接时选定的已保存版本；停滞的传输会在限定时间内结束。

## 问题修复

- **Windows 插件链接**：已安装的应用会在启动时注册插件安装链接，浏览器可据此打开 Lite 中对应的安装页面。安装或更新后，先启动一次 Lite 即可注册链接处理程序。
