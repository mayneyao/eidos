## 新功能

### 在目录树中筛选 Space 文件

目录树现在与表格使用相同的筛选编辑器，支持按文件名、路径、后缀和扩展属性查找文件。可以通过 AND/OR 和嵌套分组组合条件，也支持多个后缀或复合后缀。筛选结果保留父目录，并能找到尚未展开的文件夹中的文件。条件统一收在筛选菜单里，工具栏按钮显示条件数量。

### 插件多语言

插件现在可以打包多语言名称、描述、功能标签和独立的 README 文档。插件详情会选择匹配的语言，避免在同一篇文档中混用多种语言；支持此能力的插件界面也能响应应用语言切换。插件开发者可以通过新的 localized-page 模板和 Plugin API 3.7 开始开发。

## 改进

- **目录树**：右键 Space 可展开或收起所有文件夹，右键单个文件夹则只控制该目录及其子目录，菜单项随当前状态切换。
- **插件**：详情页在其他功能之外标明后台服务；启用状态文案更简洁，侧栏拖动排序实时显示新位置。

## 问题修复

- **同步**：安全恢复经过验证的系统元数据合并，清晰显示表格和字段冲突摘要，并在合并无法完成时保留可继续恢复的状态。
- **插件侧栏**：多个入口名称相同时，正确高亮当前选中的插件入口。
