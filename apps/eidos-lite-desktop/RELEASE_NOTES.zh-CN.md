## 改进

- **插件开发**：Plugin API 3 将视图组织为页面和文件两类。文件视图可使用文档编辑，以及 Eidos 结构、表格和配置能力。插件通过统一的能力接口操作资源，操作句柄随生命周期结束而失效。

**需要升级插件**：可执行插件须声明 `requires.pluginApi: "3.0.0"` 并使用新的 SDK 接口。升级 Lite 后，请将已安装的可执行插件更新至支持 API 3 的版本。插件开发者请参阅[迁移指南](https://github.com/mayneyao/eidos/blob/dev/docs/migrations/eidos-plugins.zh.md)。纯 API 1.6 主题插件继续受支持。

## 问题修复

- **文件创建时间**：文件系统提供创建时间时，文件元数据会显示真实创建时间，不再重复显示最后修改时间。不提供创建时间的文件系统将该值留空。
- **恢复后的文件删除**：恢复一个删除了 SQLite 文件的历史快照后，刷新历史、暂存和同步都会保留删除结果。缓存的数据库状态不会再让已删除文件重新出现。
