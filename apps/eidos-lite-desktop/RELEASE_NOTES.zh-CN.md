## 新功能

### Feed 视图

Feed 是一种全新的标准视图，把数据表读成一条时间线：最新的记录排在最前，标题取自记录标签，正文取自 Content 字段并按 Markdown 呈现。浏览日志、笔记、动态这类按时间累积的内容时，它比表格更自然。Feed 在 Eidos Lite、浏览器编辑器和 `eidos serve` 中均可用。

### 记录导航

记录面板现在可以在记录之间前后切换，并跟随当前视图的顺序，无需回到表格即可连续浏览；面板也可在侧边栏与完整内容页之间切换。

## 问题修复

- **Content 图片**：记录 Content 现在可以显示与 Eidos File 一起存储的图片，包括 Markdown 和 HTML 中的相对路径。
- **Sync 连接设置**：尚未连接的空间现在使用与已连接空间一致的紧凑 Sync 面板和账号菜单。
- **Sync 可靠性**：因 Remote 竞争被拒绝的 Hosted 上传，现在会先重新拉取并重新分类再重试，而不是针对过期的 head 重复推送。
- **字段转换**：文本字段中的 JSON 字符串数组转换为多选时，现在会为每个值生成独立选项；转换后的标量单元格也可以清空。
- **Windows 标题栏**：深色主题下标题按钮保持可见。
