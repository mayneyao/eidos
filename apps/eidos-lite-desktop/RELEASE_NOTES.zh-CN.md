## 新功能

### 通过插件自动处理本地文件变化

插件现在可以注册文件 Hook，在本地保存和重命名后执行。Markdown Title Sync 利用这一能力，让 Markdown 文件名与文档已有的开头一级标题保持同步。在 Space 中安装并启用该插件即可使用；标题同步是可选能力。文档因 Hook 重命名后，已打开的编辑器会跟随新路径，便于继续编辑。

### 创建带 Markdown 正文的表格

新建 Eidos 文件时展开高级选项，勾选「包含 Markdown 正文」，即可添加一个 Text 字段来存储记录正文。展开记录后，可用 Markdown 编辑器编辑正文。正文字段属于表格配置，所有视图共用，也可稍后在表格设置中修改。

## 改进

- **插件设置**：由插件配置生成的表单采用统一的标签、说明、控件和间距。连接配置也使用相同布局，并提供清晰的保存、错误和重试状态。
- **插件详情**：页头显示插件自己的描述。发现页和权限摘要更清楚地说明插件使用的能力。
- **新建文件**：高级选项采用紧凑的折叠布局，说明更加清晰。
- **版本历史**：合并检查减少不必要的全仓库操作。

## 问题修复

- **本地变更**：打开或应用未变化的表格、字段设置时，不再产生多余的结构变更或版本快照。
- **Markdown**：链接内支持触摸选文本和逐字删除，避免一次删除整个 URL。编辑器预留滚动条空间，减少进入编辑状态时的水平抖动。
- **文件**：文件夹元数据表中的记录可以正确打开其映射的普通文件。
- **编辑器偏好**：修改默认文件编辑器后，Markdown 编辑器选项能够持久保存。
- **发布**：文件发布会提供兼容的只读插件视图。
- **终端**：浅色主题下的文字保持清晰可读。
